# 模块 03｜邮寄要求、时限、退回与补正

## 邮寄硬规则

1. **时限**：收到网上立案“审查通过”提示后，按期寄出纸质件（示例法院要求 **3 日内**）。逾期可能被退案。
2. **承运方式**：**只能用中国邮政**（EMS／挂号信）。其他快递公司一律拒收——这一点各家法院口径一致，别赌。
3. **封面注明**：“邮寄立案”。信封或快递单备注里写清案由与原告姓名，内件附一份材料清单便于清点。
4. **收件人**：立案庭（民事一审、执行异议）；执行立案寄主审法官。执行异议另按该院指定地址寄送。
5. **留证**：快递单号、收据拍照留档。后续查询、申请执行、退费、上诉都要用到。
6. **原件就是原件**：凡要求原件的材料不得寄复印件；证明类、授权委托类、函类材料该捺印的捺印、该盖章的盖章。

## 被退回的常见原因（按出现频率）

| 原因 | 典型表现 | 预防 |
|---|---|---|
| 起诉状版本或格式错误 | 该用要素式示范文本却交了传统格式；删改要素栏目；缺项 | 先按案由判断版本；要素式表只填不删 |
| 份数不足 | 缺副本、证据只有一套 | 按“被告人数＋2”算，证据按套算 |
| 该捺印未捺印 | 签名处只有打印体姓名；落款无指印 | 逐页检查签名、指印、公章 |
| 材料缺页 | 企业信用报告缺历史变更记录页 | 打印时勾全，逐页核对页数 |
| 诉讼请求不明确 | 只写总额不写算式 | 赔偿金写出计算过程与法律依据 |
| 主体信息不全 | 缺被告联系电话、住所 | 与公示信息、合同、票据逐项核对 |

## 收到补充／补正意见后怎么做

法院审查后会一次性列出问题（常见如“补充被告联系电话”“事实与理由需简写”“落款处需捺手印”“提供被告企业信用查询报告复印件”“本案分配为调解案件”）。处理方式：

- **逐条落到具体文书**：电话补进起诉状被告信息栏与正文；事实与理由按要素逐项简写、只写时间·金额·行为·依据，不铺论证；落款签名上按指印；信用报告按公示系统完整打印。
- **程序性通知要作对应选择**：分配为调解案件的，要在先行调解告知书上勾选意见，并在起诉状（要素式表）的“是否了解／是否考虑先行调解”栏作出对应选择，两处口径必须一致。
- **改过的文书作废旧版**：一旦按意见改稿，之前打印的、已转 PDF 的、已发出的旧版全部作废；重新打印并签名捺印。三份起诉状要同版同内容。
