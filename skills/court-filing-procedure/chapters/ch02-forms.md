# 模块 02｜立案六张表格：打印规格与逐栏填写

民事立案要打印并手填六张表（示例法院口径，各院表单数量与名称不同）。**“彩色／黑白”“单面／双面”是硬要求**，打错会被退。

| 表格 | 打印规格 | 当事人要填的关键栏位 |
|---|---|---|
| 送达地址确认书 | **彩色、单面** | 案由、案号、证件类型与号码、邮编、确认送达地址、是否接受电子送达及手机号码、其他联系方式；当事人签名＋捺印＋日期 |
| 送达回证 | **彩色、单面** | 案号、案由、送达文书名称和件数、受送达人、送达地址、受送达人签名；代收人与备注一般填“无”；填发人／送达人属法院侧 |
| 诉讼事项告知书 | **彩色、正反面** | 正文是告知内容；末页“承诺人”签名＋捺印＋日期 |
| 适用简易程序告知书 | **黑白、单面** | 当事人意见（同意／不同意适用简易程序并注明理由）；当事人签名＋捺印＋日期 |
| 先行调解告知书 | **黑白、正反面** | 案号、当事人栏、是否同意调解（勾选）、签名捺印 |
| 诉讼费退费确认单 | **黑白、单面（三联）** | 案号、预交金额、预交时间、票据号、退费申请人户名、开户行、银行账号、证件名称与号码、联系电话、签名 |

## 填写通则

- 只用黑色签字笔；写错划一道横线在旁边重写，不用涂改液、不撕表。
- **签名栏一律亲笔手写全名，并在姓名上按指印**（红色印泥）。法院明示：所有诉讼文书上的签名、捺印及盖章均须本人所为。
- “案号”栏在收到法院立案通知／短信后照抄填入；未收到时留空，不要自己编。
- 带“是否接受电子送达”的表：勾选接受并填手机号能显著提速，但要知道判决书、裁定书、调解书不在电子送达范围内。
- **不确定的法院侧栏目不要瞎填**：送达回证的“送达文书名称和件数”“填发人”“送达人”，退款确认单的“票据号”等，填错不如先打立案庭电话问口径。

## 三张表的选择题（怎么选）

- **适用简易程序**：选同意。简易程序减半预收诉讼费，对当事人有利；但若案件复杂，法官可依职权转普通程序并补收剩余诉讼费。
- **是否同意先行调解**：这是当事人的真实意思表示，不是形式勾选。同意＝可能更快拿到钱且调解阶段暂缓交费，但需接受让步；不同意＝直接进入审理程序、按通知预交诉讼费、等判决文书。**必须由当事人本人决定后再填**。
- **退费确认单**：账户必须是申请人本人账户且与身份证同名；开户行与账号务必逐位核对，写错会导致退费失败。案件审结前信息有变动要及时办理变更。

## 表格与流程的对应关系

- 调解阶段：先行调解告知书（勾选同意时）→ 暂缓交费。
- 转入审理：接到《交纳诉讼费用通知书》→ 交费 → 适用简易程序告知书确认程序。
- 结案后：判决／调解书生效 → 需要退费的按退费确认单办理。
