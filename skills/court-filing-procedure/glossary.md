# 术语

- **案由**：法院对纠纷性质的分类（如买卖合同纠纷、劳动争议）。案由决定起诉状版本、特殊材料与管辖。
- **要素式起诉状**：最高人民法院公布的表格式起诉状示范文本，按“当事人信息／诉讼请求／事实与理由／对纠纷解决方式的意愿”等要素分栏填写；只填不删。
- **送达地址确认书**：当事人确认接收诉讼文书地址与电子送达方式的表格；地址不准确或变更未告知，退回之日视为送达。
- **送达回证**：记录向当事人送达何文书、由谁签收的凭证。
- **诉讼事项告知书**：告知诉讼权利义务、风险、立案方式、费用、查询与投诉渠道的文书，一式两份。
- **适用简易程序告知书**：立案窗口建议适用简易程序并减半预收诉讼费时出具，当事人须签署意见。
- **先行调解告知书**：案件分配为调解案件时出具，当事人勾选是否同意调解；同意则暂缓预交诉讼费。
- **诉讼费退费确认单**：登记退费账户信息的表格（三联）；结案后如需退费按此账户退回。
- **受理费**：案件受理费；财产案件按标的额分段累进，1 万元以下每件 50 元。
- **缓交／减交／免交**：司法救助措施，依《诉讼费用交纳办法》申请。
- **移送执行书**：审判法官开具、据以将案件移交立案庭登记执行案件的文件；执行立案的必备件。
- **执前督促**：执行立案时的督促履行申请程序。
- **保全**：诉前保全（立案前，须财产线索与保函）与诉讼保全（立案后，可网络查控）。
- **分割／执行异议**：对执行行为或执行标的提出的异议；案外人与案内人均可提。
- **执行异议之诉**：对执行异议裁定不服另行提起的诉讼，按民事立案办理。
- **小额诉讼程序**：标的额在省上年度就业人员年平均工资 50% 以下的简单金钱给付案件可适用，一审终审。
- **分流办公室**：立案后负责扫描案卷、分配承办法官的部门。
- **网上立案**：通过人民法院在线服务平台（小程序）、诉讼服务网或律师服务平台提交立案申请。
