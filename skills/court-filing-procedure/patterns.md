# 判断步骤与退案预防（自编实务推演）

以下步骤是把该法院告知材料里的规则串成可执行的判断链，属于**推演**，不是法条。

## 步骤一：定阶段

问自己：现在是“要立案”“已立案要交费／退费”“要执行”“要上诉／撤诉／补材料”还是“要提执行异议”？六个阶段对应六套材料、六个收件人、六组表格。

- 民事一审 → 立案庭
- 执行 → 主审法官（先要移送执行书）
- 执行异议 → 立案庭（**执行异议之诉**则走民事立案）
- 上诉／撤诉／补交材料 → 承办法官

## 步骤二：定版本

先查案由是否落在受理法院指定的“必须用要素式起诉状”清单里。
- 在清单内：用最高人民法院《部分案件起诉状答辩状示范文本》对应案由的表；**只填不删**，无关要素填“无”或不填；文字多时扩容栏目，不改要素与格式。
- 不在清单内：用法院提供的传统格式范本。

## 步骤三：定份数

- 原告数 × 被告数不参与计算；公式是**被告人数＋2**（第三人计入当事人数）。
- 证据按“套”算，法院一套；考虑被告是否需要一套，按受理法院要求。
- 执行立案统一“原件 2 份”。

## 步骤四：填空与签印

按栏位清单逐项填（模块 02）。签字、指印、公章三件套是退案高发点：
- 落款签名＝亲笔手写全名＋姓名上按指印；
- 公司文书＝法定代表人签字＋公司盖章；
- 证明类、授权委托类、函类材料单独再检查一遍。

## 步骤五：寄件前的三次核对

1. **数量核对**：数页数、数份数、数表格张数，与清单逐项打勾。
2. **一致性核对**：起诉状、证据目录、证据原件三处的当事人名称、金额、品名、日期必须一致；票据上的门店名与登记字号不一致的，要在文书里主动说明。
3. **口径核对**：程序性选择（是否同意调解、是否同意简易程序）在起诉状与告知书两处是否一致。

## 六类高频退案原因与对策

| 原因 | 对策 |
|---|---|
| 起诉状版本错 | 先按案由查清单再动笔 |
| 份数不足 | 用“当事人数＋2”重算一遍 |
| 未捺印／未盖章 | 按“签字、指印、公章”清单逐项过 |
| 企业信用报告缺变更记录页 | 打印时勾全页面并核对页数 |
| 诉请不明确、事实堆砌 | 诉请写清算式与依据；事实与理由按要素分项简写 |
| 主体信息不全 | 被告名称、统一社会信用代码、经营者、经营场所、联系电话逐项与公示信息核对 |

## 改稿后的处置原则

按补正意见改过的文书，旧版立即作废：已经打印的、转过 PDF 的、已寄出的全部作废；以新版重新打印、签名、捺印，并确保随案的各份完全同版。若曾按旧版打包提交过，要在提交前主动向法院说明版本替换。
