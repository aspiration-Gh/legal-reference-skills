# 劳动法

调用别名：劳动法、劳动法技能、劳动社保。英文标识：`labor-social-security`。

范围：劳动、人事与社会保障实务。

以《劳动和社会保障法律法规全书》2022年版（简称《劳动社保全书》）为依据，按30个实务模块处理用工、职业保护、人事管理、社会保险与救助问题。模块编号不是原书章号；中性名称不表示跨法域通用。版本与覆盖边界见[来源说明](sources.md)。

**先读相关章节，再按事件发生时间、地域和身份核验官方适用规则。** 书载规范、历史案例和旧范本均不直接等于现行法。个别章节附有带日期的官方核验，只覆盖列明事项；其余不得推定已更新。无法核验时提供条件性分析和待核清单，不确认法定截止日、待遇数额或办理资格。

## 使用入口与依据分层

- 用户给实务问题：按下列流程定位模块，用 `read_file` 读取涉及条件、例外及关联段落；不得只凭速查答题。
- 用户给模块号：读取对应真实链接；跨页末段按[续文导航](sources.md)补齐。
- 用户未给事实：说明适用范围，并列会改变结论的最少事实，不擅造案件。
- **书载规范**：区分法律、法规、规章、司法解释、政策及技术标准；简称查回具体版本、条款和PDF页。
- **源书编者材料**：条旨、分类、案例摘要和范本用于定位。案例保留事实差异、裁判时点；代表建议答复中的研究计划不产生已生效义务。
- **自编应用**：流程、矩阵、证据清单与演练属于应用归纳，不是汇编作者的理论模型。部分模块将本模块编写者归纳称为“编者整理”，一律归本层，不与源书编者材料混同。

## 办理流程

1. **确定事实与身份。** 收集行为与送达日期、工作地/参保地、单位登记和性质、人员身份、实际管理报酬、合同及处理决定。区分劳动关系、民事劳务/合作、事业聘用、公务员/参公及退休再就业。劳动关系与法定用工主体责任分别证明；无书面合同、超龄、外包名称均不能单独决定结论。
2. **拆分行为和请求。** 逐项写明向谁请求什么、理由与期间。同一事件的行政认定、单位待遇、鉴定结论、人事处分可能走不同程序，不以“已经仲裁”排除全部行政事项。
3. **读书载依据。** 读取主模块及必要关联模块，记录规范简称、版本、条款、PDF文件页、适用条件、例外和案例事实。跨批续文不能仅据前章的局部未读声明判断全库缺失。
4. **核适用时点。** 使用 `web_search`、`web_extract` 查询官方法律数据库、发布机关、司法机关、主管部门及当地官方办事指南；核公布、生效、修废、过渡、地域和层级。网页更新时间不是生效日；政策目标、答复解释、范本条款不替代请求权依据。
5. **形成证据与期限表。** 每项事实注明证据、持有人、真实性、缺口及举证责任；保存原件、完整电子记录、申请收件与送达凭证。期间注明起算、中断/中止、日或工作日、受理或收件起算；不同程序独立计算，信访或协商不当然保住期限。
6. **计算与行动。** 锁定适用期间、基数、地区年度参数、项目与支付主体，使用计算工具逐项扣除已付额；判断能否并列及重复支付限制。给出补证、申请、沟通、整改或救济步骤，每步写清前提。

## 联动与高风险边界

民事合作、承包追偿、保证与解除协议问题，用 `skills_list` 按“合同实务/民事合同”主题发现已安装技能，再以实际名称 `skill_view` 加载。招聘、电子签约、健康档案、社保查询和公开披露问题，同样按“网安/数据/个人信息保护”主题发现；不假设本机技能名与仓库名一致。

优先查新的事项：旧复议及部门程序；工时、节假日、工资折算和地方假期；退休年龄、最低缴费年限、费率及待遇；处分种类、考核及分类管理；旧就业许可、扶持补贴和医学技术标准。税务/公司规则节录也只作入口。认定、诊断、鉴定和支付不能合并，保险或企业间协议不能当然免除法定义务；商业保险不当然替代法定参保。医学与技术表格只供专业程序定位，不由模型自动诊断评残或给现场防护参数。

## 输出与验收

交付“条件性结论—已知事实/关键缺口—书载依据—官方核验与时间适用—证据责任—程序期限—计算或行动”。每项关键条件/例外能经章节追到PDF页；明确哪些内容为规范、编者案例或自编分析。检查主体与路径是否一致、数字是否实算、地方参数是否核实、不同请求能否并列。原书略去附件、图表/OCR疑点及局部核验不足不得用常识补为已确认原文。
