# 劳动社保决策速查

自编导航，不替代章节条件与官方适用时点核验。

|情形|先判断 → 再行动|模块|
|---|---|---|
|无合同却受管理领工资|实际用工与证据 → 分关系认定、补签与责任|[07](chapters/ch07.md)|
|外包或派遣发生争议|实际管理、许可、三方关系 → 分身份与法定责任|[04](chapters/ch04.md)、[08](chapters/ch08.md)|
|被辞退或要求主动辞职|真实意思、事由、程序、送达 → 分恢复履行与退出金额|[07](chapters/ch07.md)|
|欠薪、加班或工资折算|工资口径、工时制度、地区标准 → 工具分项计算|[09](chapters/ch09.md)、[10](chapters/ch10.md)|
|单位禁止离职或索培训费|实际培训、有效约定、服务期与离职原因 → 核范围及剩余比例|[07](chapters/ch07.md)|
|竞业与秘密争议|接触秘密、范围、补偿和期间 → 不只看签字|[07](chapters/ch07.md)|
|孕产哺乳或未成年用工|年龄、岗位和保护期叠加 → 停止危险安排并分待遇救济|[13](chapters/ch13.md)|
|工作中受伤|责任单位、工作关联 → 认定、鉴定、支付分开|[26](chapters/ch26.md)、[27](chapters/ch27.md)|
|职业暴露或健康异常|岗位危害、监护记录 → 进入专业诊断，不自行评残|[12](chapters/ch12.md)、[27](chapters/ch27.md)|
|对处罚或经办决定不服|行政行为、前置及送达 → 复议/诉讼单列期限|[01](chapters/ch01.md)、[22](chapters/ch22.md)|
|工资或解约请求|关系、请求类型、时效管辖 → 核仲裁前置与裁审衔接|[14](chapters/ch14.md)、[15](chapters/ch15.md)|
|公务员或事业人事处理|身份、处理主体与事项 → 分申诉、监察救济及聘用仲裁|[16](chapters/ch16.md)至[20](chapters/ch20.md)|
|资格证书换岗位待遇|资格、聘用、工资依据分别核 → 不自动推定升职涨薪|[21](chapters/ch21.md)|
|退休、补缴或异地转移|身份、缴费与视同年限、待遇地 → 查改革与过渡规则|[24](chapters/ch24.md)|
|医疗费用报销|费用性质、第三人/工伤责任、待遇清单 → 不直接乘统一比例|[25](chapters/ch25.md)|
|离职后申领失业金|离职原因、缴费、登记求职 → 核领金与停发条件|[28](chapters/ch28.md)|
|生育假及津贴|劳动保护、津贴、医疗费分开 → 核地方假期及待遇|[29](chapters/ch29.md)|
|困难救助或公积金|家庭资格与缴存制度分流 → 查本地门槛和程序|[23](chapters/ch23.md)|
|旧政策或建议答复|规范层级与实际生效状态 → 不把研究计划当既得权|[30](chapters/ch30.md)|

**交付前检查：**身份与程序一致；期限分别计算；基数和参数已核；同一项目不重复；案例与推演分开；无法核验处明确留待确认。原书及简称说明见[来源](sources.md)。
