# 关键术语导航

以下是基于模块的精选释义；不复现全部术语。书载规则与适用时点须回读对应章，再核官方文本。

|术语|判断要点|模块|
|---|---|---|
|劳动关系|按实际用工、管理与报酬等事实判断；合同名称不是唯一依据|[02](chapters/ch02.md)、[07](chapters/ch07.md)|
|用工主体责任|法定责任承担不必然等于直接劳动关系成立|[07](chapters/ch07.md)、[26](chapters/ch26.md)|
|劳务派遣|派遣单位、劳动者、用工单位三方权义及许可，区别民事外包|[08](chapters/ch08.md)|
|共享用工|原企业关系保留的余缺调剂；不能借此规避派遣监管|[04](chapters/ch04.md)|
|非全日制|以小时计酬等特征及法定限制辨认，不只看合同标题|[08](chapters/ch08.md)|
|集体协商／集体合同|协商程序与形成的集体规范分别审查；不能代替个人劳动合同|[03](chapters/ch03.md)、[08](chapters/ch08.md)|
|竞业限制|秘密接触、限制范围、补偿、违约及解除分别判断|[07](chapters/ch07.md)|
|经济补偿／赔偿金|解除事由和法律后果不同，不能把所有离职都归为同一倍数|[07](chapters/ch07.md)|
|最低工资／工资总额|保障下限与统计计入范围不同，地区和用途影响口径|[09](chapters/ch09.md)|
|制度工作日／计薪天数|工时安排与工资折算分母不同，核适用版本后计算|[09](chapters/ch09.md)、[10](chapters/ch10.md)|
|医疗期|因病或非因工负伤的劳动保护期间，区别医疗保险支付期|[10](chapters/ch10.md)|
|未成年工／童工|年龄和岗位保护不同，不能将两类人员一概处理|[13](chapters/ch13.md)|
|仲裁时效／起诉期限|各有起算和适用程序，不因选择其他投诉路径当然停止|[14](chapters/ch14.md)、[15](chapters/ch15.md)|
|终局裁决|特定请求的裁决效力与双方救济不同，须查法定范围|[14](chapters/ch14.md)|
|行政认定／劳动待遇争议|机关决定合法性与单位给付义务可能分属不同程序|[01](chapters/ch01.md)、[26](chapters/ch26.md)|
|人事申诉／人事争议|人事处理复核申诉与聘用争议仲裁不能混同|[18](chapters/ch18.md)、[20](chapters/ch20.md)|
|职称／岗位／待遇|评价资格不自动产生聘任或工资请求|[19](chapters/ch19.md)、[21](chapters/ch21.md)|
|实际缴费／视同缴费|须依身份、历史政策及记录认定，不以工龄直接替代|[24](chapters/ch24.md)|
|社保先行支付|不同险种、责任主体及费用范围的特别机制，基金可依法追偿|[22](chapters/ch22.md)、[30](chapters/ch30.md)|
|社会救助／社会保险|困难资格与参保缴费待遇制度不同|[22](chapters/ch22.md)、[23](chapters/ch23.md)|
|工伤认定／职业病诊断／劳动能力鉴定|责任资格、医学诊断、劳动能力等级分开处理|[26](chapters/ch26.md)、[27](chapters/ch27.md)|
|停工留薪期|工伤治疗与原待遇保护相关期间，不自动等于鉴定或病休期限|[27](chapters/ch27.md)|
|失业登记／失业保险金|登记不当然满足缴费、离职原因等领金条件|[04](chapters/ch04.md)、[28](chapters/ch28.md)|
|生育津贴／生育医疗费／产假|支付基数、费用范围与劳动保护假期分别审查|[13](chapters/ch13.md)、[29](chapters/ch29.md)|
|建议答复|政策说明与研究安排不直接新设普遍法定义务|[30](chapters/ch30.md)|
