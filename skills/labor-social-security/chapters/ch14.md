# ch14 劳动人事争议：协商、调解与仲裁程序

> 来源：《劳动和社会保障法律法规全书》2022年版（2021.12第8版，ISBN978-7-5216-1794-8），PDF412–431页，并用PDF442–443书载案例示范。以下均为书载规则，未作现行法核验；使用时查官方适用版本、当地仲裁指南及最低工资标准。章节编号为实务模块号。

## 入口：请求、主体、期限、管辖

**办理步骤（自编推演）**：逐项写清请求金额或行为→确认劳动/人事关系及责任主体→记录权利受侵害、终止、主张权利和送达日期→选履行地/单位所在地机构→形成证据目录→审查是否适用终局、保全或先予执行。协商和调解可跳过，仲裁前置及例外须与[ch15](ch15.md)共同核对，不以“调解优先”强迫放弃仲裁。

规范层次：法律《劳动争议调解仲裁法》全54条（PDF412–417）；部门规章《企业劳动争议协商调解规定》全37条（417–419）、《劳动人事争议仲裁组织规则》全38条（419–422）、《劳动人事争议仲裁办案规则》全81条（422–429）；裁审衔接意见（2017年，429–430）与调解仲裁法律援助意见（2020年，430–431）属于指导性规范文件，不能混作司法解释。

- 劳动争议包括确认关系、劳动合同全过程、除名辞退辞离职、工时休假社保福利培训保护，以及报酬、工伤医疗费、经济补偿赔偿等。事业单位聘用制人员依法律处理，法律行政法规等另有规定优先。办案规则另列聘任制公务员、事业单位/社会团体人事关系及聘用制文职人员等；聘任制公务员时效须查特别规范。（PDF412–413、417、422–424）
- 劳动合同履行地为实际工作场所；单位所在地为注册登记地或主要办事机构所在地。双方分别申请的履行地优先；多个履行地按最先受理；不明确则单位所在地；受理后地点变更不改管辖。异议须答辩期满前书面提出；移送争执报共同上级主管部门指定，不能来回推诿。（PDF414、423）
- 派遣单位与用工单位为共同当事人；无照、吊照、歇业解散等不能担责时，按办案规则将单位及出资人、开办或主管单位共同列入；个人承包争议列发包组织及承包人。利害关系第三人可参加；代理书载明权限，无/限制行为能力者由法定或指定代理人，死亡由近亲属或代理人参加。（PDF414、423）

## 协商、企业调解与效力升级

协商请求5日不回应视为不愿协商，协商期限及延长用书面约定；可请工会或受托代表参与。和解协议应书面签署并履行；审查合法可作证据，但为和解妥协而承认的争议事实，不得成为随后仲裁的不利证据。（PDF417）

大中企业应设调解委员会，小微可设或共同推举人员；劳资代表人数对等，劳动者代表由工会成员或推举产生，主任由工会成员或双方推举。可在分支、车间等设机构；调解员为本企业人员，聘期至少1年，履职占工时按正常出勤。机构还负预警、制度建议、监督履约、记录归档、培训统计职责；企业提供场所经费。严重失职调解员可解聘，未建机构且争议频发造成重大影响可被通报。（PDF417–419）

企业调解须双方同意，口头申请当场记录，受理范围内3个工作日受理，通常不公开，双方要求公开除外；一般自受理15日结束，双方可同意延长。法律另规定自收到调解申请15日未达协议可申请仲裁，不能因企业延长程序阻碍法定请求。协议写明请求、结果、履行期限方式，由双方签盖、调解员签名和机构盖章生效，一式三份。（PDF413、418–419）

| 文书/途径 | 书载效力与限制 |
|---|---|
| 和解或调解协议 | 对双方有约束力，不当然等于可直接强制执行的仲裁调解书；不履行可仲裁；合法且无新证据时可据调解协议裁决 |
| 特定给付调解协议 | 欠薪、工伤医疗费、经济补偿、赔偿金约定期限未付，劳动者可持协议申请支付令；督促程序终结后的路径见ch15 |
| 调解协议仲裁审查 | 生效15日内双方共同申请；提交协议、资格身份及相关证据、送达资料；受理后5日结束，特殊可再5日 |
| 不予审查/不制书 | 非范围、非管辖、超期、确认劳动关系或已经司法确认的不受理；违反强制规范、侵害公共/第三人权益、疑似造假、非自愿、内容不明等不制调解书 |
| 仲裁调解书 | 仲裁员签名并机构盖章，双方签收生效；送达前反悔或调解不成应及时裁决；部分请求可先出调解书 |

表据PDF413、419、428–429。审查申请送达前可撤回，撤回或不制书终止审查。直接申请仲裁者可受调解建议，但不同意则依法受理；庭前委托调解须双方同意，10日不成应开庭。企业调解规定引用旧办案规则第10、54条，书中并列新版已经重新编号，使用应核对应条文，勿照搬交叉条号。

## 时效、办案期间及送达

普通仲裁时效为知道/应知权利受侵害起1年；存续期间拖欠劳动报酬不受该普通期间限制，关系终止后1年内申请。向对方主张、向有关部门救济、对方承诺履行构成中断重新计算；不可抗力或正当理由（如法定代理人未确定）中止，原因消除继续。协商、调解失败或不履行协议的具体节点，另见企业协商规定第31条列项；保存每次请求和回应证据。（PDF414、419、424）

| 节点 | 书载期限/结果 |
|---|---|
| 申请补正、受理/不受理、组庭通知 | 补正当场或5日一次告知全部材料并出回执；受理通常5日；组庭及通知受理后5日；不受理/逾期的诉讼路径另核 |
| 申请副本、答辩与回送 | 受理后5日送副本；被申请人10日答辩；收到答辩后5日回送，不答辩不阻程序 |
| 管辖异议、反申请 | 答辩期满前提出；反申请5日决定，可合并；答辩期满后反申请另案申请 |
| 回避 | 通常开庭前，事后知悉最晚辩论终结前；3日决定；决定前暂停参与，紧急措施例外 |
| 开庭及延期申请 | 提前5日书面通知；正当理由提前3日请求延期，由机构决定 |
| 增减变更请求 | 增加或变更在举证期届满前提出，给予对方答辩期，明确放弃除外；逾期另申请 |
| 结案 | 受理起45日，复杂经批准可延15日并书面通知；部分事实清楚可先行裁决 |

据PDF415–416、423–427。**计时不可混用**：2017办案规则第80条明确其“三、五、十日”为工作日，“十五、四十五日”为自然日；此定义不要擅自扩展到所有法律、法院救济期限。（PDF429）

追加当事人、补正、增加变更请求、合并反申请、移送等触发相应重算；中止审理、公告送达不计入。死亡待继承人、行为能力变化待代理人、单位终止待承继、不可抗拒事由、待其他案件/工伤认定/评残鉴定等可中止并书面通知。法院因仲裁逾期立案，仲裁终止；未起诉仍继续处理。（PDF426）

送达须留回证并记签收日期；停业无法送达且劳动者10人以上，或拒收者，依法留置张贴并拍照录像，经过3日视送达。简易送达可用电话短信邮件等，**不包括调解书、裁决书**；开庭通知未经确认又无已收证据，不可按撤回或缺席裁决。（PDF424、427）

## 举证、庭审、简易与集体案件

主张者举证；单位掌握管理的相关证据应提供，否则不利。规则未明确者可按公平诚信和举证能力分配；客观不能自行取得可申请调查，调查人员至少2人并出示证件介绍信；其他证据程序参照民事证据规则。逾期证据需解释，可能不采或采纳并训诫。鉴定先由申请方垫付，最终原则由结果不利方承担，不明则申请方承担。庭审应调查质证辩论、征询最后意见，记录错误当庭申请补正，不准补正也须记申请；未经许可不得录播传播。（PDF413、415、423–426）

**撤回边界**：主动撤回后再申请应受理；收到书面开庭通知却无正当理由不到庭/擅退，按撤回处理后再申请不受理。被申请人无故不到庭可缺席裁决。（PDF425）

简易处理适用于事实清楚争议不大、标的不超过本地区上年度职工年均工资或双方同意之一；涉公共利益、重大影响、被申请人下落不明等不得简易。经被申请人同意可缩短取消答辩，仍保障陈述；转普通程序不重算总仲裁期限。（PDF427–428）

10人以上共同请求或履行集体合同案件优先受理审理；共同请求推3–5代表，变更放弃请求、承认对方请求及和解须被代表人同意。集体合同由工会申请，无工会由上级指导推代表。一般三人组庭，集体合同按三方原则；符合简易条件可简易。一次告知组庭、答辩举证及开庭事项，可就近开庭并引入第三方调解。（PDF413、423、428）

## 裁决、救济与组织保障

先予执行适用于报酬、工伤医疗费、经济补偿或赔偿金，须申请、权义明确且不执行严重影响生活；劳动者可不担保，移法院执行。裁决按多数，不能形成多数按首席意见；文字计算或已裁却漏写可补正。（PDF416、427）

金钱终局按**单项裁决数额**不超过当地月最低工资12个月金额判断；包括竞业补偿、解除终止补偿、未书面合同第二倍工资、违法试用及违法解除赔偿等；执行劳动标准的工时休假社保争议另属终局。混有终局/非终局事项应分别制书，已混合的法院处理见ch15。劳动者不服终局15日内起诉；单位仅可在30日内向仲裁所在地中院依六种法定事由申请撤销；撤销后15日内起诉。非终局双方15日内起诉，逾期生效；生效文书不履行申请执行。具体送达和期间务必独立建表。（PDF416、427）

仲裁不收费。仲裁委员会三方等代表组成且单数，仲裁院为办事机构；一案一庭，组庭不合规定重组，记录人不能由本庭仲裁员兼任。仲裁员需法定资格、名册公告、培训考核；书载专职至少3名、辅助至少1名、一般聘5年、年脱产培训不少于40学时。禁止偏袒、谋利、伪造隐匿证据、私见受礼、拖延、泄密、在任代理本机构案件；违纪解聘后5年禁聘，辅助人员也受约束。正卷可依法查阅复制；裁决案卷至少10年、调解及其他至少5年；证章发放、收回公告由组织规则约束。（PDF414、419–424）

裁审衔接意见要求统一受案及适用标准、联席会议信息共享、疑难案例研讨培训；仲裁阶段发现转移藏匿财产风险，告知经仲裁向法院保全并转交材料。2020法律援助意见强调低收入、农民工、工伤及“三期”女职工；书载建档立卡贫困劳动者和请求报酬、工伤赔偿的农民工免经济困难审查，紧急集体案可先援助后补材料，机构协作并落实经费。援助范围和手续须核现行法律及地方标准，不能以历史政策直接断言资格。（PDF429–431；特殊保护见[ch13](ch13.md)）

## 书载案例：集体欠薪的要素式处理

第一批案例8（PDF442–443）：142人被欠薪并陆续解约。机构当天立案，在双方同意后取消答辩期，两工作日开庭；先核入职、工资标准、欠额、解约日期，无争议项签认，有争议项写理由，联合工会等调解，制作142份调解书，约生效10日内支付共145万元。此为典型案例的具体做法，不是所有案件的法定“两日结案”标准。**自编应用**：制作逐人要素表及授权清单，保留争议项，不以多数代表意见替代个体处分同意。
