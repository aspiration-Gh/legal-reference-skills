# 实务模块04｜就业促进、就业服务与人力资源市场

来源：《劳动和社会保障法律法规全书》2022年版，2021年12月第8版，ISBN 978-7-5216-1794-8，PDF第122–175页（175页仅留学回流人员调整工作办法尾部）。本模块按书载规范分组，并非源书章号。所述均为书载版本，未逐项核验现行效力；办理时先确定事件时间、用工地及主体，再查发布机关官方有效文本、修废信息与地方实施规则。期限、补贴额度和旧许可名称尤其不得直接沿用。

## 1. 就业权、援助与登记：先确定请求是什么

- **平等就业与自主择业。**《就业促进法》2015年修正版保障平等就业；招聘、职业中介不得歧视。性别限制仅能落在规定的不适合妇女的岗位，合同不得限制结婚生育；农村劳动者不得因进城就业受歧视性限制；残疾人、少数民族等有相应保障。病原携带者一般不得被拒录，医学鉴定且属于依法禁止的易传播岗位是例外。就业歧视可直接提起诉讼；就业服务、行政监管与民事损害责任应分别判断。（PDF第123–127页）
- **乙肝体检另有具体禁令。**2010年通知禁止学校和单位在入学、就业体检中要求乙肝检测、要求报告或询问携带情况；医疗机构亦不得提供相应体检检测。特殊职业须经卫生主管部门核准并公布，特定武装系统另依规定。评价肝功能可检ALT，正常者不得被强制追加乙肝检测；相关报告密封、本人拆阅。投诉按用工、招生、医疗行为分别找人社、教育、卫生部门；不得把自愿健康检查扩大解释为招聘条件。（PDF第150–152页）
- **援助资格须核地方认定。**就业困难包括身体、技能、家庭、失地、长期失业等原因，具体范围由省级规定；公益性岗位优先给符合岗位要求者。法定劳动年龄内家庭成员均失业的城市家庭，可向街道、社区申请；确认后应为至少一人提供适当岗位，建立台账、动态帮扶。取得失业登记不当然取得失业保险金，后者另核条件。（PDF第126、162、164页）
- **区分用工备案与就业登记。**2006年备案通知：招用、续签30日内，解除终止7日内；单位信息变更30日、注销7日；注册地与经营地不一致时到实际经营地备案。书载《就业服务与就业管理规定》则为录用30日内、解除终止15日内办理就业登记。两项对象和程序不宜混写，先核当地是否合并办理。失业登记原则上面向法定劳动年龄内、有劳动能力和就业意愿的无业城镇常住人员，携身份证明及必要的离职证明；重新就业、领取基本养老待遇、失去劳动能力、终止求职、连续6个月失联等触发注销。（PDF第122、164–165页）

## 2. 就业政策、资金与创业：把政策目标和给付条件分开

- **基础支持体系。**《就业促进法》将就业纳入发展规划，配置财政、税收、金融、失业保险、区域协作、城乡统筹、创业服务、培训和就业援助；专项资金由财政审计监督，企业应按规定提取并使用教育经费，特殊工种须具备相应职业资格。政府、公共服务机构不得经营职业中介或向劳动者收招聘会费用。（PDF第123–127页）
- **规划的使用边界。**书载“十四五”规划是2021–2025工作指引，涵盖制造业、服务业、农业和小微企业扩岗，数字与灵活就业，县乡村和区域发展，创业融资、孵化、成果转化，高校毕业生、城镇青年、退役人员、农村转移劳动力、脱贫及困难群体，培训评价、公共服务、工资社保、安全与反歧视、失业监测和应急处置；组织、资金、评估保障贯穿实施。规划目标不等于个体可直接领取的待遇，须找到对应实施文件。源文本部分表格未呈现，不据空缺推定指标。（PDF第127–140页）
- **大学生创新创业。**2021年指导意见覆盖课程师资、导师和实践平台、免费孵化空间、科研设施共享、失败救助、成果确权和收益分配、赛事与信息服务。书载政府投资载体安排约30%场地免费给高校毕业生；创业担保个人最高20万元、符合条件小微企业最高300万元；10万元以下贷款及获设区市级以上荣誉的毕业生创业者免反担保。毕业年度个体经营税费扣减、小规模纳税人月销售额15万元免税等均为该时点政策，不能作为今日报价。（PDF第140–142页）
- **灵活就业。**2020年意见支持个体、非全日制和新业态；就业困难人员、离校2年内未就业毕业生从事非全日制等工作，按规定享社保补贴。指定时间场所售卖特定商品、个人从事依法无须许可的便民劳务，可适用免营业执照情形；经批准占道才适用道路占用费免征。另有租金场地、培训生活补助、零工信息、劳动保障和困难救助；2020年养老缓缴明确是阶段措施。（PDF第142–144页）

### 资金申请条件与凭证（2017年《就业补助资金管理办法》）

| 类别 | 书载条件、限度与证据 |
|---|---|
| 培训、鉴定 | 五类重点人员及符合条件企业职工；培训后取得相应证书。新招五类人员须签1年以上合同并在签约1年内参加规定岗位培训；初次技能鉴定合格证不含普通培训合格证。保存身份/就业创业证明、证书、票据；学徒、技师及项目制培训先备案，项目制保留计划教材、教师信息及全程授课视频。（PDF第144、146页） |
| 社保补贴 | 就业困难者单位补贴不含个人缴费；灵活就业原则不超实缴2/3，通常最长3年，首次核定距退休不足5年可延至退休。小微企业招毕业年度毕业生、签1年以上合同并参保，书载最长1年；离校1年内未就业毕业生灵活就业补贴最长2年。实行先缴后补，留合同、名册、缴费明细和灵活就业证明；不要与2020年对象扩展混同。（PDF第144–146页） |
| 公益岗位与创业 | 岗位补贴参照当地最低工资，通常3年，首次核定距退休不足5年可延至退休。首次创业且正常经营1年以上的离校2年内毕业生、就业困难者，依省级试点享一次性补贴。需岗位年限、工资账和营业经营证据。（PDF第145–146页） |
| 见习与求职创业 | 见习面向离校2年内未就业毕业生，特定地区可扩至中职；覆盖生活费、意外险、指导管理，留用率达50%以上可提高标准。留名单、协议、毕业证明、支付账、保险票。毕业年度困难家庭、残疾或获助学贷款等毕业生的一次性求职创业补贴，由学校初审公示、人社审核。（PDF第145、147页） |
| 服务能力与高技能人才 | 服务补助支持信息网络、招聘创业、孵化和购买服务成果；高技能补助支持基地、技能大师工作室，实施规划、专家评审和备案。标准由省级细化，地方获批新增项目另查依据。（PDF第145–147页） |

同一项目不得与失业保险待遇重复享受；基金不得用于办公宿舍建设、车辆、人员津补贴、“三公”、已安排预算或创业担保贴息等列明项目，但个人/单位依法领取补贴后的用途不受该条同样限制。分配采用基础、投入、绩效因素；中央预计数10月31日前下达、预算批准后90日内正式下达，省收款后30日内下达，地方本级预算对下级60日内下达。台账、联网核查、绩效、预算公开和责任追究贯穿全程；能共享取得信息不重复索纸件。书载公示含身份证号须特别核验后续隐私保护规则，不照搬公开完整号码。（PDF第144–148页）

**2018年创业担保贴息另案审查。**范围包括失业困难、退役、刑释、毕业生、去产能、返乡农民工、网商、贫困及农村自主创业人员；小微企业当年新招符合对象达职工25%，超过100人企业15%，并签1年以上合同。申请时本人及配偶除列明助学、住房等贷款和5万元以下消费贷款外不得有其他贷款；符合条件可续享但累计不超3次，特定荣誉或信用对象原则取消反担保。非贫困地区个人前两年全额贴息系书载版本，地方超中央部分自行负担、分账核算；原已生效合同仍按原约定。留资格、征信、合同、资金流、贴息台账；公示应防敏感信息泄漏。（PDF第148–149页）

## 3. 招聘服务：按活动确定许可、审查和留档

- **公共服务与经营服务。**《人力资源市场暂行条例》2018年版：公共机构免费提供信息、指导、介绍、援助、登记、毕业接收和流动档案服务；经营性职业中介须许可，信息发布、咨询、测评、培训和服务外包等业务开始15日内备案；分支、名称住所负责人变更及终止登记后15日内报告，许可决定20日。劳务派遣另用专门制度，服务外包不改变原劳动关系。（PDF第152–154页）
- **招聘真实性与个人信息。**求职者如实提供岗位相关经历；用人单位如实披露内容地点、条件、报酬、职业危害，禁止扣证、索财、虚假招聘及违法招用未成年人。中介须核招聘简章、营业设立文件、经办人身份和委托书；现场招聘会有方案、应急与安全措施，大型活动另核许可。信息发布建立审查、投诉制度，保守商业秘密和个人信息；一般服务台账至少保存2年，公示项目收费及监督电话。（PDF第153–154、159–163页）
- **网络招聘加严。**《网络招聘服务管理规定》2021年施行，经营机构须有人力资源服务许可并注明网络招聘，涉及电信经营另获许可；首页持续公示证照，自行终止提前30日公示。不得设置违法户籍地域身份限制；个人信息保护至少每年自查，出境另核数据规则。平台核验入驻机构证照、建档并更新；招聘与服务信息自服务完成起至少保存3年，不能用一般2年台账替代。（PDF第155–158页）
- **纠错和责任。**无许可职业中介可被关闭或停止，没收违法所得并罚1万–5万元；未备案、未报告、未明示、未存台账等有责令改正和拒改罚款。虚假或违法服务可能罚款、吊证并承担民事责任；网络平台身份核验、信息保存另衔接电子商务规则。书载就业管理规定还要求中介不成功退服务费，违法体检、登记不及时等另有罚则。不同规范处罚并列时须按行为、层级及适用时点核验，不能直接叠加。（PDF第127、155、157–158、163、165页）
- **历史人才市场分支。**《人才市场管理规定》书载2019年修正版适用于中专以上、专业技术或管理人才：机构5名以上具资格专职人员；许可20日、获准延10日、决定后10日送证。档案、政审、职称、转正工龄、毕业接收等人事代理有授权边界，须委托合同；重点工程、涉密、未满轮换期及受审查等人员流动有特别限制。第29条无培训合同按服务年限每年递减20%收费为历史书载，须核劳动合同法及后续效力，不可据此直接索赔。（PDF第165–168页）
- **外商投资机构。**人才中介与职业介绍各有书载规定：先登记后许可，投资主体、人员场所制度、外文材料中文译本、业务范围与报告分别审查；常驻代表机构、境外商会不得借身份经营中介。人才中介对外招募涉密、公务、受审查等人员有排除；分支及指定变更15日内报告。2007年补充规定曾取消港澳服务提供者合资股比限制并允许独资，须核服务提供者资格及其与2019年文本关系。（PDF第168–172页）

## 4. 易遗漏的特殊制度

- **劳服企业产权。**1997年规定先看投资、借贷、无偿资助的约定；无约定再按来源分类。主办扶持资产、借贷形成资产、公益金、个人投资及收益分开；税惠形成资产以1993年7月1日为分界，有专门用途从规定，否则按投资和劳动积累比例。费用已抵足净值、国有资产继续有偿使用、担保代偿形成债权均影响归属。清产核资、税务核实及劳动/国资登记、纠纷调解裁决和行政救济是书载路径，应核现主管机关。（PDF第172–173页）
- **共享用工。**2020年通知仅指企业安排、劳动者同意的余缺调剂；劳动者自行兼职不属该通知。不得再次转派本单位被派遣人员；期限不超原合同剩余期。企业合作协议约定岗位工时、报酬、保护、退回、工伤补偿、交通食宿，原企业与劳动者协商变更劳动合同，原关系保留。缺工企业结算报酬，原企业足额支付并参保、不得抽费；工伤责任由原企业承担，企业间可约补偿。保护义务违约可回原企业且不得拒收；不适应可协商退回，期满须接收；续用、解除及损害赔偿另核条件，禁止以共享规避派遣监管。（PDF第173–174页）
- **留学回流人员。**2015年创业通知将境外本科以上人员比照毕业生，凭学历学位及认证在创业地服务机构登记；创业指导、税费、融资、场地、档案社保等按条件衔接。1990年调整工作办法针对用非所学或缺基本条件，先本地区系统、后跨地区系统，调入调出协商并审批；公派/单位派出的培训费依有无协议分别处理，单位公派无协议按年递减20%的历史标准须另核。不要将旧人才争议机构、户籍程序当成今日统一入口。（PDF第174–175页）

## 5. 新就业形态的关系分流与证据（书载2021年指导意见）

先按用工事实分三类：符合劳动关系者签劳动合同；不完全符合但受企业劳动管理者签书面协议；自主经营、自由职业按民事关系。合作派遣须履行用工单位职责，外包等损害权益依法承担相应责任。政策要求保障正常劳动最低报酬、按时支付、合理休息、安全设施及恶劣天气保护，平台算法和进入退出、派单抽成、奖惩规则听取劳动者或工会意见、公示告知并可申诉；允许多平台就业，不得违法限制。社保、职业伤害试点、培训、公共服务分别核地方落实，商业险不当然替代法定责任。“合理节假日报酬”不应直接改写为所有平台人员均适用统一加班倍率。（PDF第149–150页）

**应用推演，非书中案例：**审查平台或共享用工时，收集实际管理指令、账号与派单规则、排班奖惩、报酬流水、劳动合同及企业合作协议，再区分关系认定、补贴行政申请、信息保护投诉和劳动/民事救济。广告有歧视条件时保全原文、投递资格、拒录理由与体检要求。规范正文未附可重构的裁判案例；以上证据清单为自编实务建议，编者仅作资料分类，未发现独立论证框架。
