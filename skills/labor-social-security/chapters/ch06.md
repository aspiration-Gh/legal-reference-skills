# 实务模块06｜残疾人就业、再就业与跨境就业

来源：《劳动和社会保障法律法规全书》2022年版，2021年12月第8版，ISBN 978-7-5216-1794-8，PDF第189–213页；189页自残疾人就业条例起，213页止于短期工作程序第六项第（二）目。末项程序跨批续载，本模块不声称覆盖其全文。所述为书载版本，非源书章号；未作现行效力逐项核验，须按事件时间核对官方有效文本、修废、过渡及地方规则，尤其保障金、税惠、旧就业许可和旧贷款政策。

## 1. 残疾人就业：义务、税惠和采购资格分别判断

**就业保障底线。**2007年《残疾人就业条例》适用法定就业年龄、有就业要求、从事有报酬劳动的残疾人。单位按比例安排适当岗位，比例不得低于职工总数1.5%，具体看省级；跨地区招用计入，未达比例缴保障金。集中使用单位全日制残疾职工须占25%以上。签劳动合同或服务协议，提供适合身体条件的工作与保护，不得在晋升、职称、报酬、社保福利上歧视，进行岗前在岗转岗培训。（PDF第189–190页）

政府开发公益岗位，支持集中就业、创业、农村生产、税费信贷和同等条件采购；残疾人就业服务机构免费提供信息、培训、职业心理咨询、适应评估、康复、指导介绍和单位支持，委托下办理登记统计，技能鉴定另需批准；劳动争议可依法寻求法律援助及残联支持。资金贪挪、虚报人数骗税、拖欠保障金分别追责，不能以缴金代替在职残疾劳动者权益保护。（PDF第190–191页）

### 增值税即征即退：2016年政策及书载2018年修订管理办法

- 单位、个体工商户安置比例至少25%且至少10人；盲人按摩机构人数门槛5人。每位签至少一年合同/服务协议，按月足额缴规定社保，通过金融机构按月支付不低于当地月最低工资的工资。每人每月退税限额为当地月最低工资4倍。残疾证或残疾军人证1–8级，精神残疾人须有劳动条件意愿。特殊教育学校自办、学校管理且收入归校的实习企业有特别条件，可计入符合条件在校学生；其申请材料中社保和工资凭证另有豁免，须核该专门分支，勿推广至普通企业。（PDF第191–193页）
- 纳税信用C、D不得享受。符合范围的货物、加工修理修配、现代生活服务收入须占增值税收入至少50%，文化体育娱乐、外购货物直销及委托加工货物销售等排除；优惠和非优惠销售额分开核算，否则不享受。同其他列明就业增值税优惠择一，不累加，选定36个月内不得变更。（PDF第191–192页）
- 首次备案留表、证件与身份副本，精神残疾人另留本人声明及监护人证明；变化15日内备案。退税提交申请、声明、社保明细、银行工资表并留存备查。新增人员次月计入、减少当月扣除；月限额按人数乘最低工资4倍，期间相加，还受当年实缴税额约束，只能本年度前后期结转，不跨年。不能提供备查证据可追缴；不符条件或骗税追缴涉期退税并自发现当月起36个月停享。（PDF第192–193页）

### 就业保障金：2015年办法的独立口径

计入安置人数须在编或签至少一年合同/协议、实发工资不低于当地最低标准、足额社保；残疾证1–2级或残疾军人证1–3级，一人按两人计，跨地计入。书载公式为“（上年职工数×省级比例－上年实际安置人数）×上年职工年均工资”，差额可为非整数；季节工折年均，派遣人员书载计派遣单位。在职人数、工资总额、安置审核与税惠口径不能互换。（PDF第193–194页）

单位按当地时限申报上年安置人数，未申报视为未安排；同时申报职工人数、年均工资并确保真实性，征收方可催报追缴。书载一般按月缴纳；注册三年内、20人及以下小微企业免征属旧政策，今日是否减免、分档及工资基数封顶均需另核。不可抗力等重大直接损失可申请减免或缓缴，书载减免上限一年应缴、缓缴最长六个月。欠缴经警告限期后仍不缴，书载自欠缴日起按日5‰滞纳金，使用前重点核后续规则。（PDF第194–195页）

保障金缴地方国库，预算用于培训康复、服务、设备支持、辅助性就业、创业及社保岗位补贴、超比例奖励、困难生活救助等；机构正常经费另由财政统筹。购买服务依法采购，收支和减缓缴名单公开；擅减、隐瞒坐支、截留挪用、违规缴库使用及失职分别追责。（PDF第195–196页）

### 政府采购：2017年通知

福利性单位同时满足比例25%、至少10人、一年以上合同、规定社保、银行支付不低于最低工资，以及本单位产品/工程/服务或其他福利性单位货物（排除使用非福利性单位注册商标货物）条件。参与采购交规定声明函并对真实性负责，不得要求另交证明声明内容的材料；中标成交同步公告声明。视同小微企业享预留份额、价格扣除，已属小微不重复享受；非公开招标须法定报批，协议供货、电商专栏及地方细化支持另核。采购声明与退税、保障金申报互不替代。（PDF第196页）

## 2. 再就业历史政策：贷款与改制分别溯源

**2002年下岗失业小额担保贷款办法。**年龄60岁以内、健康诚信、有技能、自谋职业或合伙组织就业、自筹不足、担保机构承诺担保，并持旧再就业优惠证；按个人申请、社区推荐、劳动审核、担保审核、银行核贷办理，材料齐全后书载三周答复。金额一般约2万元、期限通常不超2年，可经担保同意展期一次不超1年；微利社区服务等项目全额贴息、展期不贴。担保余额不超基金存款5倍、担保费不超本金1%由地方政府承担；贷款不良率或担保代偿率达20%有暂停及恢复机制，银行服务、资金专户独立核算及财政审计另受监管。不得把该历史额度与2018、2021创业贷款额度拼用。（PDF第196–197页）

**2002年主辅分离辅业改制分流办法。**针对国有及控股大中型企业，使用非主业、闲置一年以上、政策关闭破产企业有效资产等“三类资产”，改为独立核算法人、产权逐步多元；书载税惠须安置原富余人员达30%并变更/签劳动合同等，三年免所得税为历史扶持，须核当时认定。（PDF第197–198页）

资产定价损失核销产权变更依法审批，净资产可按程序付解除补偿，不足原主体补足；剩余可出售、租赁、入股、转债，土地用途与有偿/划拨手续单独审查。清理债务、工资医疗集资及社保欠费，不得逃废债。转入非国有控股原则解除原合同、支付补偿，补偿转股债须自愿；国有控股可依法变更主体、工龄合并。新或变更合同期限书载三年以上、工商登记后30天内完成，及时接续社保。方案由职代会讨论，分流安置及其资产事项须审议通过，否则不得实施；中央企业联合批复与属地劳动认定、地方程序分别办理，接续档案组织关系，骗惠侵占国资追责。（PDF第198–199页）

## 3. 对外劳务合作：资格、合同链和现场救济

书载2012年条例适用于经营性组织人员赴其他法域为境外企业或机构工作，境外企业机构个人不得在境内直接招人外派。对外承包工程、海员（不含渔业船员）另循专门制度；赴港澳台参照，特定目的地须另批。（PDF第200、204页）

- **主体与风险金。**省级或设区市商务批准；书载企业法人、实缴资本至少600万元、3名以上熟悉业务管理人员、内部及应急制度、法定代表人无故意犯罪记录，20个工作日审查。登记后5个工作日内缴不少于300万元备用金或等额保函，拒担/无力承担退服务费、报酬、赔偿及紧急救助等时使用，用后20个工作日补足。严禁借牌、旅游商务留学名义外派、赌博色情工作。（PDF第200–201页）
- **合同链。**企业先核境外雇主、项目、当地法和外劳许可，不得与境外个人订劳务合作合同。合作合同载岗位地点工时休息、期限、报酬社保、保护培训生活、居留许可、保险、解约补偿、应急救助和违约。再与人员签服务合同；若已建立劳动关系则签劳动合同并载同等权益。服务费依价格规定，劳动合同对象不得收服务费，所有人员均不得收押金或财产担保；如实告知及风险提示。相关合同副本及名单书载10个工作日内备案，协助其与境外雇主签确立劳动关系合同并保证权益条款一致；该期限所在文本有错序，实办须回核。（PDF第201–202页）
- **出境与在外管理。**安排职业技能、安全、语言、当地法和习俗培训，否则不得外派；购买人身意外险，约定雇主购买除外；办出境、协助居留工作手续并报使领馆。同一目的法域超过100人须随行管理；跟踪工作生活、应急预案及突发事件报告，服从依法作出的避险安排；停止营业仍须妥善安置并报方案。（PDF第201页）
- **权利受损。**实际待遇不合约定，企业应协助向雇主追履约赔偿；未得应有赔偿可要求企业相应赔偿，企业不协助可直接向企业要求；隐瞒或虚假信息造成损失由企业赔偿。违反当地法另协助依法维权。可向商务及有关部门投诉、通过使领馆合法有序反映；政府提供信息、预警、培训服务与应急协同，不等于为商业履约兜底。（PDF第202–203页）
- **责任分层。**借牌、假名义和违禁活动可吊证没收；缺培训、保险、随行管理责改拒改后企业罚5万–10万元、负责人1万–3万元；缺合同、违法雇主、隐瞒信息或不处置应急等罚10万–20万元、负责人2万–5万元，严重可吊证；备案、预案等另有罚则，合同必备条款拒补可升入更重分支；违法收费、刑事线索及监管失职另处理。（PDF第203–204页）

## 4. 入境就业与港澳台就业：身份和实际活动先于证件名称

**书载外籍就业管理规定（2017年修订）。**针对未取得定居权、境内有报酬劳动的外籍人员及聘用单位，外交特权豁免人员除外；岗位须特殊需要且境内暂缺适任者，年满18、健康、必要技能经历、无犯罪、有单位及有效旅行证件。普通路径为入境前许可、Z签证、就业及居留证件；学生、实习、随行家属及其他签证不自动获得就业权，特殊情形须审批变更。书载专家、海上石油不上岸及批准营业演出等有免办分支，协议合作项目和常驻代表等免许可证书但仍办就业证，须结合后续工作许可制度核验，不能仅凭旧证名办事。（PDF第204–206页）

申请保留履历、意向、聘用理由、技能资格、健康及单位证明，主管审批与无主管/特定投资企业直接申请分流。书载入境15日内办就业证、30日内办居留；合同最长5年，续聘在届满前30日内申请，批准变更后10日办居留变更；单位、职业、区域应与许可一致，变单位或职业区域触发变更/重办，解除及时报告交证。工资不低于当地最低标准，工时休假、安全社保按规定，争议循劳动裁审；年检、遗失补证、非法就业和伪造证件另有责任。禁止个人和个体经济组织聘用等旧条款、已引用旧出入境法的罚则须重点核验。（PDF第206–207页）

**港澳台书内已有纠偏。**2018年通知明确7月28日起取消就业许可，8月23日起不再受理，旧证2019年起停止使用；居住证或往来通行证等可办业务，营业执照、合同、工资、社保记录作就业证明，纳入就业失业登记与创业服务。故PDF第160页仍载“办理就业证”不能作为后来案件要求。（PDF第207–208页）

**优秀外籍毕业生（2017年）。**境内高校硕士以上留学生或境外知名高校硕士以上、毕业一年内的外籍毕业生，可按该文件放宽无工作经历；须成年健康、无犯罪、成绩平均80分或等级B+/B以上、无不良记录、专业对口单位，薪酬原则不低当地城镇单位在岗平均工资及有效证件。申请还需公开招聘满30天证明、学历学位成绩等；境外毕业生可免在校无不良记录证明。首次就业证一年，续聘审批最长5年；实缴个税低于意向薪酬应税额或拟薪酬不达标准，不予延期，另受配额管理。不得推广为所有外籍本科应届生通道。（PDF第211–212页）

**短期工作（2014年试行程序，本批仅节选）。**技术科研管理指导、体育试训、影视广告、时装及营业演出等，停留不超90日进入短期工作路径；配套设备安装维护、中标项目监督、分支短期任务、体育赛事、特定义工或非营业演出等另分M/F签证，不能把“90日以内”一概当免许可。超过90日的列明类别转一般就业程序；演出由文化部门批文及工作证明，其他由人社许可及工作证明，多省工作向境内合作方所在地申请。按书载办理邀请、Z签证及必要居留；工作不超30日按证明和签证停留，超过30日办90日工作类居留，签证注明入境30日内办手续。免签安排不免该文件工作证明及Z签证要求；任务取消通知审批机关，证明到期不延期。第213页后续事项不在本批，不用该节选形成完整办事清单。（PDF第212–213页）

## 5. 历史境外就业中介：与劳务合作制度衔接待核

2002年规定是境内提供境外就业中介服务的独立旧制度，书载许可有效3年、备用金至少50万元、省级初审并征公安同意后上报、60日答复；领证30日内登记、登记后10日内备案。业务含信息、推荐、培训、公证出境、代社保及维权，核验境外雇主开业资信及外劳许可，签服务协议并确认劳动合同，报备10日无异议后出确认书。禁止无证转包、非法出入境、违法职业，广告审批、公示收费、分支许可、变更、期满前90日换证及年审均为书载路径。（PDF第208–209页）

备用金用于机构责任损害赔偿、罚款罚金，专户监管；无力履行裁判可申请动用、拒履依法执行，不足不免民事责任；用后60日补足，否则停业。解散破产或注销后的领取条件书载2年无投诉诉讼，须连同清算规则核查。违规注销的负责人3年不得从事；无证、虚假、未尽核验签约、未备案、假证明及广告另罚并担民责。该规章明文不适用内地居民赴港澳台中介，而2012年劳务合作条例对此参照适用，证明二者范围不同；今日审批整合、废改及主管分工必须回核，勿并列要求申请两套旧许可证。（PDF第209–211页）

**自编应用推演与证据。**残疾员工同时涉保障金、退税、采购时建立三套人数口径核对表，留合同期限、到岗、残疾证、工资银行流水及社保月明细；外派欠薪时先核组织者资质、真实雇主、合同链、收费凭证、工作许可、培训保险、现场工时与求助记录，再选商务投诉、合同索赔或劳动争议路径。以上为自编应用建议；该范围没有独立裁判案例。编者资料分类、书载条文与这些推演应分别标识。书中明确省略的退税声明、采购声明附件未读取，不重构为原版表格。
