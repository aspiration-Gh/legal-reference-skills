# ch24 养老保险、年金与跨省迁移实务

> 实务模块编号，不是源书章号。来源：《劳动和社会保障法律法规全书》2022年版（2021.12第8版，ISBN 978-7-5216-1794-8），PDF657–694页，并关联PDF602–603、630–634。以下为书载规则及历史政策结构，未全量核验现行法。实际使用先查官方法律数据库、人社与财政主管机关、待遇地经办指南；**旧退休年龄、最低缴费年限、基数口径、费率、养老金数额、投资比例、迁移及补缴政策一律按事件时点和过渡规则重新核验**，不得据此直接承诺退休、补缴或收益。

## 一、先定身份与待遇制度（书载规则）

- **企业职工及个人参加职工养老**：社保法规定社会统筹加个人账户，书载达到退休年龄且累计满15年按月领，账户原则不得提前取，死亡余额可继承；因病非因工死亡有遗属待遇，完全丧失劳动能力有病残待遇路径（PDF602–603）。《实施若干规定》载不足年限可延缴；仅社保法实施前已参保且延缴五年仍不足的特定人员可一次缴至15年，不能推导出人人到龄自由补缴。未转居民而申请终止的，须书面告知转入权利及终止后果并本人确认；离境定居与丧失该法域国籍分别判断（PDF630–631）。
- **机关事业单位**：《改革决定》（国发〔2015〕2号，PDF657–659）适用于规定单位及编制内人员，2014年10月1日起实施。改革前已退休按原标准并参与调整；改革后参加工作按新办法；改革前工作改革后退休按新基本待遇加视同年限过渡性养老金，另有离休安排。书载单位20%、个人8%及工资60%/300%边界是历史定位，不是现行报价。基本养老与企业基金分账，配套职业年金；同统筹范围机关间流动只转关系，跨统筹或机关企业间流动涉及账户及统筹基金转移，年限累计。
- **城乡居民**：《统一制度意见》（国发〔2014〕8号，PDF659–661）覆盖满16周岁非在校、非机关事业人员且不属职工养老覆盖的居民，原则在户籍地参加。个人缴费、集体补助、政府补贴筹资，困难群体可代缴；个人账户记入个人缴费及补助资助。书载待遇为基础养老金加账户养老金，60岁、累计15年、未领其他基本养老保障待遇为一般条件，制度建立时已到龄及距领取年龄不足15年有过渡安排。2018通知载基础最低88元/月（PDF685），只作历史调整记录；不能作为当前待遇，缴费档次、补贴和139计发系数亦须核验。

居民缴费期迁居可转全部账户储存额并累积年限，已经领取待遇则不转关系；死亡次月停发、余额继承，丧葬补助依地方安排。基金收支两线、独立核算、信息公开和年度资格核对不取消个人的查询权（PDF660）。

## 二、城乡制度衔接与跨省迁移（书载规则）

《城乡养老保险制度衔接暂行办法》及经办规程（PDF661–663）适用于参加两制度而需衔接者，已经按规定领待遇的不再办衔接。先归集职工养老关系并确定职工待遇地，再判断流向：

| 情形 | 账户和年限如何处理 |
|---|---|
| 到职工法定退休年龄，职工年限达到书载15年（含延缴） | 可居民转职工，居民账户全部储存额并入；**居民年限不合并、不折算为职工年限** |
| 职工不足书载年限，选择职工转居民 | 职工账户全部储存额并入居民账户，职工年限合并为居民年限；仍须达到居民待遇条件才领 |
| 同年度重复缴费 | 按月识别重叠，只计职工年限；退居民对应个人缴费及集体补助，不把政府补贴直接退个人 |
| 同时领职工与居民待遇 | 终止居民关系，退除政府补贴外账户余额；已领居民基础养老金须退，不退可依法抵扣 |

规程要求申请表、身份/社保凭证、参保缴费信息与联系函传递，转出终止关系、转入核资清重复、合并账户并告知；书载审核发函、原地信息资金划转、转入办结各15个工作日，不是一次申请后固定15日全部完成。办结信息保留备份；具体附件源书省略，不能重造为官方表格。

《城镇企业职工基本养老保险关系转移接续暂行办法》（PDF691–692）覆盖含农民工的企业职工参保人，已领取待遇不转。跨省累积年限和账户，未到领取年龄原则不以返乡中断就业退保。旧规则非户籍地新参保男满50、女满40建临时账户，获组织人社批准调动并建立劳动关系缴费者例外；这些是**书载迁移账户年龄而非退休年龄**，须核现行适用及特殊身份。港澳台身份不建该临时账户且待遇地末级分支不同，见[ch22](ch22.md)。

普通人员待遇地依次判断：关系在户籍地→户籍地；不在户籍地而当前关系地累计满10年→当前地；未满则回上个满10年的原参保地；各地均未满则归集户籍地。PDF692部分句序交错，上个满10年分支可结合PDF693承接和PDF634特别规则阅读，但出具个案结论前核官方正文。迁移转个人账户及规定比例统筹基金，不等于将单位历年全部缴费退给个人。

《2016若干问题通知》《2019补充通知》（PDF692–694）还应同时核查：

1. **视同年限**按当时工作地分省归属，多地分别认定；1998年前因客观历史资料不全不能提供月缴费信息的，结合缴费时间记录及档案认定，不能仅因系统无月记录删年限。
2. **临时账户**补缴此前欠费不改变其性质；再次流动可封存，待遇地统一归集。农民工返乡中断不消灭记录及计息。户籍地即使从未参保，也不能据此拒绝承担依法确定的待遇地归集责任。
3. **一次缴费3年及以上的迁移材料**：依发生在2016通知之前或之后分流；之前转出地提供承诺书，之后原则提供在补缴前已形成的有效法律文书，禁止事后补办。获准缓缴、征收机构依法责令补缴、特定退役士兵补缴各有材料通道。无法转的部分书面告知并协调，合规其余部分应转尽转；资料原则由转出地取得传递，不转嫁个人反复证明。
4. **重复领取**：职工制度内部可协商保留一个关系、清理其他并追回重领，账户余额不足再按规定比例从继续待遇抵扣；职工与居民重复适用终止居民及追回居民基础养老金的规则，不能混同清退口径。旧重复领取还要查发生时间。
5. **整建制与退役军人**：整建制跨省一般按统一规则，省级主导规模企业可依两省安排；退役养老关系登记、补助年限计入安置地实际参保及历史资金调整分别核查。线上转移、跨地数据共享、异常数据核查及造假清退均纳经办监督。

**书载请示答复压缩重构**：PDF694的2017复函针对特定地区请示指出，视同年限归当时工作地，不以工作地与参保地或户籍地一致为前提；离开整建制迁移企业的个人不能再套企业间特殊协商规则，应核其历史工作地、确定待遇地。此为书载行政复函事实与理由，非裁判案例，未增补当事人年龄、金额或处理结果。

## 三、企业年金与职业年金权益（书载规则）

《企业年金办法》（PDF663–666）建立在依法参加基本养老并履行缴费义务、企业有负担能力之上，自主设立且经集体协商、职代会/全体职工通过，方案报送后15日未异议生效；适用于试用期满职工。方案要有参保范围、筹资分配、账户、权益归属、管理、给付、变更终止及监督条款；修改重新民主通过并报送，终止清算不等于即时提现。

书载企业年缴≤工资总额8%，双方合计≤12%；当期单位缴费个人最高与平均≤5倍。个人缴费及收益自始归本人，企业缴费及收益可分期归属但最长8年；退休、完全失能、死亡、方案终止、非本人过错单位解除、单位违法导致职工解除、单位原因到期不续签等触发企业部分完全归属。不能把“未满8年离职”机械写成一律没收。经营亏损重组等可协商中止，恢复时补缴不超实际中止期间和金额（PDF664–665）。

新单位有企业/职业年金则转；无年金或升学参军失业则原机构或集合保留账户管理。达到规定退休年龄或完全失能可按月、分次、一次性领取或购商业养老产品；出境定居可本人要求一次付，死亡余额继承；普通离职不是提前取款条件。方案订履争议按集体合同规则，基金管理合同争议可仲裁或诉讼，受托资质与基金独立接受监管（PDF665–666）。

《机关事业单位职业年金办法》（PDF677–678）与基本养老范围一致，书载单位8%、个人4%，缴费基数一致。个人实账，财政全额供款单位缴费先记账并在退休前财政记实，非全额供款单位实账；市场投资部分按实际收益。换工作随新单位年金制度转移，否则原账户续管。依法退休后按选择购买商业养老产品或按计发月数月领至发完，选择后不更改；不是照搬企业年金任意一次性领取。出境定居、在职死亡另有一次支付/继承规则，提前取受限；经办、监管与仲裁申诉路径按主体区分。

## 四、基金治理、资格与投资监督（书载规则）

下列是不同资金制度，不能把一套上限、报告期限或管理费通用于全部基金：

| 规范、来源 | 决策与执行审查 |
|---|---|
| 企业年金基金管理办法，全十章，PDF666–675 | 一个计划一个受托、账户管理、托管人，可多个投资管理人；受托与托管、托管与投资不得同一主体。法人受托可具资格兼账户/投资但需业务人员隔离，理事会职工代表≥1/3、决议全体≥2/3通过，理事异议记入会议记录关系免责，签约全体签字。理事会不得营业或从基金提管理费。账户管记录和待遇，托管管资产估值清算及投资监督，投资人管投资与准备金。禁止混同、挪用及保本保证收益。 |
| 企业年金管理机构资格认定暂行办法，PDF675–677 | 按受托、账户、托管、投资分别审治理、专业人员、系统设施、风控及违规记录等条件，托管有书载净资产门槛。申请补正一次告知、专家评审及必要现场检查；调查期间不受理；拒绝说明理由并告救济。书载资格3年、到期前3个月续展，虚假申请/骗取资格有禁入注销；当前资质须查主管机关公告，附件源书省略。 |
| 职业年金基金管理暂行办法，全七章，PDF678–685 | 省级/中央代理人集中行使委托并管账户；招标评选受托人，签约备案登记。一个计划一个受托、托管，可多个投资管理人；资质取自相应企业年金资格，兼任隔离。机关负责缴费及记实、转移、待遇申请，代理人负责归集与账实一致，受托配置监督，托管独立保管核算，投资人运营；更换后交接35个工作日，资金入受托户后25个工作日划投资户属书载程序。 |
| 基本养老保险基金投资管理办法，全十一章，PDF685–691 | 覆盖企业、机关事业、居民养老结余，先留待遇支付需要，由省级政府委托获授权机构集中运营，可部分直接投资；专业管理托管分离。受托选择监督机构，托管拒绝未成立的违法指令、对已成交违法指令即时报告，投资主体禁止内幕、关联输送、违规承诺收益及无限责任；职责终止妥善交接。 |

三类均强调基金财产独立：不纳管理主体破产清算，不用固有债务抵销，非基金自身债务原则不得强制执行。管理机构应依合同和法定职责报告、对账、接受查询与检查，商业秘密及举报信息受保护；违反安全或不改正可暂停新业务、终止资格职责，损失赔偿与刑事责任另论。基本养老基金管理“管理费扣减”不能误写成所有机构同额行政罚款（PDF690–691）。

**投资与费用核对表的使用方法**：企业年金PDF672–674、职业年金PDF682–684、基本养老基金PDF688–690分别载投资目录、流动性底线、固收/权益上限、集中度、被动超比例整改、关联产品同意、费率和准备金。企业年金旧书权益30%等数字不可直接作为今天交易规则；职业年金按组合与计划双层限制，专门组合有例外；基本养老允许限定重大项目/重点企业股权，股指和国债期货限套保。准备金属于风险缓冲，不构成对个人保本承诺，年金投资人管理费提取准备金与基本养老受托按净收益提取是两套规则。

企业年金计划区分单一、集合，加入集合书载满3年方可按合同退出；变更重新备案、终止清算、审计及保留账户接续。企业年金与职业年金均有连续运作满三个会计年度、管理人终止时审计，但报告期限和日/工作日口径不同；职业清算要求计划终止后三个月完成，企业清算报告是在清算完成后三个月内提交，勿互换。季度、年度与重大事件报告应按角色建立日历，纳入权益单、资金划转、审计意见及整改记录（PDF673–674、683–684）。

## 五、自编实务应用与来源边界

**自编应用**：制作参保时间轴（省份、单位性质、身份、实际/视同年限、普通/临时账户、重复月份、补缴日期与依据）→确定退休/领取条件的有效版本→归集待遇地→比较延缴或跨制度选择→核企业/职业年金已归属权益→取得经办书面决定并走复核行政救济或对应合同争议。证据包括人事档案、调动及安置文件、逐月缴费明细、工作地证明、补缴前法律文书、年金方案民主程序与备案、归属及转移记录，不以口头“交够了”替代。

**编者整理**：本段按规范、通知及请示答复汇编，以上矩阵和时间轴为自编应用；仅2017复函作书载实例，无虚构裁判。源书省略机关养老计发月数表（PDF659）、城乡衔接表单（PDF663）、年金资格申请格式（PDF677）、一次性缴费承诺书（PDF694），未读不存在于源文的附件，不据记忆填补。跨页交错疑点在审计逐项记录。经办记录、先行支付及综合救济见[ch22](ch22.md)，救助、公积金见[ch23](ch23.md)。
