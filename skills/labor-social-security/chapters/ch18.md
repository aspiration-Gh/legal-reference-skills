# ch18 公务员管理：申诉、考核、职级、退出与分类管理

来源：《劳动和社会保障法律法规全书》2022年版，2021年12月第8版，ISBN 978-7-5216-1794-8，源书“三、人事篇／2.公务员管理”后段，PDF516–539页。模块编号属实务编排。本批末页仅至《行政执法类公务员管理规定（试行）》第16条，后续条文不在本模块读取范围，不能据此宣称覆盖该规定全文。

**下文标“书载”的规则属于历史文本提炼；使用时核事件时间、人员身份、管理权限和官方适用版本，特别核退休改革、监察制度、职级改革与新旧法衔接。**本范围未见编者案例；考核登记表、辞退和辞职附件为原书注明“略”，没有重建为原件。

## 1. 申诉：区分任免机关人事处理和监察处理

书载《公务员申诉规定（试行）》（2008年，PDF516–520）处理处分、辞退或取消录用、降职、不称职考核、免职、不批辞职或提前退休、未依规定确定或扣减工资福利保险等。领导成员及法官检察官等特别规则另查；聘任合同争议不能当然纳入此路，见[ch16](ch16.md)。

| 环节 | 书载期限与条件 |
|---|---|
| 申请复核 | 知道人事处理起30日内，向原机关书面申请；复核决定前不得同时申诉 |
| 申诉、再申诉 | 复核决定收到起15日内申诉；可不经复核，在知悉处理起30日直接申诉；收到申诉处理起30日再申诉 |
| 受理与补正 | 收到申诉书起30日内决定并书面告知，不受理说明理由；材料缺失限15日补正 |
| 审理 | 原机关收到复核申请起30日决定；申诉再申诉受理起60日，复杂延长不超30日 |
| 例外与效力 | 不可抗力等正当理由经批准延限；复核申诉不停止原处理，不能因维权加重 |

申请一般由本人提出，丧失行为能力或死亡可由近亲属代为；书载还有限制委托代理的条款，不应未经查新用于现案。材料需请求理由、原处理及复核决定、送达证明；管辖按所在机关、同级主管部门、县乡或垂直管理体系分别确定。原书涉及旧行政监察机关的管辖表述已需更新。（PDF516–517、519）

申诉公正委员会审事实证据、法律适用、程序权限及是否显失公正，调查至少2人并回避；事实不存在撤销，适用或处理不当变更，事实不清证据不足或程序权限违法重新处理。决定书送达、归档；书载公告送达60日、执行情况反馈60日等仅供历史对照。错误处理须纠正、恢复名誉或赔偿；不执行、报复或诬告须担责。（PDF518–520）

**官方更新已核：**[2022年《公务员申诉规定》全文](https://www.12371.cn/2022/12/28/ARTI1672214496365474.shtml)为2022年3月19日发布的修订文本。新增或调整的一案一委员会、管辖、应诉答辩和补正等须依新版核对；第12条规定复核逾期未决定，可在复核期满起15日申诉；第30条规定决定作出起7日内送达，第36条要求生效后30日内执行并书面告知。监察机关处理走监察机关复审复核，不能继续照抄旧行政监察申诉路径。上述是制作时专项核验，不代表其他规范已全量更新。

## 2. 考核：等次、年度与人事后果不能混算

书载《公务员考核规定》（2020年修订，PDF520–523）适用于非领导成员公务员，领导成员另依干部考核规则。以职位职责任务为基础考德能勤绩廉，重政治素质与工作实绩；平时、专项、年度衔接。年度程序包括总结述职、必要民主测评、了解核实、领导评鉴、负责人或授权委员会定等，优秀公示不少于5个工作日，书面通知本人签署意见，登记表入档。优秀名额比例条文PDF521错行，涉及精确比例必须核官方原文，不据抽取文本直接核定职数。

- 优秀：工作实绩突出且满足政治、能力、作风和廉洁条件；当年嘉奖、晋升职级最低年限缩短半年，连续3年优秀记三等功、同等条件优先晋升。优秀应从平时专项考核好的人员产生。
- 称职以上：累计2年晋升级别工资一档，累计5年在对应范围晋升级别一级；计职务职级任职年限，其他资格同时具备才有晋升资格；享年度考核奖金。
- 基本称职：诫勉、检查限改，当年不计考核晋级晋档年限和职务职级年限、下一年不得晋升职务职级、不享奖金；连续2年组织调整或处理。
- 不称职：不计相应年限、降低一个职务或职级层次、不享奖金；连续2年辞退。对不称职可复核申诉。
- 不定等次：通常不计相应年限、不享奖金，连续2年视情调岗；不是直接等同“不称职”。（PDF521–522）

试用期参加年度考核只写评语不定等次；调任转任由现单位定等、原单位提供资料；挂职援派一般由当年工作半年以上单位考核，学习专项任务由派出单位考核并取表现材料。病事假累计超过半年不定等次；立案未结不写评语不定等次，结案不处分或警告后按规定补定。警告当年不得优秀，记过当年以及记大过降级撤职当年和次年只写评语不定等次；多种处分组织处理并存按影响较重规则定结果。无正当理由经教育仍拒绝考核可直接不称职。主管部门每年按不少于机关总数10%核查，发现违纪线索移送。（PDF522–523）

## 3. 职务、职级、级别：待遇晋升不产生领导权

书载《公务员职务、职级与级别管理办法》（PDF523–525）与《公务员职务与职级并行规定》（PDF525–529）相互配套。级别由低至高为27级至1级；职级不具有领导职责，不改变工作职位和指挥关系。综合管理类为两级巡视员、四级调研员、四级主任科员、两级科员；其他类别另定。

职级设置须看机关层次与机构规格；中央、省、市、县乡的职级上限与比例不同，垂直机构、派出单位参照机构规格；领导班子和所属部门职数分开统筹，不能把全机关编制直接作为每层级分母。中央、省级及副省级机关的巡视调研比例，市县调研主任科员比例及内部比例详见PDF526；县乡密集比例段存在错行，核数必须取官方原文和已批准设置方案。设置审批备案、分级统筹及特殊调整均有权限限制。（PDF526–527）

书载最低年限：一级巡视员需任厅局副职或二级巡视员4年以上；二级巡视员需一级调研员4年以上；一级调研员需县处正职或二级调研员3年以上；其余自二级科员晋一级科员、到各主任科员、各调研员相邻层级通常为2年以上，并有领导职务折算入口。应逐项对照第18条，不可把“通常2年”作通用公式。要求相应年度考核均称职以上，期间每一优秀年度缩短半年，基本称职或不定等次年度不计。**达到最低年限不等于必须晋升**，仍受空缺职数、德才实绩、职责资历、推荐考察与审批约束。（PDF527）

晋升方案、推荐测评、考察了解、公示不少于5个工作日、按权限审批；处分组织处理影响未消、审查未结或其他影响情形不得晋升。不胜任、不称职、降职或撤职等依法降级。晋升领导职务后级别低于新职最低级别应补至最低，已在范围一般晋一级，但一级、三级调研员及一级、三级主任科员相当职级晋升有例外。乡科正职任职资历含副职、三级四级主任科员等法定累计路径，乡科副职通常需一级科员相当职级3年以上。（PDF524、527–528）

职级决定相应工资及地区部门住房医疗交通补贴社保待遇，兼任领导职务按就高；不因此享有同层级政治工作待遇，因公出差交通住宿、办公用房不挂钩。县处副职以上领导成员因换届不再提名、机构改革等转职级可依规定保留原待遇；因不适宜不胜任免领导职务不适用同样保护。超职数、放宽资格、擅改待遇可纠正或宣布无效并追责。（PDF528–529）

## 4. 辞退与辞去公职：理由、审批、交接和待遇分开

书载《公务员辞退规定》（PDF529–531）与《公务员辞去公职规定》（PDF531–533）规定如下。监察官、法官检察官、领导成员特别规则优先核查。

| 事项 | 辞退 | 辞去公职 |
|---|---|---|
| 触发条件 | 连续2年不称职；不胜任且拒安排；机构调整拒合理安排；教育后仍不守义务纪律且不宜开除；无正当理由旷工连续超过15个工作日或一年累计超过30个工作日 | 本人书面申请终止任用关系，不能以通知替代批准 |
| 限制 | 因公致残丧失或部分丧失能力、医疗期、孕产哺乳期等不得辞退；审计审查调查或司法未结暂缓审批 | 最低服务年限未满、涉密脱密、审计或重要公务未完且须本人处理、审查调查司法未结等不得批准 |
| 决策程序 | 核事实提建议、组织人事审核、任免机关集体决定，必要时先经济责任审计；县级以下由县级主管部门审核报县级党委批准 | 本人申请、人事审核并征求单位纪检保密意见、任免机关批准；县处副职或二级调研员相当以上同时报告个人事项，必要先审计 |
| 期限 | 决定后10个工作日内送达；通知送达后10个工作日内交接 | 收申请30日内审批，领导成员90日；批准后10个工作日内交接 |
| 后果 | 次月停工资，身份终止、职务职级自然免除；档案2个月内转递 | 批准次月停工资、免去职务职级，档案2个月内转递 |

拒不交接可撤销辞退或同意辞去公职决定并给予开除；辞去公职审批期间擅离职亦有开除后果。专项培训约定服务期未满，一般不得申请辞去公职；申请时支付违约金或履行相应义务，金额不得超过未履行部分分摊培训费，最高不得超专项培训费。不得照搬劳动合同规则。（PDF530、532）

辞退已参失业险者依规定享待遇，未参者领辞退费；此前连续工作满1年才自次月发，标准为对应基本工资。机关年限不满2年发3个月，满2年发4个月，其后每多1年增1个月，最长24个月；重新就业、服兵役、迁居境外、判刑、享基本养老待遇或死亡停发。机关在人事档案转出后15个工作日内拨付，机构按月发，困难时原机关发。辞退后涉密管理持续，再就业工龄按规定合并；辞去公职后再就业也有工龄合并规定。（PDF530–532）

辞去公职的领导成员及县处级以上领导职务者离职3年限制任职原管辖地区业务范围内营利组织及关联经营，其他公务员为2年直接相关业务限制；“原职务／业务”看离职前3年。限制期每年底报告从业，原机关核查，特定省级以上执法监管司法机关建限制清单。违规先责令纠正，拒改可没收违法所得、清退，接收单位处违法所得1–5倍罚款。退休者从业限制同时查公务员法第107条，不能把辞职细则机械扩大至一切退休情形。（PDF466、532）

## 5. 旧任免及分类管理的保留边界

《公务员职务任免与职务升降规定（试行）》（2008年，PDF533–536）以委任制为主，选任、聘任、法官检察官等另办；任职审核空缺与资格回避，集体决定并履手续，机关外兼职批准且不得领酬。免职有转任调出、辞职退休、非组织选派离职学习超一年等，降职须审理由并听本人意见。书载降职一般一层，级别超新职上限相应降，工作一年后表现突出、考察符合可再晋升；监督包括超编职数、任人唯亲、突击晋升等，免降职可申诉。其旧“非领导职务”序列和年限、劳动教养及自然免职表述仅供历史定位，须与后来的公务员法、职级并行及废改规则核对。（PDF534–536）

《专业技术类公务员管理规定（试行）》（2016年，PDF536–538）针对强技术性、低替代性的技术支持保障岗位；设置须主管部门确定范围，中央审批、地方省级审批后报备。旧通用职务11层，从一级总监至专业技术员；任一级二级总监及一级高级主管须正高，二三级四级高级主管须副高以上，一二级主管中级以上，三级四级主管及技术员初级以上；须专业资格、职数和考核条件，失资格或转其他类别应免职。不称职降一层，试用合格且获专业资格方定级。

其录用重专业能力，特殊专业可其他测评，部分职位可聘任；考核与资格评定衔接，初任业务在职和继续专业培训并行。企事业、人民及群众团体中副高满2年或正高专业人员可按调任规定进入四级高级主管以上职位；转其他类别通常专业类工作满5年并比照确定层次。工资津补贴、成果奖励、特殊津贴和人才项目需各依条件批准，擅扩设置、降标准、违规录任或改待遇须追责。（PDF537–538）

《行政执法类公务员管理规定（试行）》（2016年，**本批仅第1–16条**，PDF538–539）按对相对人直接实施许可、处罚、强制、征收收费检查等执行性强制性职责界定；设置范围及方案有中央、省级审批备案。旧职务11层从督办、四层高级主办、四层主办到两级行政执法员；职数及晋升年限另由主管部门规定，不可拿综合类表直接套算。晋升要求相应资格和任职期年度称职以上，不称职降一层，跨类别转任免原职。第17条以后未在本批，需继续查书后续模块及官方全文。

**官方更新已核：**[2023年两类管理规定公布全文](http://www.news.cn/politics/zywj/2023-09/14/c_1129864001.htm)确认2023年9月1日修订发布，专业技术类及行政执法类已调整为职级等管理制度。使用旧职务名称、资格门槛、交流年限及对应关系前必须查新版；不把2023年条号冒充书载条号。

**自编应用：**“考核基本称职所以立即辞退”“满2年一定晋级”“领导职位免除所以所有待遇归零”都不能直接成立。先取得历年考核与通知、任职职级批复、编制职数、处分影响期、安排岗位及拒绝证据、病假医疗和保护身份材料，再按对应分支判断；同时保存知道决定与送达日期以安排救济。范围录用见[ch17](ch17.md)，一般公务员法、监察处分、档案及合同人事争议见[ch16](ch16.md)。
