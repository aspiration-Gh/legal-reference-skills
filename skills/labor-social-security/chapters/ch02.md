# ch02 劳动关系基础、用工责任、工资税务与监察

## 来源、效力与用途

本模块取自《劳动法规全书》2022年版（2021年12月第8版）劳动篇综合部分：PDF57–65、69–95、104–105页；对应刑法节录、劳动法、个税法、企业组织及破产节录、监察及实施规定、监察员管理、1995年劳动法实施意见、诚信评价、违法公布和劳动听证规则。模块是按问题重组，不是源书章号。工会专门材料另见[ch03](ch03.md)，行政处罚、许可及救济总则见[ch01](ch01.md)。

以下均标示书载规则，不构成已核验的现行法律结论。实际使用时，先查行为和权利发生日期，再查官方法律数据库、人社与税务机关、司法机关及地方有效规范。旧劳动法条文与后来的特别法可能并存；不能机械采用书中60日仲裁期限、90日产假、44小时工时、试用随时辞职、期满不补偿、旧日工资折算或旧劳动能力鉴定救济。1995年文件引用的收容审查、劳动教养、免予起诉、已被替代法规和机构称谓，均须独立核验历史效力。书中无此范围的事实案例，下面操作步骤为应用推演；方括号条文主旨是编者所加（PDF56）。

## 识别关系与主体，建立事实清单

《劳动法》书收2018年修正文本适用于企业、个体经济组织与形成劳动关系者，以及机关、事业组织、社会团体建立劳动合同关系的劳动者（PDF57–58）。1995年意见第1–5点以组织成员身份、提供有偿劳动识别实际关系，说明工勤、企业化管理及合同制人员范围，并排除公务员及比照管理人员、现役人员、家庭保姆等；“个体经济组织一般雇工七人以下”属于历史表述，不能用人数规避用工义务。（PDF86–87）

先核单位登记或实际用工主体、签约方、招聘管理、考勤指挥、报酬支付、社保及劳动实际。机关、事业单位人员须先区分聘用、人事和劳动合同关系。没有书面合同不排除事实劳动关系；劳动合同未鉴证不能成为拒绝受理理由。勤工助学、长期借用、带薪上学、长病假、停薪留职、富余待岗、派至参股单位等有旧意见专条：劳动关系仍在的，合同与缴费原则仍由原单位承担，非在岗事项可协商变更；不得只凭“没有实际出勤”判断关系消灭。（意见第6–17、74、82–84点，PDF87、91–92）

平等就业与选择职业、报酬、休息、安全卫生、培训、社保和争议处理是劳动权利类别；劳动者亦有完成任务、遵守安全规程纪律和职业道德义务。劳动规章须合法，劳动者有工会组织、民主管理和平等协商权。禁止未满16周岁用工，文艺体育特种工艺例外仍须遵守专门规定并保障义务教育；16至未满18周岁是未成年工，不等于可安排任何劳动。（劳动法第3–15、58条，PDF58、61）

## 劳动合同的条件分支与旧规则识别

| 事项 | 书载判断要素 | 页码 |
|---|---|---|
| 成立、变更和无效 | 平等自愿协商一致、书面合同、期限内容报酬劳动保护等；违法或欺诈胁迫可无效，部分无效不当然影响其余；无效由仲裁或法院确认，不能任一方自行宣告 | PDF58–59；87–88 |
| 无固定期限及试用 | 劳动法旧表述为同单位连续10年以上、双方续订且劳动者提出；试用包括在合同期内且最长6个月。不得将法定解除条件包装成终止条件逃避补偿；必须联查劳动合同特别法的完整要件 | PDF59；87–88 |
| 单位过失性解除 | 试用不符录用条件须证明；严重违纪、严重失职营私舞弊致重大损害、被追究刑责分支分别取证。“重大损害”不能只看单位自订数字，旧意见要求结合企业规模、类型及程度判断 | PDF59；88、92 |
| 非过失性解除 | 医疗期满不能原岗也不能另岗；不胜任经培训或调岗仍不胜任；客观重大变化致不能履行且协商变更失败。书载提前30日书面通知、依法补偿，并核保护期禁限 | PDF59、89 |
| 裁员 | 书载破产整顿或经营严重困难条件；提前30日向工会或全员说明、提供经营资料、制定人员时间步骤补偿方案、听取意见并修改、向主管机关报告、公布办理解除；6个月再招优先原裁员 | PDF59、88 |
| 保护性限制 | 工伤职业病丧失或部分丧失能力、医疗期、孕产哺乳等限制非过失性解除及裁员；不是对严重违纪等所有解除的绝对豁免。期限届满的保护性延续须查特别法 | PDF59、88–89 |
| 劳动者解除 | 书载一般提前30日书面通知及强迫劳动、不付报酬不提供条件等随时通知；试用期规则需特别法校验。普通辞职不是必须等单位批准；违法解除造成损失须证明因果关系 | PDF60、88 |
| 期满、转制及补偿 | 旧意见的期满不补偿、固定工转制、生活补助、临近退休、15%工资性补贴、工伤期满不终止等均有特定年代背景；合并分立、重新签约不能机械当作关系重建或工龄归零 | PDF89–90 |

保密与培训事项可约定，但违约金、培训费和竞业限制须另查特别法及司法规则，不直接照旧意见推定无限责任；禁止招用时收取定金、保证金、抵押财物。借用、租赁承包经营、受委托管理和经理任命分别核实际用人单位及签约权限，企业名称及法人不变时承包人不是当然的新雇主。（PDF59、87–88）

医疗期满另岗与劳动能力鉴定、病退退职、经济补偿和医疗补助的旧处理分支见意见第35点。医疗期依据实际工龄和本单位年限为3–24个月，特殊疾病未愈在旧意见中有批准延长规则；旧意见把不同退休岗位、原工人与干部身份转制分开处理，实际结论须核当期退休制度和特殊规则。（PDF89、91）

补偿与失业待遇不能互相无依据扣减。集体合同草案经职代会或全体职工讨论通过、签署并报送；主管机关15日未异议生效，个人合同标准不得低于集体合同。签订争议与履行争议分别由协调、仲裁诉讼处理。（PDF60、63、89–90）

## 工时工资、安全保护、培训与社会保险

1. **工时与加班**：劳动法文字为每日不超过8小时、平均每周44小时，每周至少休1日；其他工作休息办法要经批准。延时须与工会和劳动者协商，一般日1小时，特殊理由且保障健康时日3小时、月36小时；灾害事故紧急处理、设施故障抢修等特别例外。标准工时不能按季度年度摊平超时。综合工时按批准周期与法定平均标准校核，遇法定节假日仍有加班规则；不定时工时不能免除休息权。（PDF60、90–91）
2. **报酬分类**：延时150%、休息日工作不能补休200%、法定节假日300%，均为书载最低标准；法定假日加班不能单靠补休替代。工资以货币按月支付，不能克扣无故拖欠；最低工资是正常劳动的保障，试用见习熟练期也适用，未完成定额条款不能当然突破。社保福利、劳动保护费用与工资概念不同；最低工资排除项目另有地方差异，不能把旧意见一概当最新口径。（PDF60–61、90）
3. **病假和停工**：书载医疗期内病假工资或疾病救济费可以低于最低工资但不得低于其80%；下岗待工生活费、产假工资或生育津贴、经济困难企业基本生活保障另有规则。留存停工原因与期间、当地标准及是否提供正常劳动；不得把低生活费规则用于正常出勤。意见第61点的21.16或23.33日折算是历史标准，实际计算须另核。（PDF90）
4. **安全卫生**：建立规程和教育、提供合格设施及必要防护用品，职业危害岗位定期体检；新改扩建安全卫生设施与主体工程同时设计施工投入使用；特种作业专门培训和资格；劳动者可以拒绝违章指挥、强令冒险，对危险行为检举控告。事故及职业病要统计报告处理。（PDF61）
5. **特殊保护**：女职工一般、经期、孕期、产期、哺乳期分别有限制；孕7个月以上不延时不夜班，哺乳未满1周岁婴儿者同样禁止延时夜班；未成年工不得矿井、有毒有害及禁忌作业并定期检查。书载产假90日只是旧法文字，不是现行天数结论。（PDF61–62）
6. **培训和社保**：单位建立培训制度及经费，技术工种岗前培训、职业资格鉴定依规则；社保覆盖年老疾病工伤失业生育，依法参保缴费、按时足额待遇，基金禁止挪用，补充保险福利可发展。工伤认定、职业病诊断、伤残及护理鉴定、报告漏报、补发待遇各是不同步骤；意见第77–81点基于当年制度，尤其不能据第81点直接对鉴定结论走复议诉讼。（PDF62–63、91–92；部门办法PDF97）

劳动争议可协商、调解、仲裁、诉讼，调解非普遍前置，仲裁与诉讼衔接另查特别法；监督监察不替代仲裁裁决。书载劳动法60日申诉、60日裁决与旧意见调解最长30日中止、申请至受理中止，均需按适用时点查后续劳动争议特别法；不能用于设置当前期限。（PDF63、92）

## 企业形式、管理人员与破产职工债权

独资企业投资人以个人财产负无限责任，职工劳动合同、安全、足额工资、社保义务不因组织形式减轻；受托管理须书面明确事项权限，内部权限限制不得对抗善意第三人。解散清偿书载依次为工资社保、税款、其他债务。（独资企业法节录第2、6、19、22、23、29条，PDF74–75）外商投资企业也须支持依法组建工会；公司有保护职工、培训、合同社保、工会集体协商和重大改革事项听取职工意见的义务。（外商投资法第8条、公司法第17–18条，PDF74–75）

公司法为2018年旧版节录：董事监事高管须查行为能力、有关犯罪及剥权后5年、对破产或吊销关闭负个人责任后3年、到期大额未清债务等任职障碍；任职不符应解除职务，但公司职务解除与劳动合同解除分开判断。忠实勤勉、禁止资金挪用、私人账户、越权借贷担保、未经允许关联交易、抢商业机会同业经营、私收佣金和泄密；违法收益归公司，有损失可赔偿。股东代表诉讼有书面请求、股份公司连续180日和1%门槛、30日不诉或紧急例外；直接侵害股东利益另可诉。（第146–152条，PDF75–76）实际须核公司法新旧条号及实体变化；民事合同问题可联用civil-code-contracts。

破产不能将“工资优先”写成压倒所有权利。书收《企业破产法》节录要求债务人提交安置预案、工资支付和社保缴纳资料；法定工资、医疗伤残抚恤、个人账户基本养老医疗费及法定补偿，不需职工申报，由管理人调查公示。职工发现漏错先请求更正，拒不更正可诉。债权人会议有职工工会代表；债委会含一名职工或工会代表，最多9人；重整中职工债权单列组。（PDF76–77）

破产财产先付破产费用、共益债务，之后职工法定项目、其余社保及税、普通债权，同序不足比例分配；特定财产担保权另查，不能忽略。高管工资按企业职工平均工资计算。程序终结后2年发现应追回或可分配财产可申请追加分配，但不足分配费例外。拒交、虚假工资社保资料、毁灭账册财产证据可罚责任人。（第113、123、127条，PDF77–78）

## 个税：先分类，再扣除与申报

《个人所得税法》为2018年修正文本，PDF69–74。税务居民按住所或纳税年度累计居住183日判断；居民原则就境内外所得、非居民就境内所得计税，实际须核无住所例外、税收协定及当年优惠。工薪、劳务、稿酬、特许权使用费对居民构成综合所得按年合并；经营、利息股息红利、租赁、转让、偶然所得分别计税。扣税类别不是劳动关系认定的替代证据。

书载综合所得年收入额减6万元、专项、专项附加及其他依法扣除；非居民工薪每月减5000元，其他三类按次。劳务、稿酬、特许权先减20%费用，稿酬收入额再按70%；经营扣成本费用损失；租赁每次不超过4000元减800元、以上减20%；转让扣原值合理费用。公益捐赠一般以应纳税所得额30%为限，法定全额扣除例外。专项含规定社保公积金，专项附加含教育、继续教育、大病、房贷利息或租金、赡养老人等；具体范围和额度必须另查。（PDF70–71）

税率表正文是图片：综合表在PDF73页、经营表在PDF74页，表题分别始于72、73页；已补读图片OCR，多尺度补读税率列。综合年度应纳税所得额档界36000、144000、300000、420000、660000、960000元，对应税率3%、10%、20%、25%、30%、35%、45%；经营档界30000、90000、300000、500000元，对应5%、10%、20%、30%、35%。非居民四类劳动性所得按综合表换算月档；其他上述比例所得书载20%。这是超额累进表，不能把最高档税率乘全部收入。表内税率个别OCR识别有漏字，正式算税仍须复核官方表和当年预扣方法。（PDF70、73–74）

免税包含法定奖金、国债及规定金融债券利息、统一补贴津贴、福利抚恤救济、保险赔款、退役类给付、规定安家退职及基本养老金退休费等、外交及协定免税和法定其他所得；不能把企业任意命名的“补贴”“福利”都免税。残疾孤老烈属和自然灾害重大损失可按地方规定减税。境外已缴税可限额抵免；不独立交易、低税负控制企业无合理理由不分配、无合理商业目的安排可调整并加利息。（PDF70–71）

支付者为扣缴义务人，依法全员全额申报并提供收入已扣税信息；应采纳合规专项附加信息。综合年度汇算一般次年3月1日至6月30日；非居民四类代扣不汇算；经营按月季终15日预缴、次年3月31日前汇算。无扣缴义务人一般次月15日申报，漏扣一般次年6月30日前缴、税务限期通知从其规定；境外所得另申报，非居民多处工薪次月15日，迁居注销户籍前清算。预扣代扣次月15日缴库，退税依法办理。法定身份及扣除信息共享、股权不动产完税查验、货币换算、扣缴2%手续费、征管责任及储蓄利息特别政策分别有条款。（PDF71–72）

## 劳动保障监察：受理到执行

《劳动保障监察条例》PDF78–81、实施若干规定PDF81–85及《劳动监察员管理办法》PDF85–86是书载程序来源。

- **管辖和范围**：一般由用工所在地县级或设区市主管机关管辖，省级另有具体办法；上级可办下级案件，争议报共同上级指定。规章合同、童工、女职工未成年工、工时工资、最低工资、参保缴费和中介培训鉴定机构是监察事项；无照或吊销后仍用工也受监察。职业安全卫生有其他部门专门分工。
- **举报与投诉**：任何人可举报，劳动者自身权益受侵害可投诉，举报信息须保密；同事由集体投诉可推代表。书面列双方身份、单位、侵害事实、具体请求，确有困难可口头笔录签字。符合2年、明确单位及侵权联系、职权管辖条件，接投诉5个工作日受理并立案；超时不受理给书面通知，主体事实缺陷补正，管辖不符指引。2年自发生、连续继续自终了起算；不要与仲裁时效混用。
- **分流**：劳动损害赔偿争议、应由劳动争议程序处理或已进入调解仲裁诉讼的事项，依法告知相应路径；社保经办机构行政争议另处理。既有争议程序不等于所有不同对象行政事项都排除，见[ch01](ch01.md)。
- **调查**：立案调查一般60个工作日，复杂批准延30个工作日；至少两人、指定主办、出示佩戴证件标志，笔录签章，拒签注明。回避书面申请3个工作日决定，决定前不停止调查。可进入场所、询问、调文件、录音录像复制、委托会计审计、异地协查；证据灭失风险经批准登记保存、给通知清单，7日内处理，届满解除。不能擅自把登记保存扩大成无限期扣押。
- **处理**：区别责令整改、行政处理、行政处罚、轻微已改或事实不成立撤销立案、移送其他机关与涉嫌犯罪移送。听取陈述申辩、告知听证及救济，不能用处罚取代支付工资。调查完成后一般15个工作日决定，特殊情况批准可延；决定内容须有事实证据依据、履行救济期限、机关印章，宣告当场或不在场7日内依法送达。
- **执行归档**：决定不适当主动纠正；复议诉讼原则不停止执行。延期分期罚款须申请批准，罚缴分离；逾期不履行处理处罚可依法申请法院或依法执行。案件档案至少3年，地方处罚决定10个工作日上报备案。监察员须培训任命、持证及考核验证；书载三年考核，岗位离开收证注销，兼职单项监察处罚须会同专职；越权、非公务用证或牟利等可撤任处分追责。

书载责任项目包含：保护女职工未成年工按每人1000–5000元；超时按每人100–500元；欠薪、最低工资差额或解除补偿责令限期支付，逾期才加付应付金额50%–100%；瞒报工资人数及骗社保按相应金额1–3倍；中介培训鉴定违法没收并1–5万元、严重吊证；抗拒、虚假隐毁证据、拒改或拒履处理决定2000–20000元；打击报复、强迫劳动及工作人员违法另有治安刑事赔偿责任。条例第32条明确法律和其他行政法规另定处罚从其规定，因此不能将旧罚则压过新特别法。（PDF80–81；劳动法责任类别PDF64–65）

1996年劳动听证规章要求调查与主持职责分离，主持记录员回避、当事人与直接利害关系第三人质证申辩及最后陈述、主要证据听证出示和认定、笔录核阅。其告知后3日申请与同书2021年处罚法5个工作日冲突；不把旧规视为独立缩短权利的依据，听证范围及较大罚款门槛另核地方规则。（PDF104–105；总则见[ch01](ch01.md)）

## 诚信评价、公开后果与刑责

2016年《守法诚信等级评价办法》每年根据上年监察等记录评一次：未被查处为A；被查处但不到C为B；三次以上查处、群体极端或严重影响、童工强迫劳动、拒履决定、阻挠监察、被追刑责之一为C。A减少检查、B增加、C重点检查并约谈；记录至少3年，确定后新违法需降级则及时重评，跨部门共享依规进行，省级可配套。（PDF93–94）

2016年《重大违法社会公布办法》先依法查处并决定，再公布较大欠薪或刑事移送、严重社保工时特殊保护、童工等重大事项。公开主体名称代码地址、负责人、主要事实和处理，但秘密隐私排除；市县每季度、部省每半年，必要可随时，事前报上级。异议收到起15个工作日复核处理；原决定变更撤销后10个工作日更正。与处罚法公开处罚信息撤回的3个工作日规则分别核查适用对象，不能混成一个时限。（PDF94–95；处罚法PDF30）

刑法仅节录三罪（PDF57）：暴力威胁或限制自由强迫劳动，明知而招募运送协助者也可能担责，单位犯罪追单位及责任人；雇未满16周岁从事超强度、高空井下或危险环境劳动且情节严重可构罪，事故另犯罪可数罪并罚；拒付报酬须逃避或有能力不付、数额较大、有关部门责令仍不付等要件，严重后果加重。未严重后果且公诉前支付并承担相应赔偿可减轻免除。核对司法解释的数额、支付能力、责令送达和责任人身份，不能把所有欠薪直接定罪。

## 应用推演：欠薪与停工的材料路径

先列每名劳动者关系、月份、正常工资、加班、已付、差额及停工原因，保留合同、考勤、流水、工资表、社保记录、沟通及整改送达。判断是明确欠薪的监察请求，还是涉及关系或损害的仲裁诉请；分别计算适用期限。主张加付赔偿金须核有无合法责令及逾期，移送拒薪罪须再核刑法要件。破产已受理则同步查管理人职工债权清单及更正渠道；不能只继续向停业单位催款而遗漏破产程序。
