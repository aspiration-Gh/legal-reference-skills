# ch29 生育保险、产育支持与待遇衔接

> 来源：《劳动和社会保障法律法规全书》2022年版（2021.12第8版，ISBN 978-7-5216-1794-8），PDF830–836页；830页前段属失业保险，836页末为前文案例来源尾注。本文件为实务模块，不是源书章号。下述规则均为书载文本，实际应用须核适用时点的官方现行法、地方生育假、参保连续性、待遇与报销标准。本章不宣称已完成法律更新。法条方括号条旨等为编者整理；流程、证据和示例为自编应用。

## 1. 先拆开三个问题

**自编流程：**确认生育或流产时间、参保地、单位及就业身份、缴费记录，再分别判断：（1）生育及劳动保护、产假和地方奖励假；（2）生育津贴的支付主体、基数与期限；（3）生育医疗费用范围和结算。不能用“合并实施”推出取消生育待遇，也不能把所有地方延长假自动计入基金津贴支付天数。

《人口与计划生育法》书载2021年修正版第17–22条（PDF831–832）：夫妻共同承担责任；一对夫妻可生育三个子女，符合地方规定条件可再生育；两地再生育规定不一致，按有利于当事人原则。育龄夫妻自主选择安全适宜的避孕节育措施，依法免费享受规定基本技术服务，经费由财政或社会保险保障；禁止歧视虐待生育女婴及不育妇女，禁止歧视虐待遗弃女婴。不得把本章生育政策直接等同具体津贴资格，须继续查待遇规定。

## 2. 2019年两险合并的六项核查

国办发〔2019〕10号（PDF833–834）要求保留险种、保障待遇、统一管理、降低成本，2019年底前实现合并；指导思想段存在提取错序，以下执行要点来自清晰的“主要政策”正文。

| 环节 | 书载明确要求 | 实务检查 |
|---|---|---|
| 登记 | 参加职工医保的在职职工同步参加生育保险 | 查就业身份、参保记录和漏登漏缴 |
| 征缴 | 生育基金并入职工医保基金，统一征缴及统筹层次；新单位费率按两险单位费率之和确定，个人不缴生育费 | 核地方实施与后续动态调整，不能要求个人另担生育费 |
| 财务 | 不再单列生育基金收入，在医保统筹待遇支出中设生育待遇项目，实施风险监测及监督 | 区分合并记账与待遇消失 |
| 医疗 | 统一定点协议管理，执行规定药品、诊疗及设施范围；探索分娩按病种、产检按人头付费，原则上经办与定点直接结算 | 区分基金支付、个人自费及异地结算 |
| 经办 | 统一由医保经办机构负责，经费列同级财政预算；旧结算平台可过渡保留 | 依当地办事指南确定入口 |
| 待遇 | 生育医疗费及津贴不变，从职工医保基金支出；津贴期限依《女职工劳动保护特别规定》等产假规定 | 分别核法定产假、地方奖励假及津贴范围 |

地方方案须结合两险人群差异、支付能力和待遇水平，确保参保人待遇不降低、平稳过渡；按收支平衡确定调整费率，防范风险转嫁（PDF834）。

## 3. 旧试行办法保留的计算与程序边界

《企业职工生育保险试行办法》（劳部发〔1994〕504号，PDF834–835）适用城镇企业及职工，属地统筹，1995年1月1日起试行。书载企业按工资总额一定比例缴费，地方确定且不超过1%，个人不缴；**该旧上限不是合并后单位医保总费率上限。**

- 津贴按本企业上年度职工月平均工资计发，由基金支付；核查基数所属年度、统计口径及地方后续规定，不能直接等同本人当月工资。
- 生育检查、接生、手术、住院及药费由基金按规定负担；超范围服务、药品及营养药品个人承担。出院后因生育引发疾病的费用与其他疾病费用分流；产假期满因病休息，按病假和医疗保险待遇处理。
- 书载本人或企业凭计生证明、婴儿出生死亡或流产证明办理津贴与医疗报销。此为旧材料表，不能未经核验向申请人加设现行指南已经取消的证明。
- 旧办法列基金专户、利息并入、预算决算、财政审计及社会监督；经办管理费可提取且最高为基金2%，逾期缴费按日加收2‰滞纳金。这些历史规定与后续基金财务、社保征缴及合并经办规定必须做时序核对，不作为今日收费或处罚依据。
- 虚报冒领应追回并依法处罚；企业欠付拒付津贴、医疗费，劳动行政部门责令限期支付，造成损害承担赔偿；经办人员滥权、失职、贪污挪用分别涉及处分或刑事责任。

人社部发〔2015〕70号（PDF835–836）自2015年10月1日起针对结余过多地区降费：合理结存为6–9个月待遇支付额；累计结余超过9个月的统筹地区应降到工资总额0.5%以内；低于3个月支付额须预警并报告；不足支付时通过加强支出管理、临时补贴或调整费率等确保待遇。**不是所有地区无条件适用0.5%，也不是当前统一费率。**836页省级方案报批与8、9月底安排出现错序，具体工作日程不据残缺文本重构。

## 4. 产育支持、机构合规及责任

《人口与计划生育法》第23–34条（PDF832）区分以下层次：

- 符合法律法规生育的夫妻可获延长生育假或其他福利；支持有条件地方设父母育儿假。具体假期、工资与费用承担依地方有效规定，不推导统一天数。
- 孕期、产期、哺乳期享特殊劳动保护及帮助补偿；因生育影响就业者有就业服务，计生手术依法休假。
- 财税、保险、教育、住房、就业支持与普惠托育属于制度安排；鼓励单位、社区等提供托育。托育机构须符合标准并向县级卫生健康部门备案。公共场所和女职工比较多的单位应配置母婴设施，核具体场景和适用标准。
- 旧独生子女政策期间已获光荣证者按规定继续享奖励；法规规章指定由单位落实者单位应执行；原计生家庭老人奖励扶助继续；独生子女伤残死亡家庭依法扶助，不能把新生育政策理解为旧待遇自动全部撤销。
- 农村计生家庭生产发展可获支持，困难家庭按规定优先；地方可制定具体奖励保障办法。

第1–16、35–48条（PDF830–833）还覆盖依法行政、各级人口规划和实施、部门分工及组织协助、学校适龄教育、流动人口现居住地为主管理、经费保障与禁止截留挪用、婚前孕产期保健和技术服务、军队另定执行办法及施行日期。禁止非医学需要胎儿性别鉴定及选择性别终止妊娠。

书载责任需按行为分别认定：非法计生手术或非医学性别鉴定等，警告、没收违法所得；违法所得达到1万元时罚2–6倍，否则罚1–3万元，严重可吊证，犯罪另追究。托育违反标准先改正警告，拒改罚5000–50000元，严重停服并罚5–10万元；虐待婴幼儿的直接责任者终身不得从事照护。技术人员违章或延误造成严重后果、行政人员侵权舞弊及统计造假、不履行协助义务、妨碍执法分别适用对应责任；行政侵权可复议或行政诉讼（PDF833）。

## 5. 自编证据与应用

按四组保存：劳动合同与参保缴费记录；产检、诊断、出生或流产及出院材料；休假审批、工资台账和津贴到账；医疗票据明细、定点信息、申报回执及拒付理由。先判断是单位支付争议、参保漏缴还是经办资格/结算争议，再选择劳动争议、征缴处理或行政救济，并核期限与管辖。

**自编演练：**女职工产假结束后因病继续治疗，应拆分生育引发疾病、其他疾病及病假工资，分别查医保与病假规则；不能把产后全部医疗和休息日都记成生育津贴。原书本节没有完整案例。836页的五条案例来源尾注属于前文资料，不据尾注编造生育案例。
