# 实务模块05｜职业培训、学徒制与合作办学

来源：《劳动和社会保障法律法规全书》2022年版，2021年12月第8版，ISBN 978-7-5216-1794-8，PDF第175–189页；起点为终身职业技能培训意见，终点为合作培训办法附则。内容为书载规则提炼，非源书章号。未作现行效力逐项核验，使用前核对事件时点、官方有效文本、办学类型与当地实施标准，尤其旧机构名称、职业资格、合理回报及审批程序。

## 1. 选定培训制度，先确定对象与资金来源

**书载2018年终身职业技能培训意见**覆盖城乡全体劳动者的学习工作全程，以政府补贴、企业自主和市场化培训供给，以公共实训、职业院校、培训机构、企业为载体。就业前技能、在岗提升和创业创新培训分别适用，不能仅凭“参加培训”推定财政给付。（PDF第175–176页）

- 高校毕业生、农村转移与新生代农民工、失业和转岗人员、未升学初高中毕业生、即将退役及退役人员、困难家庭与残疾人、服刑及强戒人员等有不同项目；高技能培训围绕紧缺工种、技师和高级技师及关键岗位创新；创业培训涉及项目、开业、管理、孵化、科技金融及在校“试创业”。这些是政策对象清单，具体申请条件仍找对应项目。（PDF第176页）
- 企业承担职工培训主体职责，可通过岗前、学徒、在岗、脱产、研修、练兵竞赛组织；政府补贴项目向具资质的职业院校和培训机构开放。评价并列职业资格、技能等级、专项职业能力，不把普通结业证等同准入资格；工匠精神、职业道德、质量、安全环保卫生、法律意识属于培养内容。（PDF第176页）
- 监管采用补贴项目、培训机构、评价机构、职业资格目录动态清单；绩效关注培训合格及就业创业成效，建立电子档案并衔接就业社保。技能待遇以岗位价值、能力和业绩为导向，支持薪酬、职称、晋升、落户及成果权益衔接，不能把“鼓励企业”直接写成法定固定奖金。（PDF第177页）
- 基础建设包括公共服务平台、职业分类及标准、培训包、学分转换、师资教材、实训基地和技能大师工作室；资金由政府、企业、社会和个人等渠道筹集，补贴需监督以防骗取挪用，捐赠税前扣除另按税法。各部门分工和地方规划、财政投入、宣传等构成实施保障。（PDF第177页）

## 2. 企业新型学徒制：劳动关系、培养协议和补贴须同时闭合

书载2021年意见的主要对象为至少签订1年以上劳动合同的技能岗位新招用、转岗等人员，企业结合生产实际选定。目标包括中级工、高级工、技师及高级技师；通常培养1–2年，特殊可延到3年，按“一班一方案”组织，允许弹性学制与学分制，中小企业可集中开展。企校合作、工学交替，企业与院校导师及基地协同；源文该段有错序，具体模式用语须回核官方原件。（PDF第177–178页）

办理顺序如下，属于依书载要求整理的实务步骤：

1. **确定人与岗。**核劳动合同期限、技能岗位、转岗需要、培训职业标准及培养层次；将岗位技能、数字绿色技能、安全、职业素养与创新等纳入课程，不仅编造一个补贴名册。（PDF第178页）
2. **签两类协议。**企业与学徒约目标、内容、期限、质量考核，同批同类可集体培养协议；委托院校时另签合作协议，明确方式、内容、期限、费用和双方责任，保证工作同时能系统学习。（PDF第178页）
3. **培训前备案。**向所在地人社提交计划、学徒名册、劳动合同等地方清单，审核列计划后可按规定预支。书载补贴每人每年原则5000元以上，具体由市地以上人社财政确定；补贴年限按实际且不超备案期限，可按社保缴纳地或就业地申领，不可推定跨地重复领取。（PDF第178页）
4. **培训中履行工资义务。**企业依劳动合同法付工资且不低于企业所在地最低工资；向培训机构付费可依政策从职工教育经费列支，导师津贴由企业确定承担。培训不能当然变成无薪期。（PDF第178–179页）
5. **结训评价与结算。**保存证书编号或复印件、视频、合规收费票据；依据符合条件人数拨余款。技能评价可结合生产过程、模块考核、业绩或直接认定；政府、企业、院校分工以及工会、工商联组织和监督须落到具体人员。（PDF第178–179页）

## 3. 技工学校：审查教学与生产的边界

《技工学校工作规定》为1986年发布、书载2010年修正文本，带有历史计划管理术语。其培养中级技术工人为主，也承担在职提高、转业、待业青年和学徒培训；通常初中毕业生三年，个别专业高中毕业生经批一至二年。招生全面考核择优，毕业推荐与单位录用；办学规模通常不少于200人，专业、师资、经费、校舍实验、教学计划应匹配，设立调整撤销履行规定审批备案。（PDF第179–180页）

- **教学与实习。**操作训练为重点，理论围绕专业，教学计划可按规定小幅调整，书载课时约15%；平时、学期学年、毕业考核并行。下厂前校企商订计划，明确课题、学时、岗位、师傅、定期考核和轮岗；理论教师与实习教师互补，教研组及学校领导持续检查教学。（PDF第180–181页）
- **学生与教师。**注册学籍、学生组织和奖助相结合；纪律处分应经校务会议讨论、校长批准，退学开除还须报备，不能由企业现场主管直接代行。课程、操行、毕业考试合格才毕业；书载两门毕业考试不及格或操行不及格发结业证。教师聘任、课时、考核奖惩及进修另有规定，一般理论课每周12–16课时是旧文参数。（PDF第181–182页）
- **育人与行政。**思想品德、职业道德、法制教育贯穿教学，对思想问题以讨论说理疏导；品德评定每学期一次、实事求是。校务会议、教职工民主参与、后勤卫生、食堂账目、独立财务及学校基金构成治理要求。（PDF第181–182页）
- **生产经营约束。**实习工厂兼顾教学与生产，禁止脱离教学单追利润；设备原料制度、岗位责任、独立核算、产品质量及经济合同须落实，改善安全防护和劳动条件。实习产出高不证明培养质量合格。（PDF第182页）

《技工学校教育督导评估暂行规定》1997年版同时检查主管部门、学校及管理部门：法律政策、办学标准、设施教学、教师资格待遇、学生发展、就业指导及其他培训。综合与专项评估并列，分层机构组织，可聘技师参与；督导员有资格与经历要求，可查文件、现场和用人单位评价，整改意见经机构确认后实施；弄虚作假与滥权分别追责，结果可公布。（PDF第182–184页）

## 4. 合作职业技能培训：机构和项目走不同程序

书载《合作职业技能培训办学管理办法》为2006年发布、2015年修订。本节以简称表述：境内外教育机构合作举办以该法域公民为主要招生对象的公益性职业技能培训，分为新设机构和依托现有教育机构的项目；经营性机构另依规定，境外组织个人不得单独设立上述培训机构。港澳台教育机构合作原则参照，另有规定除外。（PDF第184、189页）

| 审查环节 | 机构 | 项目 |
|---|---|---|
| 申请与主体 | 合作双方具相应办学资格质量；境内教育机构向省级人社申请筹设、正式设立，已具条件可直接正式设立。境外资格证明须依书载要求公证。（PDF第184–185页） | 双方法人资格，办学层次类别匹配，境内机构具师资设备；向省级申请并报上级备案，受理后30个工作日决定，批准给项目批准书。（PDF第186–187页） |
| 协议、资产 | 中文协议写身份、目标内容期限、投入、纠纷与违约；外文一致。投入按期足额，不抽逃挪用；非货币资产定价转移，国有资产评估备案。（PDF第184–185页） | 协议、申请表、公证资格及有捐赠时协议证明；项目列入举办学校教学活动和管理。（PDF第186–187页） |
| 标准与治理 | 同时培训不少于200人；一般建筑3000平方米、实训实验1000平方米，租期至少3年、图书5000册；专职教师一般不少于1/3。校长国籍、境内定居、学历/职称/技能资格和师资条件逐项核；技工学校另参其标准。设章程、理董事会、专职校长及管理制度，公职人员任董事有限制；不得设分支或再办合作机构。（PDF第185–187页） | 依批准专业、宗旨目标办学，可在境外实施部分培训；按招生简章或培训协议开课并保证设施质量。培训、结业证与另经鉴定的职业资格区分。（PDF第187页） |
| 财务与终止 | 公益土地校舍用途不得改变，不得营利经营；旧文“合理回报”和发展基金衔接民办教育旧条号，须核新版分类管理。财务审计会计年度终了1个月内公布并备案。（PDF第188页） | 学校账户内专项统一收支，收费依规定公布、结余留教学；协议终止须批准，一方失去资格或批准书吊销等可终止，提交安置学生方案、交回证书并公告注销。（PDF第188页） |

**许可风险与持续义务。**不符公益和发展需要、主体不合格、文件虚假或不改正，筹设/项目申请不批；正式设立再核标准、理董事会及人员资格、章程、筹备期间违法。技工学校正式设立专家评议时间书面告知、不计审批期限，必要核查至少2名工作人员。年度办学报告3月31日前；计划大纲教材依法备案；招生广告发布后5日内备案，并如实列课程、期限、收费、证书和就业去向。未经批准或骗批项目应改正、退费并可罚款；乱收费退多收并移价格监管，虚假招生退费、没收及罚款，超层次、低质量、财务违法、分配结余须整改，越权审批文件无效并追责。（PDF第185–189页）

**自编应用推演，非书中案例：**若机构称“国际证书包就业”，先查是机构许可证还是项目批准书及专业层次，再比对广告、课程、师资设备、考勤视频、证书性质、收费票据与就业承诺；不因有境外合作方就认定具备办学许可或就业资格。学徒欠薪与培训补贴可分别处理，财政补贴到账不是工资支付前提。该段原文为规范汇编，没有具体裁判案例；未发现编者独立学理框架。
