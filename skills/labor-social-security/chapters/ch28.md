# ch28 失业保险：身份、离职原因、待遇与转移

> 来源：《劳动和社会保障法律法规全书》2022年版（2021.12第8版，ISBN 978-7-5216-1794-8），PDF824–830页；824页为分节标题，830页与生育模块共页。本文件编号是实务模块编号。下述为书载规范提炼，未经现行法更新；办理案件时必须核验适用时点的官方文本、地方费率、待遇标准与经办规则。方括号条旨属编者整理；核查流程、证据清单及示例属自编应用。

## 1. 先按身份与离职事实分流

**书载《失业保险条例》第2、14、21、32条（PDF825–827）：**城镇企业事业单位及职工为主要对象；社会团体、民办非企业单位、有雇工的城镇个体工商户是否纳入，书载条例留给省级决定。《失业保险金申领发放办法》第2条（PDF827）只调整已经参保的人员，应参未参者不适用该申领办法，不能据此免除单位参保责任。

普通失业保险金必须同时具备：单位和本人依法缴费满1年；非因本人意愿中断就业；已失业登记且有求职要求。按《申领办法》第4条，合同终止、单位解除、开除除名辞退，以及依书载《劳动法》第32条第2、3项解除等属于非本人意愿（PDF827–828）。**自编核查：**取得实际解除原因、发起人及书面依据，不能只凭离职证明上“辞职”二字判断，更不能建议故意违纪获取资格。

另行处理：农民合同制工人本人按旧条例不缴费；连续工作满1年、单位已经缴费，合同期满未续订或提前解除时，按工作时间和省级标准领取一次性生活补助。此身份待遇与普通按月失业金不可混算（PDF825–826、829）。

## 2. 将费率、期限、金额分开核对

| 核查项 | 书载规则及限制 | PDF页 |
|---|---|---|
| 条例费率 | 单位工资总额2%，职工本人工资1%；省级可按规定报批调整 | 825 |
| 2015年降费 | 人社部发〔2015〕24号：自2015年3月1日起总费率暂由3%降至2%，单位与个人具体比例由省级确定，省域统一；按基金承受力测算、批准备案 | 829–830 |
| 待遇期限上限 | 累计缴费满1年不足5年：12个月；满5年不足10年：18个月；10年以上：24个月。是最长上限，不是每人固定月数 | 826 |
| 再就业后再失业 | 新缴费时间重新计算，未领余额可合并，但合计最长24个月；领金期间再就业后不满1年再次失业，可继续领取前次剩余期限 | 826、828 |
| 视同缴费 | 实行个人缴费前按规定计算的工龄，可与条例发布后缴费时间合并；须有档案依据 | 828 |
| 金额 | 书载条例要求低于当地最低工资、高于城市居民最低生活保障；具体省级确定 | 826 |

医疗补助、职业培训和介绍补贴、丧葬补助与供养配偶及直系亲属抚恤，分别核对领取期间及地方标准；死亡当月未领失业金可由家属一并领取。符合低保条件可依法另行申请，不以失业金领取期是否结束一概排除（PDF826、828）。旧条例医疗补助及费率均不能直接当作今日办理口径。

## 3. 申领、停发与争议证据

书载流程（《条例》第16条及《申领办法》第5–20条，PDF826、828）：单位及时出具解除终止证明、告知待遇权利，并于解除终止之日起7日内报失业名单；个人按书载办法于60日内申领，填写申请表，出示身份、解除终止、失业登记及规定的其他材料；经办机构受理后10日内审核并告知结果，合格者自失业登记之日起计发，按月发放；期限届满前1个月告知。**60日、现场按月领取、材料与起算方式均属旧书载程序，须核官方后续简化政策，不得以本章直接拒绝逾期申请。**

书载停发情形包括再就业、服兵役、移居境外、享受基本养老待遇、被判刑收监或旧制劳动教养、无正当理由拒绝指定机构介绍工作及其他法定情形（PDF826、828）。涉及旧制用语及与后续法律衔接时逐项核验，不能机械套用。临时工作是否再就业，应结合劳动关系、单位参保与当期经办政策判断；书载2020年答复对单位缴社保认定标准、非规范劳动关系临时工作、档案不得作为停发依据的说明见[ch30](ch30.md)。

**自编证据包：**身份与参保地、逐月缴费及视同缴费记录、解除终止通知和送达材料、申请回执及失业登记时间、历史领金及剩余月数、再就业参保记录；家属领取另备死亡、身份、亲属关系证明。要求不予受理、拒付或停付的具体事实和依据形成书面记录。书载办法第27条列主管劳动保障部门行政复议路径；实际救济另核现行复议管辖、期限及诉讼规则。

## 4. 转移、退役身份与历史安置

- **一般转移（PDF826、829）：**单位成建制跨统筹地区转移、人员跨地区流动，关系随迁。原单位与户籍分属统筹地区时，由两地协商发放办法，协商不成报上一级。书载跨省费用包括失业金、医疗补助和培训介绍补贴，后两类合计按应享失业金总额的一半计算；省内转移按省级办法。凭迁出证明到迁入地领取。实际操作应核新转移接续办法，不沿用旧划转比例报价。
- **退役人员（人社部发〔2013〕53号，PDF829）：**计划分配的转业干部、复员干部、安排工作及自主就业退役士兵，服役年限按实际时间计至月，符合参保条件时视同缴费；由团级以上财务机关出具证明，凭证明及退役证件办参保，与入伍前、退役后年限合并。入伍前关系留原参保地，不转军队。自主择业转业干部为明确例外：服役年限不再视同，从当地实际缴费起算。参保缴费满1年后失业，按规定享受；2013年8月1日前已退役者按原规定，不能只凭“退役”二字推定。
- **破产安置复函（劳社厅函〔2001〕133号，PDF830）：**针对优化资本结构试点城市特定破产安置背景，一次性安置费以自愿自谋职业为前提，在业人员不享失业待遇；未申请或申请后未实现自谋职业者，以及实行劳动合同制后参加工作的职工，解除时按规定给予经济补偿，符合法定条件可享失业待遇。不能把收到任何安置款等同已经就业或当然丧失失业金资格。

## 5. 基金与责任不遗漏

《条例》第5–13、24–31条规定缴费、利息、财政补贴等基金来源，统筹与省级调剂，收支两条线、专款专用、预算决算及财政审计监督；经办运行经费由财政预算拨付。骗领按书载条文退还，严重者处骗领额1–3倍罚款；违规开具单证、失职和挪用涉及追回、处分或刑事责任。《申领办法》第25–26条另载违法经办造成损失依法赔偿（PDF825–827、829）。处罚种类幅度须核后法，不能脱离行为时点引用旧标准。

**自编演练：**领金期间再就业，不满1年又非自愿失业，不应仅因新缴费未满1年就否定前次余额；先调取前次核定和已领月数，再分别判断旧余额与新增待遇。原书本节无完整案件，以上不是书中案例。
