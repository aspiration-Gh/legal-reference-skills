# ch03 工会组织、民主管理、劳动监督与集体协商

## 适用范围与来源分层

来源为《劳动法规全书》2022年版（2021年12月第8版）PDF65–69页《工会法》、105–112页2018年《工会章程》、112–114页2021年《工会劳动法律监督办法》、114–119页2006年《企业工会工作条例》、119–120页2020年修正《工会法民事审判适用解释》及120–121页2006年《关于开展区域性行业性集体协商工作的意见》。关联劳动法集体合同条款见PDF60、63页；企业组织和破产权利见[ch02](ch02.md)。

此为实务模块重组，法律、司法解释、部门联合意见、工会章程与内部工作规范效力不同。书中未提供本范围的具体案件评析，条文主旨是编者导航；下列办理步骤、示例是应用推演。每次应用先定位书载规则，再在官方法律数据库、法院、工会及人社官方渠道核验适用时点文本、生效日、地方配套与上位法。特别注意：书收《工会法》记载2021年12月24日修正，2020年司法解释却仍援引修正前条号，不可自动互换；章程、公司治理及劳动合同规则亦须查新。

## 组建、会员及组织治理

《工会法》书载适用于企业、事业单位、机关和社会组织中以工资为主要生活来源的劳动者，维护新就业形态等群体参加和组织工会的权利；组织性质为职工自愿结合的群众组织，在既定政治领导及组织体系下，依章程独立开展活动。职责包括维护合法权益、服务职工、平等协商、集体合同、民主管理、技能教育及产业工人队伍建设，并有国际交流原则；这些是工会组织职责，不应虚构成作者提出的管理模型。（PDF65）

- 会员25人以上应建基层委员会；不足25人可单独建、联合建或选组织员等。基层、地方和产业组织建立须上级工会批准；单位终止或撤销时相应撤销并报告，外部不得随意撤并。主席作为具备法人资格基层工会的法定代表人，工会及单位和其兴办企业民事责任分别判断。（PDF66、109、114、120）
- 本人自愿申请、基层批准发证；有选举表决、监督罢免建议、依法维权求助及相应服务权利，须履行学习守法、参与、缴费等义务。组织关系随工作关系转接；自由退会。无正当理由连续6个月不缴费不参加，经教育拒不改正才视为自动退会；严重违法犯罪受刑事处分的开除须小组讨论、基层决定、上级备案。离退休失业可保留会籍且免会费。（章程第1–8条，PDF106–107）
- 民主集中、无记名投票、充分讨论候选人，禁止强迫选举；法定或章程组织领导、代表会议、委员替补、经审组织、女职工组织、法律服务机构分别配置。全域与地方代表大会通常5年，地方委员会全会至少每年一次，提前延期依批准；全域执行委员会、主席团、主席会议、书记处与产业组织有分工。（PDF107–109）
- 基层工会会员大会或代表大会至少每年一次；企业工作条例记为每年一至两次。三分之一会员或委员会提议可临时召开；100人以下会员召开会员大会。选举委员会、经审委、批准报告、监督财务和撤换罢免；会员代表常任，任期与工会委员会相同。法律基层委员会任期为3年或5年，2018年章程表述3至5年，适用时按法律和有效章程核对。（PDF66、109–110、115）

把“会员大会”与“职工大会”分清：前者是工会权力机关，后者处理企业民主管理事项，不能相互替代，也不能用股东大会代职代会。（PDF115、118）

## 工会干部保护、职工保障与证据

《工会法》对企业主要负责人近亲属担任基层委员设限制；企业工作条例还将行政负责人、合伙人及其近亲属列入不适任人选，须辨明规范层级和适用范围。职工200人以上单位设专职主席：法律用“可以”，章程及企业工作条例有更具体组织要求；企业专职工作人员一般不低于职工千分之三，人数协商确定，不能一律称法定最低编制。（PDF65–66、109、115–116）

主席副主席任期内工作不得随意调动，确有工作需要须本级及上级工会同意；罢免须全体会员或全体代表过半数，企业条例还要求无记名投票。专职主席副主席委员劳动合同自动延长期相当于任职期间；非专职尚余合同短于任期的延至任满，个人严重过失或达到法定退休年龄除外。2020年解释对专职延长期规定自工会职务任职期届满起算，不能自行把尚余劳动合同期限归零；“个人严重过失”依解释指劳动法严重违纪、严重失职营私舞弊重大损害、被追刑责等，不是泛化的“不配合工作”。（PDF66、117、120）

非专职委员占生产时间从事工会工作，每月不超过3个工作日工资待遇不变；工会活动需占用生产工作时间一般事前获单位同意。专职人员工资奖励补贴由单位支付、社保福利同单位职工。上级工会可派聘人员、培训并保障履职；新任企业主席副主席一年内参训，上级可代行遇阻基层维权职责，违法不履职亦有改正罢免及赔偿责任。（PDF68、111、116–117、119）

参加工会活动或依法履职被解除，书载救济为恢复工作并补发期间报酬，或年收入两倍赔偿。2020年司法解释第6条进一步规定，依当事人请求裁判两倍年收入赔偿，并按劳动合同法第46、47条给予解除经济补偿。不能把特别赔偿与一般违法解除赔偿自行叠加；诉请组合应依适用时点解释核验。违法调岗打击报复可请求改正、恢复原岗、赔偿；阻挠组建、非法撤并、拒绝平等协商等分别由劳动部门、政府处理，涉嫌犯罪另究。（PDF68–69、120）

证据应保留工会批准文件、选举票及会议记录、任期、原劳动合同及未履行期限、专兼职身份、任命调岗解除通知、单位知悉与履职因果关系、收入凭证和上下级工会意见。无关个人严重过错与履职报复不能互相替代证明。

## 民主管理、集体权益与经营权限

工会对不当处分可提意见；单位单方解除应事先通知理由，工会认为违法要求研究时，单位应研究并书面反馈。拖欠工资、安全条件不足、随意延时、特殊保护受侵害等，工会代表职工交涉，拒改可提请当地政府。工会参与伤亡和严重健康问题调查，监督新改扩建安全设施“三同时”；重大隐患可提建议，危及生命可建议撤离并要求单位及时决定。企业工作条例另写可组织撤离，应联查安全生产特别法明确实际权利。停工怠工时工会反映合理诉求、协商并协助恢复秩序，不能据此编造书中未载的权利结论。（PDF66–67、118）

基层工会还承担法律援助、争议调解、工资社保福利、技能竞赛培训、文化教育、困难救助和女职工专项保护；政府制定涉及职工利益政策听取或吸收工会，劳动行政部门、工会、企业代表建立三方协商。（PDF67–68、110、116、118）

企业重要经营发展问题应听取工会意见，涉及工资福利安全工时休假女职工社保会议应有工会代表。职代会具体职权随企业类型不同：国有及控股企业审议经营改制，审议通过集体合同和安置方案、有关规章福利，民主评议与选举；集体企业还涉章程、管理人选、重大经营及合并分立破产；其他企业侧重发展建议、权益方案和重要规章合同审议、履行监督。先看法律授权和当地规定，不能把某类职代会权力移植给所有企业。（PDF67–68、117–118）

书载企业职代会一线代表一般不低于50%；召开须全体代表或职工三分之二以上参加，重要决议选举以无记名、全体过半数通过，注意分母不是到会人数。职工董事监事由工会提名、职代会或职工大会民主选举，对其负责；公司是否设置、人数和替代机制应查适用公司法。厂务公开、劳动监督及劳动保护委员会、风险预警与调解组织各有职责。（PDF117–118）

女会员10人以上建女职工委员会、不足10人设委员，任期与同级一致，主任待遇及人选依企业条例；重点是经孕产哺乳、禁忌劳动、生育保险和健康，重要议题提交职代会，单位工会保障经费。劳动法本体与地方假期标准另见[ch02](ch02.md)。（PDF108–109、118–119）

## 群众监督的办理步骤

2021年《工会劳动法律监督办法》是有组织的群众监督，不等于行政监察，不具有自行行政处罚权。监督覆盖就业、合同全周期、集体协商、工时工资、安全伤亡职业病、特殊保护、培训、保险福利及内部规章，重点关注恶意欠薪、违法加班裁员、未缴社保、体罚强迫、歧视童工健康问题。（PDF112–113）

1. 核监督组织职责：全域、地方、乡镇街道园区、区域行业及单位分别负责；县级以上设监督委员会，基层或职代会设委员会小组，监督员培训合格持证、实名管理，可聘专家律师。上级对重大事项指导，行政专业安全社保监督按专门规定。（PDF112–113）
2. 接投诉留痕并保护实名信息。上级转单位工会调查，30个工作日内反馈职工与上级；不属范围或已由行政、仲裁、法院受理须告知，仍可依法提供支持帮助，不能冒充审判结果。（PDF113）
3. 调查不少于两人，现场如实记录，单位核阅签章、拒签注明；查阅复制限相关资料，尊重个人信息与商业秘密。核实不存在侵权向职工说明；存在侵权先代表协商整改。（PDF114）
4. 协商无果或整改无效，向上一级报告，由本级或上级发书面监督意见；逾期不答或无故拒改，可提请地方工会向政府主管机关发书面建议并移交材料。履职受报复向本级或上级反映，监督经费入工会预算，地方可有非公企业监督员补助。（PDF114）

应用推演：将投诉、事实调查、工会意见、主管机关建议、仲裁代理援助分别建档；投诉转工会不当然中止劳动仲裁或行政救济期限，期限表应独立维护。行政监察、救济见[ch02](ch02.md)、[ch01](ch01.md)；调查个人信息问题可联用cyber-data-law。

## 集体协商：主体、程序及效力

企业集体协商由工会代表职工，与单位平等协商报酬、工时、定额、休息、安全、保险、女职工保护等，可签综合或专项合同。草案经职代会或全员讨论通过，签后报送，主管机关收到15日未异议生效，劳动合同标准不得低于集体合同。签订争议协商不成可由行政部门协调，履行争议可仲裁诉讼，工会依法代表职工要求单位承担责任。（PDF60、63、66、117）

书载企业工会可以聘外部专业代表但不超本方三分之一；小企业集中可区域行业协商，派遣工集中可与企业及劳务公司共同协商。企业收到集体协商书面要约20日不回应，工会可请上级协调；无正当理由拒绝可提请政府处理。企业条例的裁员“同意或否决意见”，应作为工会工作规范理解，不能未经上位法核验就宣告所有裁员以工会批准为生效条件。（PDF117）

2006年区域行业意见针对小企业或同业集中乡镇、街道、社区、园区，条件具备可县区层面开展。职工代表由区域或行业工会选派、主席为首席；企业代表由企业组织行业协会选派或民主推选授权、首席企业方民主选。人数对等，一般每方3–10人；首席书面委托专业人员不得超过本方三分之一。（PDF120–121）

程序链为：书面要约和回应 → 双方广泛征意形成议题 → 协商一致成草案 → 区域职代会或企业职代会、职工大会审议通过 → 企业主签名或公章确认 → 双方首席签署 → 企业方报当地主管机关审核备案 → 15日未异议生效 → 向职工公布。报送还须企业主确认件和职代会通过文件。工资、工时、定额计件标准应具体量化，不把抽象口号当可执行条款。（PDF121）

合同约束辖区内签约企业和职工，企业集体合同不能低于区域行业标准；不把未签约所有企业无条件纳入。签订争议可书面申请或由机关认为必要时三方协调；履行争议按劳动法及集体合同规定。各方负责发展组织、培训代表、完善审核和协调、沟通报告，这是实施保障，不等于新设仲裁机关。（PDF121）

## 经费、财产和司法救济

《工会法》书载已建工会单位按每月全部职工工资总额2%拨缴，另有会费、所属事业收入、政府补助及其他收入；主要用于服务职工和活动，法定经费税前列支。章程另写未建会单位按2%建会筹备金，办理时查其征收依据、地方操作和减免，不混写为法律原文。独立银行账户、预算决算、经审、资产监管及会员报告制度分开设置；经费、财产、不动产不得侵占挪用任意调拨，组织合并归合并后、撤销解散由上级处置。（PDF68、111、119）

企业工会条例还列职教培训费1.5%–2.5%、竞赛奖励1%提取要求，这是所收工作规范，不能据此直接确定现行税前扣除率。单位应提供设施场地、承担规定职工教育劳动保护等费用；上级提供培训法律信息支持、干部权益专项经费及考核保护。（PDF119）

无正当理由拒拖经费可申请支付令；司法解释规定被申请人所在地基层法院管辖，先征询意见，仅争数额时对无争议部分发令。上级工会可申请支付令或起诉，基层可参加成为共同申请人原告；“全部职工”“工资总额”按主管部门标准，不能直接用会员数或缴费基数代替。拨缴诉讼时效援用民法典第188条，支付令申请费和之后财产诉讼费分别依交纳办法。侵占工会经费财产可诉返还赔偿，单位与工会法人责任应分开。（PDF68–69、120）

应用推演：某单位以“员工未全入会”缩减拨缴基数。先核工会成立批准、单位工资总额口径和欠缴期，再分无争议及争议数额；可请求支付令并准备争议转诉材料，同时保护会员信息。不能仅凭工会章程的组织权利，免除证明拨缴依据、数额和时效的义务。
