# 实务模块12：职业病防治、劳动防护用品与职业健康监护

来源：《劳动和社会保障法律法规全书》2022年版（2021.12第8版，ISBN 978-7-5216-1794-8），PDF317—326、346—356、370—387。覆盖书载职业病防治法、有毒物品与尘肺专项规则、劳动防护用品规范、职业卫生监督、体检与健康监护规则。模块编号与实务步骤为自编；原书为规范汇编，其分节为编者整理，本部分未见可据以重构的完整事实案例。

## 责任主体与三条分流〔自编应用〕

先建立“单位与用工身份—岗位与工艺—危害因素—接触起止—检查诊疗—合同状态”事实表。

1. **作业风险治理**：存在危害即须预防，不待确诊。单位主要负责人全面负责，工会参与监督；劳务派遣用工单位履行职业病防治法规定的用人单位义务。发包给无防护条件者与接受该作业者均有违法风险。（《职业病防治法》第1—42、85—88条，PDF317—321、325—326）
2. **健康检查与禁忌处理**：职业健康检查是针对危害因素的上岗前、在岗、离岗及应急监护；普通福利体检不当然替代。异常可能要求复查、医学观察、调离，而非一见异常就等于确诊职业病。（PDF375—380）
3. **诊断、鉴定与待遇**：职业史、危害接触史和临床证据交由法定医疗机构综合判断；劳动关系争议、诊断争议、工伤及民事请求分别进入相应程序。职业病目录内疾病与一般工作相关不适须区别，但不得仅以缺少单位检测报告拒绝进入诊断。（PDF321—323）

## 全过程预防：先工程控制，再个人防护〔书载规范〕

《职业病防治法》（2018年修正版，第1—88条，PDF317—326）及《工作场所职业卫生管理规定》（2020年发布，第1—60条，PDF381—387）：

- **设立与建设**：危害强度浓度达标，有害无害分开、工作生活分开且工作场所不得住人，配防护设施、更衣洗浴及孕妇休息等卫生设施。可能产生职业危害的项目在可研阶段预评价，防护设施纳入预算并与主体工程同时设计、施工、投用；竣工前控制效果评价。医疗机构放射性项目有卫生部门审核、严重项目设计审查和防护设施验收的特殊路径，其他项目由建设单位依法组织验收，不能用旧一律行政审批文字取代。（PDF318—319、382）
- **制度人员与经费**：职业病防治责任、警示告知、申报、培训、防护设施与用品、监测评价、建设“三同时”、监护档案、事故报告应急及岗位规程均须落实。危害严重单位配专职职业卫生人员；其他存在危害单位超过100人须设或指定机构并配专职，100人以下可专职或兼职。经费不得挪用，相关费用按规定计入成本。（PDF319、321、381—382）
- **申报、日常监测和定期服务不能互代**：存在目录所列危害因素即按规定如实申报；专人负责日常监测。书载危害严重单位每年至少检测一次、每三年至少现状评价一次，一般单位每三年至少检测一次；事故等情况另须及时现状评价。检测评价由相应资质机构承担，结果存档、报主管部门、向劳动者公布，并落实整改；一般频次不能覆盖高毒等专项较严要求。治理仍不达标必须停相关作业，达标后才能恢复。（PDF319、383）
- **告知与防护**：劳动或聘用合同写明危害、后果、防护措施与待遇；转岗新暴露要重新告知并协商变更，不告知时劳动者可拒绝危险作业且不得因此解约。公告栏公布制度、应急措施和检测结果，严重岗位醒目警示，高毒岗位设告知卡。供应设备化学材料须中文说明、安全标识；不合要求、明令禁止的设备材料不得使用；优先低危新技术，不得故意隐瞒危害。（PDF319—320、382—384）
- **事故控制**：急性有毒有害场所须报警、急救、冲洗、撤离及泄险设施；密闭或半密闭可能大量泄漏场所另有事故通风与联锁报警。放射场所标志、联锁、剂量与辐射监测设备、个人剂量计有专门要求。经常维护检修，不能擅拆停用。急性危害发生或可能发生，立即救治检查观察、控制并及时报告，费用由单位承担，保护现场证据。（PDF319—320、382—384）

劳动者享有培训、防治服务、知情、防护、建议监督、批评举报及拒绝无防护冒险作业权；合法行权遭降薪、解约等行为无效。劳动者亦须遵章、正确维护使用用品、接受培训并及时报告隐患。未成年工不得接触职业危害，孕期哺乳期不得安排危及本人及胎婴的作业，有禁忌者不得从事禁忌作业。（PDF320—321、384）

## 有毒物品与粉尘的专项分支

**《使用有毒物品作业场所劳动保护条例》**（第1—71条，PDF346—354）区分一般有毒与高毒，先按目录确定，优先无毒或低毒替代；童工禁用，未成年人及孕期哺乳期女工不得从事有毒作业。普通有毒区域黄色警示线，高毒红色警示线并配通讯报警；高毒与其他作业隔离、设撤离与泄险区、必要医疗卫生服务及应急队伍物资。高毒项目申报另交控制效果评价、制度规程和预案，品种变化重新申报，名称负责人变化有备案要求。（PDF347—348）

高毒装置检修要预先方案、专人监护、警示；进入高毒设备、容器或狭窄封闭空间前须通风达标、合格用品、监护和救援设备，措施不具备不得安排进入。防护与报警异常即停相关作业；书载高毒至少每月检测、每半年控制效果评价一次，超标立即停止高毒作业，治理达标后恢复。淋浴、更衣和污染工作服处理专间，工作服鞋帽不得带入非高毒区；岗位轮换、津贴、停产转产破产时残毒设备容器妥善处置也属于单位责任，不能只发口罩。（PDF348—349）

专项条例同样要求上岗、在岗、离岗和急性暴露体检，禁忌调离、复查医学观察、免费签章档案复制及危险撤离待遇保护。未参保单位承担职业病工伤待遇；无照或被吊照的按有关标准一次性赔偿，分立合并由承继单位承担，解散破产优先清偿相应补偿。其第41条旧工伤支付主体、月数和金额后附“项目标准调整从其规定”，**不得引用该旧表直接算待遇**。（PDF349—351）

条例的职业卫生安全许可、建设行政审批、旧刑事罪名与处罚有历史文本风险；使用时对照职业病防治法、审批改革及现行部门权限。监督包括现场取证抽样、资料复制、临时停作业封物控制现场、消险后解除、举报保密、罚缴分离；违法责任分别覆盖建设、防护、培训用工、许可、残毒处置、申报告知、监护档案，不以支付赔偿替代整改。（PDF351—354）

**《尘肺病防治条例》**（第1—28条，PDF354—356）适用有粉尘作业的企业事业单位：综合防尘和低尘替代，防尘经费专用，不得向无设施单位外包转嫁；中小学校办实习工厂车间禁止粉尘作业，未满18岁禁止从事；新接尘工须教育考核、健康检查。定期测尘、报告公布及建档，岗前在职离职检查；确诊者调离粉尘岗位并治疗疗养。浓度超标且未积极治理、严重影响健康时职工有权拒绝操作。拆防尘设施、隐瞒测尘诊断、强令患者继续接尘、挪用经费等有处罚风险。旧审批与15日复议等文字不能覆盖较新上位法，诊断和粉尘限值须查官方适用标准。

## 劳动防护用品：选择到报废〔书载规范〕

《用人单位劳动防护用品管理规范》（2018年修订，第1—27条，PDF370—372）将个体防护定位为辅助预防措施，**不得替代工程及其他技术管理控制，不得发钱或其他物品替代配发**。派遣、实习纳入统一配备，作业现场其他外来人员按相同防护标准使用。

书载类别覆盖头部、呼吸、眼面、听力、手、足、躯干、护肤、坠落及其他用品。按“识别—评价—选择”并结合劳动强度、个人特征决定；粉尘类型浓度及游离二氧化硅、毒物种类浓度影响呼吸器选型；噪声暴露80—不足85dB按需求配护听器，85dB以上必须配发并指导，具体测量指标是八小时等效声级，不能用任意瞬时读数代替。放射危害经评价确认所需用品，多种危害须同时防御且相互兼容，流动作业应满足所有地点需求，考虑贴合与舒适。（PDF371—372）

单位应形成危害对应配备标准、采购计划，保存产品检验等质量证明，发放登记、使用维护培训、用前检查、定期使用检查；公用品统一保管维护，急救用品就近有标识且定期检测，流动巡检携带应急防护。按有效期限和最低防护功能及时更换，损坏即时补发，安全帽、呼吸器、绝缘手套等到期强制报废。（PDF372）

本规范引用GB2626、GB/T18664、GB/T24536、GB/T29512、GB/T28409、GB/T23466、GB/T29510、GB/T11651、GB/T30041、GB/T23468及煤矿AQ1051等。**这些是书载标准编号索引，未逐一核版本和替代关系；选型必须在官方标准平台查生效版本、适用范围和产品参数，不能按本章远程指定呼吸防护等级。**四个附件（选择程序、呼吸器护听器选用、配备标准、发放表）原书均“略”，本模块没有声称读到附件内容。

## 检查机构与用人单位各自的监护责任

依据《职业健康检查管理办法》（2019年修正，PDF375—378）和《用人单位职业健康监护监督管理办法》（2012年，PDF378—381）：

| 责任方与节点 | 条件、程序及证据 |
|---|---|
| 机构准入与能力 | 书载2019年办法采用开展后15工作日内省级备案；许可、放射诊疗资格、场所人员仪器、生物监测与质量制度匹配类别项目，信息变化10工作日内提交。主检医师具执业资格、中级以上职称、职业病诊断资格及相关工作三年以上。2012年监护办法仍写省级批准，不能不处理版本差异就索要旧批准证。（PDF375—378） |
| 分类和项目 | 粉尘、化学、物理、生物、放射、其他特殊作业六类，机构不得超备案类别项目。与单位签委托或凭单位介绍信；单位提供危害种类、接触名册、工种接触时间及检测资料并付费。项目周期据危害及GBZ188、放射GBZ235等**适用版本**确定，外出检查有地域、影像及生物安全要求。（PDF376—377） |
| 岗前、在岗、应急 | 新录用、转入接触危害及特殊健康要求岗位先检；在岗定期检查，按建议复查、医学观察。出现与暴露相关不适或急性中毒症状立即应急检查，检查视同正常出勤。身份必须真实，不得安排冒名体检。（PDF378—380） |
| 离岗 | 书载离岗前30日内安排，离岗前90日内在岗检查可视为离岗检查；未经离岗检查不得解除终止合同。该规则与具体危害项目匹配、现行标准及新规定须复核，不宜把任何一次90日内体检都视为足够。（PDF379） |
| 结果闭环 | 机构书载检查结束后30工作日内向单位书面报告个人及总结结果；单位书面如实告知劳动者。疑似职业病告知本人、通知单位并报告卫生主管部门；禁忌亦告知双方。单位按报告分别调离、安置、复查、观察或安排诊断，并改善岗位防护。（PDF377、379） |
| 档案两层 | 机构检查档案含委托、单位资料、报告告知等，最后一次检查结束起至少保存15年；**不将这一保存期直接套给单位个人监护档案**。单位保存职业史、接触史、检查处理、诊疗资料，依法查阅复印、离职免费签章提供，分立合并解散破产移交保管并安置病人。（PDF377、379、384） |

机构保护隐私和知情权，质量控制包括实验室比对、质量考核；监管检查类别范围、外出、报告和档案，虚假证明、未备案、未告知、未报告、主检不合格或质量整改不到位分别承担责任。单位的监护制度经费、资料真实性、落实建议、费用、档案和禁忌岗位安排亦独立受监管。（PDF376—380）

## 职业病诊断：单位不交材料不等于程序终止

《职业病防治法》第43—61条（PDF321—323）：

- 可以选择单位所在地、本人户籍地或经常居住地的依法承担诊断的医疗机构；具备执业许可、相应人员设备及质量制度的机构不得拒绝劳动者诊断要求。结合职业史、危害接触及工作场所因素、临床与辅助检查；无法以证据否定危害因素与临床表现必然联系的，依书载条文诊断为职业病，具体判断由专业机构依诊断标准作出。
- 用人单位如实提供职业史接触史、检测结果，监管督促；需要现场调查时机构可自行调查或请求卫生部门，书载卫生部门10日内组织。单位拒交资料时，结合临床检查、职业接触史、劳动者自述及日常监管信息诊断；资料争议或单位解散无资料时提请卫生部门调查，书载30日内判定。
- 劳动关系、工种、岗位、在岗时间争议可申请劳动人事仲裁，书载30日裁决；单位掌管证据而拒供承担不利后果。劳动者不服可依法诉；单位不服须在职业病诊断鉴定程序结束后15日内起诉，诉讼期间治疗费依职业病待遇途径支付。不能用劳动关系争议拖延必要救治。
- 诊断异议进入所在地卫生部门组织的市级以上鉴定，再不服可省级再鉴定；专家随机抽取、利害关系回避，出具鉴定书，诊断鉴定费用由单位承担。**不要把诊断鉴定与伤残等级鉴定混成同一程序。**
- 疑似病人及时安排诊断，诊断和医学观察期间不得解约终止，相关费用单位承担；确诊后治疗康复、定检，不宜继续原岗的调离安置，接触危害作业依法给予适当津贴。未参保单位承担医疗生活保障；换单位不减待遇，分立合并解散破产妥善安置；单位不存在或无法确认关系者可向医疗保障、民政等申请医疗生活救助。工伤待遇外的民事赔偿仍须具体法律基础。

## 监督检查、风险与交付材料〔自编应用〕

《用人单位职业卫生监督执法工作规范》（2020年，PDF372—375）以随机公开、重点和信用监管结合，要求公示、全过程记录、重大决定法制审核及分级风险监管。检查12类事项：管理制度、建设、申报、监测评价、告知警示、防护、培训、健康监护、病人报告处置、外包、急性事故、放射作业。方法不止看制度文本，还抽查现场人员、离岗名单、合同、复查调离、维修、剂量监测和事故资料，必要时延伸检查服务机构；派遣同样检查。发现问题出监督意见，违法查处，犯罪移送，重大案件上报并依法信用公示。（PDF373—375）

《职业病防治法》责任章和《工作场所职业卫生管理规定》罚则分开覆盖：建设缺陷、管理档案、申报告知监护、浓度防护及拒交资料、隐瞒危害或违法转移、职业禁忌、已经严重伤害、供应设备材料、病人报告以及服务机构和监管失职。后果可能包括警告整改、罚款、停作业、停建关闭、取消资质及民刑责任，不能仅按最低罚款作成本预算。执法临时停作业、封存和控制现场有条件，危险有效控制后应解除；当事人应配合并可依法救济，具体罚额和期限回核现行法。（PDF323—326、385—387）

建议每次输出四组材料：①危害清单、暴露人员与工艺岗位映射；②建设评价验收、申报回执、监测和用品设备记录；③分阶段检查、书面告知、复查调离与档案交接；④诊断所需职业接触证据、费用与劳动合同保护、监管和争议程序节点。只提供必要范围的健康信息，避免把健康档案当作全员公开信息。作业事故和应急责任见[模块11](ch11.md)，检查出勤与休假关系见[模块10](ch10.md)。
