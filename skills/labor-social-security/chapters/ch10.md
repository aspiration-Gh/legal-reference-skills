# 实务模块10：工时、休假与医疗期

来源：《劳动和社会保障法律法规全书》2022年版（2021.12第8版，ISBN 978-7-5216-1794-8），PDF296—302页。模块编号为本知识库自编编号。本批页码均指PDF文件页，不是印刷页。

**使用规则：先定位书载依据，再按事实发生时间、人员身份和所在地核验官方适用版本。下列“书载规范”不等于现行结论；“自编应用”是工作步骤。汇编的分节、标题归类属于编者整理，并非作者提出的理论模型。**

## 先分身份与时间，再核工时制度〔自编应用〕

收集劳动或聘用关系、单位性质、岗位、连续与累计工龄、当前单位工龄、特殊工时批件的岗位范围和有效期、排班考勤、休假审批及实际休假记录。不能把机关事业单位工作人员规则直接套给所有劳动合同人员，也不能把合同写着“弹性工时”等同依法获批特殊工时。

- **标准工时**：书载《职工工作时间的规定》为每日8小时、每周40小时；特殊劳动条件的缩短工时按专门规定处理。机关事业单位原则统一双休日；企业及不能统一安排的事业单位可灵活安排周休息日。历史延期实施条款只说明制度沿革，不能继续援引延期。（PDF297—298）
- **不定时工时**：适用候选包括高管、外勤、推销、部分值班、长途运输和其他无法用标准时间衡量或需机动作业的人员；须核实际岗位及审批。**综合计算工时**：连续作业、季节或自然条件限制等岗位，可以周、月、季、年为周期，平均日、周工作时间应与法定标准基本相同。两者均须保障健康、充分听取职工意见，安排集中休息、轮休等，不能据此取消休假。（《特殊工时审批办法》，PDF301—302）
- 书载中央直属企业与地方企业审批路径不同；使用时查现有主管机关、地方权限及批件。机关事业单位的特殊工时另循人事审批体系；不能执行统一休息时间的轮班安排有备案要求。严重灾害、事故或紧急任务延长工作时间后应安排相应补休。（机关事业单位工作时间实施办法，PDF300—301）
- 本节未完整列明一般加班工资规则。计算加班费还须联读工资模块，核标准工时、综合周期超时、不定时的地方规则及法定节假日性质，不能仅凭本节推定免付。

## 年休假：资格、排除、安排与结算〔书载规范〕

依据《职工带薪年休假条例》（PDF296—297）、《企业职工带薪年休假实施办法》（PDF298—299）、《机关事业单位工作人员带薪年休假实施办法》（PDF299—300）。

| 判断节点 | 会改变结论的条件 |
|---|---|
| 资格与天数 | 连续工作满一年是资格，累计工作时间决定档位：满1年不足10年5天、满10年不足20年10天、满20年15天。企业累计工作包括不同单位任职及依法视同工作期间；不能只算本单位工龄。机关事业单位按工作年限，满相应档位后从下月起享受对应天数。 |
| 不计入假期 | 法定休假日、休息日不计入年休假；企业办法另明确探亲、婚丧、产假及因工伤停工留薪期间不计入。 |
| 当年排除 | 依法享受寒暑假且天数多于年休假；事假累计20天以上且按规定不扣工资；累计工龄1—不足10年、10—不足20年、20年以上分别累计病假2、3、4个月以上。不能省略“事假不扣工资”条件。 |
| 已休后又触发排除 | 已休当年年休假后又出现前述事假或病假情形，不享受下一年度年休假。寒暑假因工作需要不足的，应补足差额。 |
| 统筹安排 | 考虑本人意愿，可集中或分段，一般不跨年。企业确因工作需要不安排或跨一个年度安排，应征得本人同意；机关事业单位另有特殊任务跨年度安排规定。 |
| 未休工资 | 企业经同意不安排或少安排，按日工资300%支付，**已含正常工作工资**，在本年度内支付。企业已安排而职工因本人原因书面提出不休，可只付正常工资；不能用空白放弃书代替实际安排与本人原因。 |
| 优于法定的承诺 | 企业劳动合同、集体合同、规章制度给出更高天数或工资待遇的，按更高约定或规定执行。 |

**企业折算**：新进单位且已具备连续工作资格的，用“当年本单位剩余日历天数÷365×全年应享天数”，不足整天不享受；离职结算用“当年本单位已过日历天数÷365×全年应享天数－已安排天数”，不足整天不支付，已经多安排的不扣回。月工资取支付前12个月剔除加班工资后的平均数，不满12个月按实际月份；日工资按月工资÷21.75。计件、提成或绩效工资同样适用该口径。以上为书载公式，实算须用工具并核适用标准。（PDF298—299）

**派遣例外**：劳动合同期限内无工作而由派遣单位依法付薪的天数，多于全年年休假天数时不享受当年年休假，少于时由派遣与用工单位协商补足。原文“多于／少于”未单列等于情形，不擅自补成明文规则。机关事业单位、社会团体中建立劳动关系人员，除另有规定外依企业办法；船员另查专门条例。（PDF299）

**机关事业单位结算不同**：书载全年应发工资收入÷261；工资组成与企业办法不同，住房、用车改革直接货币补贴不计入所称津贴补贴。300%中除正常工资外的部分，于次年第一季度一次支付。已安排而因个人原因未休，或事假超过应休年休假但不足20天，只享受正常工资；不能把这项事假例外用于企业。（PDF300）

**程序与证据〔自编应用〕**：制作“资格工龄—排除假期—统筹安排—本人意见—实休—工资结算”台账，保存社保或任职证明、病事假记录、通知送达、书面不休申请、工资组成及离职日期。未安排且未支付的行政处理先责令改正，逾期可加付同额赔偿金；强制执行及纪律处分路径因单位身份不同。企业争议循劳动争议程序，机关事业工作人员按申诉控告或人事争议途径，不能把行政加付赔偿直接视为所有仲裁案件自动支持。（PDF296、299—300）

## 法定节假日与探亲假〔书载规范及有限更新〕

《年节及纪念日放假办法》书载2013年修订版区分全体公民、部分公民和地方民族习惯节日；全体公民假日遇周末应补假，部分公民假日遇周末不补假，其他列举纪念日不当然放假。妇女节半天、青年节适龄青年半天、儿童节适龄儿童一天、军人纪念日现役人员半天，先核对象及专门口径。（PDF297）

**已核验的版本变化**：[第795号令修改决定](https://app.www.gov.cn/govdata/gov/202411/12/521605/article.html)自2025年1月1日起将春节改为4天（含除夕），劳动节改为2天，并增加假期前后连续工作一般不超过6天、个别特殊情形除外的安排原则。因此书载春节3天、劳动节1天不可用于该时点以后的判断。具体年度还应核放假调休通知，区分法定假日与调休日。本次未逐项核验其他休假规则截至使用日的全部修订。

《职工探亲待遇的规定》有严格主体边界：机关、人民团体、全民所有制企业事业单位工作满一年的固定职工，与配偶或父母远居且不能利用公休假团聚；能与父母一方团聚的，不适用探父母待遇。书载探配偶每年一方30天；未婚探父母原则每年20天，工作需要未安排或本人愿两年一次可45天；已婚探父母每四年20天。含公休与法定节日，另给必要路程假；实行休假制度者原则利用原休假，不足适当补足。假期及路程期按标准工资；探配偶、未婚探父母往返路费单位负担，已婚探父母本人月标准工资30%以内自理，超过部分单位负担。集体单位及地方细则另核，不能推广为全体企业统一待遇。（PDF298）

## 患病或非因工负伤医疗期〔书载规范〕

《企业职工患病或非因工负伤医疗期规定》（PDF301）保护的是停工医疗期间的劳动合同，不等于医生每张病假单的天数，也不等于一切解除事由都被排除。先按实际工作年限及本单位工龄确定档位，再以法定累计观察区间核病休：

- 实际工作不足10年：本单位不足5年为3个月，满5年为6个月；实际工作满10年：本单位不足5年、5—不足10年、10—不足15年、15—不足20年、20年以上分别对应6、9、12、18、24个月。原文该行抽取错序，临界工龄措辞须回核官方原件。
- 3、6、9、12、18、24个月医疗期分别放在6、12、15、18、24、30个月内累计。病假工资、疾病救济和医疗待遇按相关规定另核。
- 书载非因工致残、难治疾病的医疗终结或医疗期满后劳动能力鉴定，以及退休退职、岗位安排和经济补偿另有条件。**不可直接照搬旧文办理退休或解除**；须结合现行解除保护、病残津贴及退休制度。保存医疗材料、病休起止、工龄证据、另行安排工作和能力鉴定记录。
