# 实务模块11：安全生产责任、行业控制与事故处理

来源：《劳动和社会保障法律法规全书》2022年版（2021.12第8版，ISBN 978-7-5216-1794-8）。本模块整合书载“劳动安全—综合、事故处理”，对应PDF302—317、326—346、356—370、387—405；共享页的职业卫生内容另见[模块12](ch12.md)。模块为自编实务分组，非原书章号。

## 责任不能随委托、发包和投保转移

《安全生产法》书载2021年修正版（第1—119条，PDF302—313）适用于生产经营单位，包括平台等新兴行业；消防、交通、核与辐射、特种设备等另有法律行政法规规定的从其规定。监管按综合与行业分工衔接，权限不明的新业态由地方政府按业务相近原则确定监管部门。标准的制定、强制性标准实施、协会与技术服务、公众举报和工会监督共同构成预防体系。

- 主要负责人为第一责任人，负责全员责任制、制度规程、培训计划、投入、风险分级与隐患治理、预案、及时如实报告；其他负责人对职责范围负责。委托专业服务，安全责任仍由单位承担。全员责任制须写明岗位责任人、范围、考核，不能只有负责人签字。（PDF302—304）
- 矿山、冶炼、施工、运输及危险物品生产、经营、储存、装卸单位须设安全机构或专职人员；其他单位超过100人须设机构或专职人员，100人以下配专职或兼职。特定高危单位管理人员考核、注册安全工程师、任免告知等分别适用，不把各类主体合并成同一清单。（PDF304—305）
- 派遣劳动者纳入用工单位统一管理和岗位培训，派遣单位另负必要培训义务；实习学生也应培训并获防护用品，学校协助。新工艺、技术、材料、设备要专项培训，特种作业须取得相应资格后上岗。（PDF305）
- 同区域交叉作业：安全协议、明确措施、指定专职协调人员。发包出租：审资质和安全条件，约定职责，发包出租单位统一协调、定期检查并督促整改；特定高危建设不得违法转包、分包或转让资质。发给不具备条件者导致事故损害，可与承包承租方承担连带赔偿。（PDF306、312）
- 工伤保险必须依法参加；规定的高危行业领域应投保安全生产责任保险。劳动合同载明安全、防职业危害与工伤事项，免除减轻事故伤亡法定责任的协议无效。工伤待遇外是否尚有民事赔偿权，须再核独立请求基础，不能一律重复计算。（PDF306—307、312—313）

## 从建设到停复工的控制链〔书载规范＋自编核查〕

| 场景 | 规范要求与应留材料 |
|---|---|
| 建设项目 | 安全设施与主体工程同时设计、施工、投用，预算单列；特定矿山、冶炼和危险物品项目须安全评价、设计审查，按批准设计施工，由建设单位组织验收合格方可投用，监管部门监督核查。留评价、批件、变更、施工与验收资料。（PDF305） |
| 设备与危险作业 | 警示、定检和签字维护记录；不得关闭破坏监控报警救生设备或篡改数据；餐饮燃气设报警装置；特定容器运输工具及设备依法检验和取得使用标志；淘汰目录禁用。爆破、吊装、动火、临时用电专人现场管理，危险物品另依专项许可。（PDF305—306） |
| 人员与场所 | 如实告知危害与应急措施，关注身体心理状态，提供合格用品并监督使用；危险品车间仓库与宿舍不得同楼，疏散出口通道不得占锁封堵。劳动者可拒绝违章指挥、强令冒险；直接危险可停止作业或采取可能措施后撤离，不得因此降薪解约；劳动者亦须遵章、防护、培训及报告隐患。（PDF306—307） |
| 风险、危险源、隐患 | 风险分级管控；重大危险源以危险物数量达到临界量等辨识并建档检测监控、备案与应急告知；隐患是物的危险状态、人的不安全行为或管理缺陷，不能以“重大危险源”替代“重大事故隐患”判断。（PDF306、313、356） |
| 治理闭环 | 一般隐患立即整改；重大隐患由主要负责人制定目标、措施、资金物资、人员、时限、安全措施与预案，报告现状成因和治理方案。无法保证安全先撤人停产；自然灾害有预警、撤离、停工和监测要求。挂牌停产隐患完成评估后书面申请复产，经审查同意再恢复，留整改指令、治理及评估报告、复产决定。（PDF356—358） |

《隐患排查治理暂行规定》还载每季、每年统计分析及负责人签字，分别于下一季度15日前、次年1月31日前报送；重大隐患另须及时报告，不能等统计期。监管移送、挂牌、台账、现场复查、核销与中介虚假评价责任均需闭环；书载复产申请后10日现场审查及处罚金额，使用前核上位法和最新实施规则。（PDF357—358）

## 行业与许可的附加控制

**矿山**：《矿山安全法》（PDF313—317）及实施条例（PDF334—341）贯穿勘探资料、可研论证、安全专篇、设计审查、施工验收、开采与闭坑。核地质断层与老窑积水、瓦斯、放射性和热害资料；至少两个独立能行人直达地面出口及各生产水平出口连通；通风、支护、边坡、供电提升、防排水、防火防爆、防尘、尾矿与排土场、安全隔离矿柱及通信救护成套检查。小型非沼气矿的自然通风是附条件书载例外，不泛化到所有矿山。不得越层越界、损坏保留矿柱、带电检修；特殊瓦斯突出、冲击地压、水体下等开采需专门设计；有出水征兆等情形应探水前进；闭坑仍须处理采空区、封闭与残余风险。（PDF335—338）

矿长负责制度、跟班检查、供应、培训、灾害预防与报告，并向职代会报告重大决策与事故处理；新井下工书载72小时培训、师傅带领满4个月再次考核，露天新工40小时、在职每年20小时，培训有工资与档案；女职工、未成年人不得安排井下劳动。应急计划、演习、邻矿救护协议及专项安全经费均有要求。（PDF315、338—340）**矿山检测频率、空气成分和温度、经费比例、事故24小时报告、90—180日调查及旧15日救济条款均需核适用新规，不当作现场作业数值指令。**特别是报告还须与本模块一般事故1小时制度衔接，不能因旧文迟报。（PDF337—341）

书载《预防煤矿生产安全事故的特别规定》（PDF341—345）覆盖无证生产、重大隐患停产、季度排查、复产验收、关闭与人员安置；重大隐患类别含超能力强度定员、瓦斯与突出、抽采监控通风、水害、越界、冲击地压、自燃、禁用设备、供电、边建边产、违法承包及改制责任不明。另有培训持证、带班下井档案、免费安全手册、举报奖励、禁止违规入股、执法与处分救济及同一行为不得重复罚款。**已核验更新**：[《煤矿安全生产条例》第76条](https://www.gov.cn/gongbao/2024/issue_11186/202402/content_6934550.html)自2024年5月1日起施行并废止该特别规定。因此上述内容仅供历史案件定位，现案应改查新条例、隐患判定及矿山安全规程。

**安全生产许可证**：《安全生产许可证条例》（PDF345—346）适用矿山、建筑施工、危险化学品、烟花爆竹、爆炸物品生产企业，机关按行业分工，煤矿以矿井为单位取证。审责任制度、投入机构、人员资格培训、工伤保险、场所设施职业防护、安全评价、危险源及应急；书载45日审查、有效期3年、期满前3个月申请延续。有效期内守法且无死亡事故，经原机关同意才可免复审延期，不能自动续证；不得降低条件、转让冒用伪造。无证或过期生产有停产、没收和罚款风险，监管失职也追责；旧监管机关名称需更新核实。

**特种设备**：《特种设备安全法》（第1—101条，PDF326—334）先按目录确认锅炉、容器管道、电梯、起重、索道游乐、厂内机动车等是否适用；军事、核设施及航空航天器设备不适用，井下、船舶、机场及建筑市政工地部分设备另由行业监管。全生命周期均需人员资格与安全技术规范：

- 生产许可、特定设计鉴定与型式试验，施工前告知，监督检验，交付技术档案；验收后30日内移交资料；同一性生产缺陷主动召回。新材料新技术与规范不符或未规定且可能重大影响安全的，须技术评审批准后使用。（PDF326—327）
- 销售验收台账、进口合规检验及中文资料和提前告知；出租期间使用管理及维保原则由出租方承担，法律或约定另有安排除外。共有设备受托物业等承担使用管理责任，未委托时由共有人或实际管理人承担。（PDF327—328）
- 投用前或投用后30日内登记；有效期届满前一个月申请定检；未检或不合格不得继续用；日常自行检查不替代法定检验。异常先全面检查消险，达到报废条件消除使用功能并注销；达到设计年限但不属法定报废的，须检验或评估、变更登记并加强维保。（PDF328—329）
- 电梯制造方跟踪、安全告知，维保方需许可并负责应急；索道游乐每日试运检查；锅炉介质处理和清洗检验；移动容器气瓶充装许可、前后检查与使用指导各有责任。（PDF329）
- 检测机构核准、人员资格、独立真实与保密，严重隐患告知并报告；监管许可程序、两人持证检查、书面监察指令、拒签记录、禁止重复许可检验。事故专项预案和专门分级调查路径不同于一般事故，不能机械套用一般管辖。违法可停产停用、没收罚款、吊证禁入、民刑责任；财产不足时民事赔偿优先。（PDF329—334）

## 培训、举报、信用与行政争议

《生产经营单位安全培训规定》（PDF362—366）区分主要负责人、安全管理人员、特种作业和其他人员。书载负责人管理人员初训32学时、年复训12；煤矿、非煤矿山、危化、烟花爆竹、冶炼等为48／16；新工24，高危类新工72、年复训20。加工制造等岗前厂矿—车间—班组三级培训，调岗或离岗一年以上返岗须车间班组重训，新技术设备等针对性重训；委托机构不能转移培训责任，培训支付工资和费用，档案记录时间内容、人员与考核，现场抽考验证实际能力。六个月内任职考核等条件与行业新规逐一核，不把上述数字替代最新培训要求。

《非法违法行为查处办法》（PDF358—361）区分无许可或失效许可的“非法”与违反法定要求的“违法”，覆盖实名匿名线索核查、受理告知、保密、跨区域协作、强制与处罚、证照移送、执行及公示；原文按上限处罚及旧裁量表不得直接替代现行法定裁量。《失信联合惩戒实施办法》（PDF361—362）包括事故、无证、隐患冒险、抗拒监管、瞒报、未验收、越界和虚假报告等纳入条件，审核公布、异议处理、书载一年期限及申请移出。附件汇总表和合作备忘录原书均“略”；使用时另核现行严重失信名单、信用修复和惩戒清单。

《从业人员安全生产举报处理规定》（PDF362）为本单位职工举报重大隐患或违法行为提供专门路径：真实姓名及有效联系方式、核查反馈、管辖移送、奖励时证明从业身份；信息和奖励严格保密，防报复并回访。它的实名要求不能抹去其他办法中匿名具体线索核查机制。不得捏造、诱导违法或诬告。自编取证建议：固定实际危险、已报告对象与时间、监管回执、工作身份和后续降薪解约证据，避免传播可识别举报人的资料。

《安全生产行政复议规定》（PDF366—370）书载处罚、强制、许可和不履责等范围；对事故调查报告、隐患认定、公告等有排除文字，管辖、受理与工作日算法也属旧体系。**现案必须查适用时点《行政复议法》及行为是否实际影响权益，不直接依旧排除条款拒绝救济。**可复用的证据组织是：确认作出机关和送达；整理请求、利害关系、事实；机关提交作出行为时证据依据，补证有条件；申请人举证不履责请求、损害等；材料编号说明来源与证明目的，复印件核对原件。重大复杂案件听证、现场调查鉴定、撤回、有限和解调解、改变原行为后继续审查、赔偿及返还财物各有条件；旧文禁止在请求范围内作更不利决定，不能未经现行法核验就套用全部期限。（PDF368—370）

## 事故发生后的并行任务

依据《事故报告和调查处理条例》（PDF387—391）、《事故应急条例》（PDF391—395）、《事故信息报告和处置办法》（PDF395—397）、《应急预案管理办法》（PDF397—401），以下是书载规则的自编执行顺序：

1. **救人、撤离与控制危险立即启动。**负责人组织救援，通知可能受影响者，维护现场并向救援队提供技术资料；不得以调查、投保或审批等待延误救援。统一指挥亦须保护救援人员，直接危险可暂撤。应急救援费用原则由责任单位承担，无力承担由政府协调；征用财产归还与依法补偿另处理。（PDF393—394）
2. **首报和续报同时建时间轴。**现场人员立即报负责人，负责人接报1小时内向属地监管及有关部门报告，紧急可直接报；较大以上事故另有同步省级报告。情况不清先报概况再补报，不等最终责任认定。报告含单位、时间地点现场、经过、伤亡及失踪涉险、初估损失、措施；一般／较大／涉险每日至少续报一次，重大／特别重大至少两次；伤亡变化一般30日内、道路交通火灾7日内及时续报。（PDF388、395—396）
3. **先定行业与等级，再定调查权限。**一般制度的死亡、重伤、经济损失任一指标触及更高等级即核该等级：较大起点3死／10重伤／1000万元，重大10死／50重伤／5000万元，特别重大30死／100重伤／1亿元；“以上”含本数、“以下”不含。急性工业中毒计入重伤；行业补充规定优先查。重大、较大、一般分别原则由省、市、县政府调查，特别重大由中央行政机关或授权部门；无伤亡一般事故可由县政府委托单位调查，不能自行宣布有权调查。（PDF387—389）
4. **无伤亡也核较大涉险。**书载涉险10人以上、被困或失踪3人以上、疏散500人以上、严重环境影响、危及重要场所设施等均可能需报；不要把“没有死人”当免报理由。（PDF397）
5. **保全与配合。**救人或疏通需要移动物件时标记、绘图、书面记录，保存原始监控、设备和作业数据；负责人不得擅离，调查材料不得拒绝提供。一般调查报告60日，可批准延长最多60日，技术鉴定不计；批复、处罚、处分、刑事移送和整改分别履行。事故调查与报告公示依法保密，不能将旧信息发布限制解读成禁止依法举报。（PDF388—391、397）

## 应急预案不止是一份备案文件

书载预案管理分综合、专项、现场处置方案；风险单一且小可仅编现场处置，专项可并入综合，危险性较大场所仍应有现场方案。先风险辨识评估、资源调查，再由有现场经验人员参加编制，衔接政府、周边及救援队，制作简明岗位处置卡。特定高危和中型以上单位须专家评审、回避、书面纪要，其他可论证；负责人签署公布，影响周边的应告知风险与措施。（PDF397—399）

重点单位书载公布后20个工作日内备案，材料含申报表、需要时评审意见、电子预案、风险评估及资源清单；受理方5工作日核对，不齐一次告知，逾期不备案且不说明理由视为备案，实践须保留提交凭据并核地方规则。中央企业、油气管线、海洋石油、煤矿的报送抄送路径另核。年度综合或专项演练、半年现场方案演练；重点行业和人员密集场所至少半年一次应急演练并报送。演练后评估，特定单位每三年预案评估，法规、组织、风险、资源或演练重大问题变化即修订，重大内容变更重新评审报备；装备队伍、值班和培训档案需实际落实。小微企业可指定兼职救援人员，园区可联合组队，不等于免除救援准备。（PDF392—393、399—401）

## 处罚与刑事风险：禁止把旧金额当现行报价

《安全生产法》书载责任章覆盖监管滥权收费、中介失实或虚假、投入不足、负责人失职、培训机构配置、建设设备、危险作业、隐患、发包交叉作业、宿舍疏散、免责、从业违规、拒检、未投保、报告救援、按日连续处罚、关闭禁入、事故罚款及赔偿执行。处罚主体、违法行为、整改或后果条件应逐项匹配；不能只因发生事故即推定每位高管有罪。（PDF310—313）

旧《事故报告和调查处理条例》罚则（PDF390—391）、《事故罚款处罚规定（试行）》（PDF401—404）与2021年《安全生产法》金额、比例、条号并存不一致。后者书载分事故等级和子档，核上一年收入，难核收入有替代口径；迟报为超时、漏报为过失遗漏、谎报为故意不实、瞒报为隐瞒未报经查实；多项违法分别裁量合并决定，不等于同一行为重复罚款。**已核验更新**：[应急管理部门第14号令第24条](https://www.mem.gov.cn/gk/zfxxgkpt/fdzdgknr/202401/t20240115_475152.shtml)自2024年3月1日施行并废止旧试行规定；具体处罚必须重新查新规则及从旧兼从轻等适用原则。

书载两高《办理危害生产安全刑事案件解释》在本批仅有第1—11条及第12条开头（PDF404—405），**不是解释全文**。主体按实际组织、指挥、管理、投资、控制、直接作业和报告职责确定；明知隐患仍强制、威胁或故意掩盖隐患组织作业，可进入强令冒险认定。特定事故犯罪书载入罪后果为1死、3重伤、100万元直接损失等，重档通常含主要责任及更高后果，工程、教育设施等罪名有不同要件。报告犯罪还须贻误抢救，串通者可为共犯；阻挠救援或藏匿遗弃伤者致死重残可能另涉故意犯罪；不合格安全设备生产销售亦有独立罪名。必须续读下一批解释余文并核刑法修订、后续解释；不能把行政事故等级替代犯罪要件。此部分原书没有完整事实型安全案例，未编造案例。
