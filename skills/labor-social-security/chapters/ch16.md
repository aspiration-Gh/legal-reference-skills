# ch16 人事综合：身份、处分、退役安置与人事争议

来源：《劳动和社会保障法律法规全书》2022年版，2021年12月第8版，ISBN 978-7-5216-1794-8，源书“三、人事篇／1.综合”，PDF457–501页。本模块是实务编排编号，不是源书章号。下列规则除“官方时效核验”外均为书载规范提炼；本范围未见编者案例，自编应用另作标记。

**使用顺序：先定人员身份、行为与处理时间，再定位书载依据，最后核验适用时点的官方法律、配套规则和过渡安排。不得把旧机关名称、旧处分幅度或旧待遇标准直接写成现行结论。**

## 1. 先分法律关系，再分办理机关

- 《公务员法》以依法履行公职、纳入行政编制、财政负担工资福利三项共同界定公务员；领导成员不包括机关内设机构领导人员。监察官、法官、检察官等另有特别规定的从其规定。具有法定公共事务管理职能的事业单位，经批准可对除工勤人员外的工作人员参照管理，不能仅凭财政供养推定公务员身份。（PDF457、466）
- 法定条件包括该法域国籍、年满18周岁、宪法与政治制度要求、政治道德品质、身体心理条件及职位能力。公务员履行忠实履职、保密、廉洁、服从合法命令等义务，享有工作条件、报酬福利、培训、申诉控告和申请辞职权；免职、降职、辞退、处分必须有法定事由及程序。对错误命令可提出纠正意见；上级坚持时通常由上级承担后果，但执行明显违法命令仍须承担相应责任。（PDF457–458、461–462）
- 职位分综合管理、专业技术、行政执法等类别；职务、职级、级别不同，均须核编制、职数、资格和管理权限。录用一般针对一级主任科员以下相当职级，公开考试、考察、体检、公示，特殊职位须批准；新录用试用一年。考核区分领导成员与其他人员，平时、专项、定期相衔接，定期结果书面告知。委任、选任、聘任各有任免方式；晋升须考察、公示及审批，不因任职年限届满自动发生。（PDF458–460；细则见[ch17](ch17.md)、[ch18](ch18.md)）
- 奖励包括嘉奖、记三等功、二等功、一等功、授予称号，个人与集体均有适用场景；骗奖、隐瞒严重错误、程序违法、严重违纪影响称号声誉可撤销。初任培训在试用期内，领导任职培训在任前或任后一年内，业务及在职培训须登记并与考核任用衔接。（PDF460–462）
- 交流包括调任、转任；挂职不改变原人事关系。调入机关的国有企事业单位从事公务人员须满足领导职务或四级调研员以上相当职级等条件。亲属任职回避、地域回避、公务利害关系回避分别判断；配偶、子女及其配偶经营企业的监管或主管部门领导成员另有限制。（PDF462–463）
- 工资包括基本工资、津贴、补贴、奖金，禁止机关擅自增减、拖欠；非工作日加班先安排补休，不能补休依规定补助。福利、保险、因公牺牲或病故抚恤另循规定。达到适用退休年龄或完全丧失工作能力应退休；书载提前退休为本人申请并经批准，条件包括工龄满30年，或距规定退休年龄不足5年且工龄满20年等。退休年龄及改革过渡须另核。（PDF463–465）

## 2. 处分：先查主体和身份，不能重复处分或混用救济

《公职人员政务处分法》（PDF466–473）适用于监察机关对违法公职人员作出的政务处分；任免机关、单位处分适用其第二、三章实体规则，程序与申诉另依相应规则。公务员不是全部公职人员；事业单位管理人员、国有企业管理人员、基层自治组织管理人员等后果不同。

| 核查事项 | 书载判断要点 |
|---|---|
| 种类与期限 | 警告6个月、记过12个月、记大过18个月、降级和撤职24个月、开除；决定作出即生效。多项违法分别评价，执行最重种类，同种撤职以下处分合并期限最长48个月。（PDF467–468） |
| 裁量 | 主动交代、配合、有效挽损、检举属实、次要作用、退赔等可从轻或减轻；轻微且具法定情节可免予或不予。处分期内再次故意违法、阻碍举报、串供毁证、拒退违法所得等应从重。（PDF467–468） |
| 刑事衔接 | 故意犯罪被判管制、拘役、有期徒刑以上刑罚含缓刑，过失犯罪刑期超过3年，或被剥夺政治权利，应开除。较轻过失犯罪通常开除，特殊情况撤职须报上级批准；单处罚金、犯罪情节轻微不起诉或免刑有专门后果，不能概括为“未坐牢就不处分”。（PDF468） |
| 身份后果 | 公务员及参公人员限制职务职级衔级级别晋升；事业等人员限制岗位、职员等级、职称；国企管理人员限制岗位和职称。基层自治管理人员适用警告、记过、记大过并涉及补贴奖金；其他依法履行公职人员另有降薪、调岗、解除关系等处理。（PDF468–469） |
| 解除及离职 | 开除解除人事或劳动关系；其他处分期内悔改且无应受处分的新违法，期满自动解除，降级撤职不恢复原职级待遇。退休者不再给予政务处分，但可调查、追缴并调整待遇；已离职或死亡者履职期间违法亦有追责处理规则。（PDF469） |

违法类别覆盖政治纪律、重大事项与个人事项报告、档案造假、集体决策及执行、出境和身份资格、选任与考试、人事利益骗取、压制举报和选举、贪贿及特定关系人谋利、礼品宴请、公款与津补贴、营利兼职、黑恶势力、侵害服务对象、滥权失职与形式主义、泄密及商业秘密隐私、赌博毒品、家庭义务与社会公德。须逐项核行为、后果及“较重／严重”条件，不能把目录当作统一处分幅度。（PDF469–471）

调查至少2人，非法证据不得作处分依据；处分前告知事实和依据，听取并核实陈述申辩，不得因申辩加重。决定书应列事实证据、种类依据、复审复核途径期限并送达；调查处理人员有亲属、证人、利害关系等应回避。司法裁判或行政处罚变化影响处分时，须重新处理；人大选举任命等身份先履行相应罢免撤免职程序。立案期间出境、辞职须监察机关同意，单位不得交流、晋升、奖励、处分或办理退休；降级以上待遇变更一般1个月内办理，批准延长最长6个月。（PDF471–472）

监察处分走原监察机关复审、上一级监察机关复核；本法未在本处直接规定申请天数，必须核适用版本的监察规则。复审复核不停止执行，不得加重。事实不清证据不足、影响公正的程序违法、越权滥权应撤销重作；法律适用、情节认定或幅度错误应变更；撤销减轻涉及待遇补偿与名誉恢复。对不执行决定、阻碍调查、打击报复及办案违法另行追责。施行前已结案案件复审复核依当时规则；未结案案件保留从旧兼从轻衔接。（PDF472–473）

《行政机关公务员处分条例》旧文本（PDF479–485）另载处分设定权限、共同违法、从轻减轻、政治组织廉政财经与生活纪律、任免或监察权限、调查与回避、6个月办案且最长12个月、书面解除处分、申诉及补偿。其“判刑即开除”、解除程序、旧监察制度、生育等条款不得不加辨别地与新法拼接；该条例已废止，见下方核验。

## 3. 退役安置：区分军官、军士、义务兵及安置方式

《退役军人保障法》（PDF473–479）按移交接收、安置、教育培训、就业创业、抚恤优待、褒扬激励、服务管理及责任设制度。原部队移交证明、档案和社会保险关系资金，安置地接收、户籍与社保接续；服役问题由原部队处理，安置问题由安置地政府处理，其他移交问题安置地处理、部队配合。

- 军官有退休、转业、逐月领取退役金、复员；军士有逐月领取退役金、自主就业、安排工作、退休、供养；义务兵有自主就业、安排工作、供养，具体门槛转查适用配套规范。参战、特定作战主官、烈士子女和功臣模范、长期艰苦地区特殊岗位人员有优先安置；机关事业接收涉及编制，国企接收须劳动合同；依法裁员优先留用。逐月领金者被录用为公务员或聘为事业人员，自下月停发退役金。（PDF474–475）
- 伤病残实行专门移交、医疗康复护理住房保障；随调配偶原在机关事业单位且符合法定条件才安排相应工作，其他情形提供就业协助，子女入学转学另有优先类别。学历与技能培训并行，符合条件享资助；入伍前高校在读或录取者退役后2年内入学复学。年龄未达退休且需就业创业者核技能补贴。（PDF475–476）
- 招录可依规定放宽年龄学历且同等条件优先；退役军士义务兵服役视为基层经历，服役满5年的高校毕业生有定向招录安排，不能推定免试入编。原单位身份决定复职复工路径。服役工龄合并，养老医疗失业缴费年限依法衔接；贷款贴息税惠须核条件。普惠与优待叠加，涉及住房、医疗、交通文旅、供养、困难援助、残疾抚恤及参战特别优待。（PDF476–477）
- 荣誉奖励、迎接走访、纪念设施、地方志及公墓属于褒扬激励；服务中心站点提供就业优抚权益保障。可检举控告违法安置，拒绝拖延安置须限期纠正并追责；骗领待遇可取消追缴。对因违法犯罪被省级主管部门中止、降低、取消待遇不服，可依法复议或诉讼。武装警察退役人员、文职干部、院校学员、参试人员及既有自主择业对象分别适用或参照相应条款。（PDF478–479）

《退役士兵安置条例》是书载2011年旧制（PDF485–489）：自主就业报到为批准退役起30日内，无正当理由逾期报到超过30天视为放弃；原则按入伍户籍地，大学在读未复学、父母迁居、婚姻和特殊情形另判安置地。安排工作条件包括士官满12年、相应立功、因战5–8级残疾、烈士子女，符合者可自愿自主就业。政府接收后6个月内完成年度安排，介绍信开出1个月内上岗，合同不少于3年；非本人原因未上岗，从介绍信当月按不低于同等人员平均工资80%发生活费。待安置补助与此不是同一责任。因战因公致残安排者有工伤同等待遇，不能因残疾解除关系。退休、终身供养按士官层次、服役年限、伤残等级区分；中级以上因战5–6级可自愿放弃退休选工作，因战因公1–4级可放弃退休选供养。另有退役金立功增发按最高等级、教育和土地权益、养老医疗失业接续、拒收企业处罚、2011年前入伍人员自愿选择旧制的过渡条款。上述门槛金额与期限须先通过新旧法适用检验。

《关于自主择业的军队转业干部安置管理若干问题的意见》（PDF498–500）涉及既有自主择业群体：计划、退役金预算与银行发放、住房补贴公积金、未就业与就业医疗负担、就业后养老失业缴费、创业税惠、培训指导、死亡抚恤丧葬及档案服务职责。书载工资计至转业当年末、次年领金；进入特定机关团体及财政拨款事业单位正式工作后次月停金，其他就业退役金照发。不可与新制“逐月领取退役金”混同；营业税等旧税惠及PDF500错行的抚恤公式不直接用于计算。

## 4. 档案、调配与人事争议

《干部人事档案工作条例》（PDF489–494）涵盖干部及国有企事业管理、专业技术人员等，工勤、流动人员等另辨。十类材料为履历、自传思想、考核鉴定、学历职称培训、政审审计审核、党团、奖励、处理处分、工资任免出境会议代表、其他。形成部门1个月内移交；整理合格一般2个月内归档；管理权限变动2个月内转递，接收后一般2个月内审核入库。正副本及数字档案应一致，遗失损毁须报告查补，转递走机要或专人，保密审查后方可依法流转，不得由个人随意持档。

查档须工作理由、审批，至少2人、一般均为党员；通常不外借，例外须批准。本人权益取证可提请组织人事部门查阅，并非自行阅档权。“凡提必审、凡进必审、凡转必审”，核年龄、工龄、学历、经历、身份与关联合理性；涉嫌造假未核准，暂缓考察或暂停任用录用调动。禁止擅加删改、拍摄外泄、接收来历不明材料；救济可向上级组织人事、纪检监察举报申诉。（PDF492–494）

《干部调配工作规定》（PDF494–495）保留全民所有制身份的历史适用范围：编制计划、工作需要、专业与困难兼顾、回避；见习未满或审查处理中一般不得调动。先单位商洽并征求本人意见，再按权限审批；个人请求书面申请，调出如实提供、调入审核。跨地区及企事业调机关另核权限，不能以此跳过公务员录用调任规则。《京外调迁入有关人员审批暂行规定》（PDF500–501）针对中央有关部门在京单位等特定对象，涵盖选调、毕业生、两地分居、老干部子女、离休安置及家属迁移；年度指标、部门审批、主管部门备案与统一调令分工不同。户籍及机构改革后的有效政策另查，旧指标机制不等于当前个人落户资格。

《人事争议处理规定》（PDF495–498）书载范围包括聘任制公务员合同、事业与社团人员解除人事关系或聘用合同、军队文职聘用合同等。协商调解非强制前置，可申请仲裁再诉讼；考核、任免、职称评审依其他规定处理。中央驻地、垂直管理、军队单位层级与省级授权影响管辖。

书载期限为知道或应知侵权起60日申请，正当理由超期可经确认受理；10个工作日受理审查及答辩，庭前5个工作日通知，通常90日结案、批准延长不超30日；裁决后15日内起诉。**不得将这些旧数字套用于全部劳动人事仲裁**：先核身份、争议和现行办案规则；公务员法聘任合同争议另为争议发生起60日、裁决后15日起诉（PDF466）。解除关系、不同意辞职或终止合同引发争议由单位举证；证据须质证，仲裁可调档，保密例外限制公开。申请人无正当理由缺席视为撤回，被申请人可缺席裁决；调解书送达生效，生效文书不履行可申请执行。（PDF497–498）

## 5. 官方时效核验与应用

制作时仅核高风险更新，不代表全量现行性确认：

- [2024年安置条例官方文本](https://www.gov.cn/zhengce/zhengceku/202408/content_6965765.htm)第93条明确自2024年9月1日施行，旧《退役士兵安置条例》同时废止；历史案件仍须核行为时间及过渡政策。
- [国务院令第797号公报](https://www.gov.cn/gongbao/2025/issue_11786/202501/content_6997034.html)附件2第4项废止《行政机关公务员处分条例》，决定自2025年1月20日施行。

**自编应用：**收到“取消资格／解除聘用／处分”通知，先收集编制登记、任聘文件、合同、原处理决定和送达证据，再分别走录用救济、合同仲裁、人事申诉或监察复审复核。不能仅因工作地点在机关就统一走劳动仲裁，也不能把撤销处分与处分期满解除视为相同待遇后果。录用程序见[ch17](ch17.md)，考核晋升、退出与申诉见[ch18](ch18.md)。
