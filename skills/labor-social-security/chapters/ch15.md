# ch15 裁审衔接、欠薪刑责与典型案例判断

> 来源：《劳动和社会保障法律法规全书》2022年版（2021.12第8版，ISBN978-7-5216-1794-8），PDF431–456页。以下区别书载司法解释、典型案例分析与编者注；全部属于历史版本材料，未核验现行法。应用时以事件时间核官方法律、司法解释及过渡安排、地方标准。编号为自编实务模块。

## 诉讼前先做请求分类

书载《劳动争议司法解释（一）》（法释〔2020〕26号，2021年施行，全54条）见PDF431–436，属于司法解释。与[ch14](ch14.md)仲裁程序联用。

**受案边界**：履约、事实劳动关系、解除终止及补偿、退还保证抵押、档案社保转移、工伤职业病待遇、自主改制等属于劳动争议。未办理社保且经办机构不能补办导致无法享受待遇的损失赔偿、退休者向未参加统筹的原单位追索相关待遇也列入。请求经办机构发社保金、对劳动能力或职业病诊断鉴定结论异议、公房改革转让、家庭个人与家政人员、个体工匠与帮工学徒、农村承包户与受雇人等不属劳动争议；另行识别民事、行政或专门救济，不能笼统说法院一律不受理。（第1–2条，PDF431–432）

| 程序问题 | 书载处理边界 |

| 仲裁以无管辖拒收 | 法院核查后引导向有权机构仲裁；认为原机构有权，书面反馈，仍拒收才受理；不是拿到拒收书即可一律直接诉 |
| 非劳动争议、主体不适格等 | 分劳动争议、法院主管的其他案件或不属法院范围处理；主体确不适格不受理/驳回；纠错重裁可依法起诉 |
| 预先支付与生效调解书 | 不服预先支付裁决起诉不受理，未履行可执行；仲裁调解书生效后单纯反悔起诉不受理 |

表据第3–15条，PDF432–433。部分事项起诉使该劳动者的仲裁裁决不生效；多人裁决中仅部分人起诉，不影响未起诉人员裁决生效执行。（第16–17条）

## 终局裁决、执行与保全的衔接

裁决类型以裁决书确定为准；未注明时法院核实。单位起诉而被认定终局的，不予受理并告知自收到该不予受理裁定书起30日内向仲裁所在地中院申请撤销，已受理则驳回起诉。未注明类型且多项金钱请求每项裁决均未超过当地最低月工资12个月金额的，按终局处理。同一裁决已混入终局与非终局事项，法院按非终局处理；不要与办案规则“应分开制书”混为一条。（第18–20条，PDF433）

劳动者已就终局起诉，单位撤销申请不受理/驳回；劳动者被驳回起诉或撤诉后，单位自收到裁定30日内可申请撤销。撤销审查原则合议开庭，无新事实证据理由且认为不必要可不开庭；可法院调解，驳回或撤销裁定为终审。（第21–23条，PDF433）

执行阶段不予执行事由：非仲裁范围或无权、适法确错、违法程序、伪造证据、隐瞒足以影响公正裁决证据、仲裁员受贿枉裁等，以及违背公共利益；裁定须告知自收到次日起30日内起诉。终局申请撤销期间中止执行；撤回/驳回撤销恢复执行，撤销则终结。单位撤销失败不能在执行中以同理由重复抗辩。（第24–25条，PDF434）

诉讼保全中，经济确困难或有证据显示单位欠薪逃匿可能，可减免担保。书载要求在仲裁裁决/法院文书生效后3个月内申请强制执行，否则解除保全；**这是保全维持要求，不能写成一般申请执行时效**。仲裁阶段保全材料转交见ch14。（第49条，PDF436）

## 实体审查与责任主体

- 合并由承继单位应诉；分立由实际用工单位，承继不明全列；招用未解约者，原单位与劳动者争议可列新单位第三人，侵权诉讼另依对象列当事人。发承包双方、无照单位或出资人、挂靠单位与执照出借者须按具体规则列入；漏列必要共同仲裁人可在诉讼追加并处理责任。（第26–31条，PDF434）
- 已依法享受养老保险待遇或领取退休金者书载按劳务；停薪留职、未达退休年龄内退、下岗待岗及经营停产长假人员与新单位按劳动关系。外籍/无国籍人员须核合法就业证件，不能只凭合同认定劳动关系；书载证件名称及许可组合使用前核现行制度。（第32–33条，PDF434）
- 合同期满继续工作且单位不异议，视为原条件续履；依法应签无固定期限而未签，可视存在无固定期限关系。解除结算协议须合法、无欺诈胁迫乘人之危；重大误解、显失公平可请求撤销。无效合同已付劳动仍有报酬、依法经济补偿，单位过错造成损失还须赔偿。口头协商变更实际履行超过1个月、内容合法不违公序良俗，不可仅因未书面主张无效。（第34–35、41、43条，PDF434–435）
- 竞业未约补偿但已履义务：离职前12个月平均工资30%按月，不足履行地最低工资按最低；已有约定除另约外双方履行。单位原因3个月不付，劳动者请求解除应支持；单位主动解除，劳动者可请求额外3个月补偿；违约金支付后仍可能被要求继续履行。（第36–40条，PDF435）
- 加班事实劳动者先举证；证明证据由单位掌握而不交，不利归单位。开除辞退、解约、降薪、工龄计算决定由单位举证。暴力强迫、违约欠薪或不提供劳动条件、拒付加班、低于最低工资迫使解除，书载报酬、补偿及可能赔偿分别核要件。（第42、44–45条，PDF435）
- 非本人原因在关联单位轮签、工作场所岗位未变而换主体、组织调动、合并分立等，原单位未付补偿，且劳动者依法被迫解除或新单位提出解除终止时，可合并年限算补偿赔偿。已建工会的单位依法定相关条款解除须事先通知工会，书载“起诉前补正”例外须核适用时点。经营期限届满不续经营导致合同不能履行，应付补偿。（第46–48条，PDF435–436）
- 规章须民主程序、合法及公示，才可作权义依据；与合同/集体合同冲突，劳动者可主张优先合同。法定调解组织的协议有劳动合同约束力；仅报酬给付协议不履行可普通民事诉；人民调解仅给付义务协议可共同申请司法确认。违法开除解约法院可撤销，给付金额不当可变更。（第50–54条，PDF436）

## 拒不支付劳动报酬刑事解释

书载2013年司法解释全9条（PDF436–437）。劳动报酬含工资、奖金、津补贴、加班及特殊情况工资。逃避支付表现包括隐匿转移财产、恶意清偿、虚构债务或破产倒闭、逃匿及毁改账册名册工资考勤。不能仅因有欠薪即认定犯罪，应联查刑法构成、支付能力/逃避方式、数额、责令支付及履行情况。

“数额较大”书载两分支：一名劳动者3个月以上且5000元至2万元以上，或10人以上累计3万至10万元以上，地方高院在幅度内定标准并备案。政府部门依法责令而指定期限仍不付，才进入相应判断；有证据证明正当理由未知悉或未及时支付除外。逃匿者可依法张贴责令文书并拍照录像形成送达证据。致本人或受扶养者基本生活严重影响、重大疾病不能及时医治或失学，对讨薪者暴力威胁等，属严重后果筛查。（PDF436–437；第4条提取叠字，须复核原文）

未严重后果且支付报酬并依法赔偿：刑事立案前可不认为犯罪，公诉前可减免，一审宣判前可从轻；已严重后果但宣判前支付赔偿可酌宽。均是“可以”，不是付钱自动免责。非法主体违法用工、实际控制人及单位责任人员也受相应追责；单位另处罚金。证据应形成劳动报酬金额、到期、财产/逃匿行为、责令与送达、支付赔偿时间链。（末句为自编推演）

## 第一批典型案例：15案全部定位

下列是联合发布典型案例的书载事实与分析，不是司法解释条文，也不代表所有地区所有时点同样裁判。疫情案例必须重核事件时点防控措施和地方生活费标准。

| 案例及PDF页 | 判断、证据与边界 |
|---|---|
| 1 疫情“中止合同”，437–438 | 物流停工首工资支付周期仍按合同付薪，裁决及一审支持5000元。案例否定以疫情不可抗力当然中止劳动合同、停止工资；不可把民事合同免责直接迁入劳动关系 |
| 2 居家观察，438–439 | 物业要求不等于医疗隔离/医学观察或政府依法隔离；非相应受保护情形、超周期且不能正常劳动，经协商支付地方生活费，差额请求驳回；协商程序不等于必须达成一致 |
| 3 因工出差滞留，439 | 因单位派遣滞留，分析视为正常劳动，调解补工资差额；核出差安排及滞留原因，区别自行外出未返岗 |
| 4 一个工资周期，439–440 | 周期为时间长度而非跨过发薪截止日；例中停工起2月3日至3月2日为首周期，随后分段，调解差额3227.8元并恢复工作；金额按书载结果，公式提取错序，不拿它作通用工资计算器 |
| 5 部分停工，440 | 部门相对独立、真实停工且无差别适用，可以适用停工工资政策；不能只因其他部门复工就否定，也不能假停工针对个人降薪 |
| 6 统筹年休假，441 | 已有跨年申请同意，单位履行沟通协商、考虑意愿并付薪后统筹安排，不以再次协商一致为必要；不推成可任意跨年、无沟通强制消耗假期 |
| 7 共享用工，441–442 | 原单位破产终止关系，借入单位明知而继续管理付薪，从该时点确认新关系并补签；借用本身不改变原关系，禁以共享名义营利派遣、诱导个体化逃责，自主到别处兼职另论 |
| 8 集体欠薪，442–443 | 142人经要素核实、合法简化、工会协同调解145万元；流程及授权边界详[ch14](ch14.md) |
| 9 培训费用，443–444 | 培训期间工资不属专项培训直接费用；凭证培训费47000元、差旅5600元，60个月服务期剩27月，书载违约金23670元，返还61930元；核费用性质、凭证及未履行比例 |
| 10 虚假学历，444 | 与网络岗位直接相关的专业学历欺诈导致合同无效，可依法解除；真实告知限直接相关信息，不能泛化要求婚育隐私 |
| 11 视为无固定期限，444–445 | 未书面签约满1年“视为”与依法“应当”订立不同；案例驳回满1年后继续累计第二倍工资的请求，不免除此前法定责任 |
| 12 竞业欠补偿，445–446 | 银行11个月未付，劳动者之后加入竞争单位，案例视行为提出解除，驳回单位违约金及继续履行请求；这是案例分析，不能泛化为欠付即自动解除，正式提出解除和留证更稳妥（后句为应用推演） |
| 13 不定时工时，446–447 | 合同约定不能替代审批；按批准岗位和有效期间分段，批准前休息日加班未补休应付，批准期间按相应制度；不扩大到所有节假日或其他地区规则 |
| 14 调岗调地，447 | 审经营需要、是否重大变更、歧视侮辱、报酬条件影响、胜任、交通不便与补助六要素；原案同类辅助岗、合理整合及沟通获支持，不能把宽泛调岗条款当空白授权 |
| 15 离岗创业处分，447–448 | 保留事业人事关系仍受原单位管理；开除生效触发法定聘用解除，处分异议走复核申诉，不能仅以企业安排工作否定原单位管理权限 |

**算例复原**（第一批案例9）：费用总额=47000+5600=52600元；上限=52600÷60×27=23670元；已收85600元应返61930元。工资33000元排除于培训费之外；先确认存在合法服务期、违反服务期及可归责事实，再计算，而不是所有离职都赔培训费。（PDF443–444）
