# 第十章　供用电、水、气、热力合同：持续供应与停供争议

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15；本章PDF第1184—1217页。以下页码均为PDF页码。已顺序阅读对应源文全文；法条图框有OCR缺损，规则主要依据可读正文释义，不据猜测补写条号。本章提炼书中规则，实际使用前须核验行为发生时有效法律、行业规章及地方规定。

## 核心问题与适用范围

处理供能企业拒绝接入、供电质量不合格、欠费停电、灾害抢修、设施维护及水气热参照适用争议。先辨认供用合同双方及请求权，再区分供应中断的原因。公共服务属性限制缔约自由及停供权，但不意味着用户可以欠费，也不意味着任何停供损失都由供应方承担。

## 八项核心规则

### 1. 强制缔约先审主体、营业区和需求合理性（1184—1189）

【书中法条规则】向社会公众供电的供电人不得拒绝合理的订约要求。

【编者解释】供用电具有有偿、双务、诺成、公益和继续性，通常采用格式合同，买卖规则可作补充。强制缔约并非任何企业对任何申请人承担：须核实供电资格、核准营业区、接入方案和需求是否合理。受委托营业网点不当然成为独立供电合同主体。供电人与用电人的数量及地位差异，是限制随意拒绝、停供和提价的理由。物业服务人不得以业主欠物业费停止供电、水、气、热；书中同时从非合同主体及民生保障解释该限制。

【应用推演】拒绝接入案件先固定申请时间、技术资料、所属供区及拒绝理由；物业停供案件另行调取物业合同，不将物业费与电费混为同一债务。

### 2. 合同条款与设施边界分别查清（1190—1196）

【书中法条规则】合同内容一般包括供电方式、质量、时间，用电容量、地址、性质，计量、电价、结算及设施维护；履行地约定优先，未明确约定时按供电设施产权分界处确定。

【编者解释】条款列举不是缺一即无效的清单，可依补充协议、相关条款及交易习惯补充。供电时间不等同合同存续期限。产权分界关系维护责任及履行地，不能直接套用一般标的物在履行义务方所在地履行的规则。计量装置安装位置可推定产权分界，但允许反证；产权归属、运行维护、受托管理和技术责任分界可能并不完全重合。

【应用推演】收集原合同及附件、供电线路图、资产移交单、验收资料、表计位置、委托维护协议。只写“按国家规定划分”的条款不足以直接定位故障责任。

### 3. 不合格供电按质量、因果和损失审查（1197—1198）

【书中法条规则】供电人应按国家标准及约定安全供电；违反义务并造成损失的承担赔偿责任。

【编者解释】义务包括频率、电压、可靠性、按约供给及安全隐患提示；用户可请求继续合格供电、补救及赔偿。赔偿可涉及设备损坏和可得利益，但受可预见性限制。

【应用推演】将电压检测、故障时点、停机记录、设备鉴定与订单履行资料串联；利润主张应扣除未支出的成本，并核查是否存在用户设备故障等替代原因。损失报表本身不等于因果关系证明。

### 4. 计划检修等停供同时审实体理由与通知（1199—1202）

【书中法条规则】设施检修、依法限电、违法用电等中断供电情形，供应方应依国家规定事先通知；未通知造成损失的赔偿。

【编者解释】用户负合理容忍义务，但检修必要性、次数、时段也须合理。通知要分时间、方式、内容、对象审查，约定快捷通知方式不能当然缩短法定提前期限。书中列出的提前7日、24小时及停电前再次通知等要求来自当时不同规范，适用对象并不相同，不宜拼接成统一程序。供电人对已通知承担证明责任；损失还受减损规则限制。

### 5. 灾害免责与抢修义务分两阶段判断（1203—1205）

【书中法条规则】自然灾害等造成断电时，供电人仍须及时抢修；未尽抢修义务造成损失的赔偿。

【编者解释】免责须证明不可抗力及其与断电的因果联系。灾害不能成为灾后持续不作为的免责理由；“及时”结合交通、天气等实际障碍及当时行业时限判断，障碍消失后应行动，供应方举证已及时抢修。用户自身过错、第三人破坏与不可抗力分开审理。对于第三人导致断电，编者区分合同违约与电力运行侵权规则，主张不能用第三人侵权责任直接排除合同相对方的违约责任。

### 6. 欠费停供须完成催告、宽限及事先通知（1206—1211）

【书中法条规则】用户按规定及约定支付电费，逾期依约付违约金；经催告在合理期限内仍不支付，供电人可依规定程序中止，且须事先通知。

【编者解释】核算需分用户类别、计量、结算周期、总表或分表模式，并审配合抄表义务。书中将当时行政法规的欠费逾期超过30日作为具体审查依据。违约金约定、管理规范标准及过高调整不能混为一谈。中止不是解除：通常欠费处理指暂停供应，补交后应及时恢复；无恢复可能或双方同意终止等情况另论。IC卡余额耗尽自动断电未必存在欠费，也未必履行通知，书中对此明确保留进一步研究，不能写成自动停电当然合法。

### 7. 用户安全、节约和计划用电义务独立存在（1212—1215）

【书中法条规则】用户依规定和约定安全、节约、计划用电；违反义务致供应方损失时赔偿。

【编者解释】擅改类别、超容量、私动计量设施、私接电源等须核事实及规范依据。损害赔偿要求义务违反、实际损失及因果关系；行政警告、罚款不替代民事责任。监管部门作出停供处理与企业依据合同主张中止，主体和依据不同，不可只看后果相同。

### 8. 水、气、热先作同类比较，再补充买卖规则（1216—1217）

【书中法条规则】供用水、气、热力参照供用电规定。

【编者解释】共同基础是公共供应资格、网络持续给付、基本民生与行政干预；参照适用应保留产品特性。热力明显具有季节性、地域性，设备检修应围绕供热季安排。供用电规则仍不能解决时，再考虑买卖合同规则，不能将电力行业通知时限直接移植到所有公用事业。

## 具体论证重构

【书中论证，1195页】合同只笼统写产权“依法确定”，又可能由供电人受托管理全部设施，此时不能因谁维修就断定产权归谁。编者提出用表计安装地点推定产权分界，但双方可以举证推翻。实务判断顺序因此为：查明确约定及资产归属证据→无清晰资料时使用表计位置线索→审相反证据→再定履行地及维护义务。这是可反驳推定，不是物理位置的绝对规则。

【书中例证，1198页；处理推演】书中举电压不稳使企业无法正常生产、利润受损。分析该类事实时须分别证明质量偏差、停产原因、实际利润损失与订约时可预见范围；不能以“确曾停电”自动支持全部营业额。

## 操作步骤、证据与误区

依次建立合同主体表、供应线路及产权边界图、停供原因分类、通知与抢修时间轴、费用账单、损失及减损证据。对供应方索取调度命令、检修方案、通知送达、报修录音、到场及恢复记录；对用户索取缴费、设备维护、安全整改和停产记录。确定诉请究竟是接入、复供、费用调整还是损害赔偿，再检查违约与侵权竞合。

常见误区：把行政违规直接等同合同无效；认为通知后任何停电均免责；把灾害损失与迟延抢修增加损失合并；仅凭物业控制开关便承认其有停供权；把任一表计位置当不可推翻的产权证据。
