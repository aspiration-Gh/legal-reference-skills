# 第二十七章 合伙合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15；完整阅读PDF2824—2863，源ch27.txt。法条层是书载规范提要，编者解释保留原有争点，应用推演为实务处理路径。使用时先确认契约型合伙或合伙企业，再核适用时点的法律和特别规定。

## 核心问题与规则

### 1. 识别共同事业及合伙类型（PDF2824—2829）

**法条层：**合伙合同围绕共同事业目的、共享利益、共担风险形成。

**编者解释：**本章是合伙一般规则，合伙企业另受组织法特别规范。参与人可包括自然人、法人、非法人组织，特别法对普通合伙人身份的限制须另查。共同事业既可能是长期营利，也可能短期、非营利的共同活动。书面协议利于举证，但临时契约型合伙没有书面协议不当然不能成立；应结合出资、经营及口头合意。

借用一个人的营业执照、登记为个体户，不足以否定内部合伙；反过来，仅汇款或参与分红也应审实际安排。编者认为合伙是共同目的行为而非交换型双务合同，不能直接用同时履行、不安抗辩拒绝自己的出资义务。

**应用推演：**核资金是应返还本息的借贷、劳动报酬、买入权益，还是投入共同事业并承担风险。对外登记主体、内部协议关系、诉讼主体与责任财产四者分开记录。

### 2. 出资义务与合伙财产范围（PDF2830—2835）

**法条层：**合伙人按约定方式、数额及期限出资；出资、因合伙事务依法取得的收益和其他财产为合伙财产，终止前不得请求分割。

**编者解释：**资金、实物、财产权和劳务的适用范围应结合特别法。对财产须有处分权、保证无瑕疵；劳务是债的给付，不成为可共有的“人身劳务物权”，不实际提供时可求违约赔偿，不能强制本人劳动。房屋使用权作出资，不等于把房屋所有权交给合伙。约定出资与实际缴付不同，编者将未缴出资亦纳入财产范围；实际操作应区分出资请求权与尚未完成交付、登记的具体物权，不得以合同约定替代物权公示。

分配已经产生并可分配的利润，与抽取尚供共同事业使用的资本财产不同。合伙人个人债权人不能直接把共同财产当作债务人的单独财产。

### 3. 决定、执行、监督、异议与执行报酬（PDF2836—2841）

**法条层：**合伙事务决定原则一致同意，合同另约除外；事务原则共同执行，按约或全体决定可以交一个或数个合伙人执行，其他人享监督权。分别执行时，可对他人的具体执行事务异议，异议后暂停该项事务。执行事务原则不另取报酬，合同另约除外。

**编者解释：**决定权和执行权不是一回事；交由一人经营，不等于其他人失去看账监督权。异议针对具体事务，不能抽象宣告全部经营无效。执行人应勤勉，避免利益冲突及擅自转交执行；书中讨论竞业和自我交易限制，契约型合伙使用时还须核合同与规范来源。执行权由合伙关系而来，不宜直接当普通有偿委托。必要差旅、垫付款及执行事务不可归责自身受损的补偿，与工资或执行报酬分别结算。

### 4. 内部盈亏与对外债务分开（PDF2842—2850）

**法条层：**利润、亏损依约，约定不明先协商；协商不成按实缴出资比例，无法确定比例才平均。合伙人对合伙债务承担连带责任，清偿超过自己份额可追偿。

**编者解释：**不得以内部约定“只担少量亏损”对抗外部债权人。一般合伙把全部利润或全部亏损归少数人的条款，书中倾向否定；有限合伙等存在特别法例外，不能统一判断。只约利润或亏损一项比例时，编者支持据共享共担推定另一项，须结合完整协议。

先认定为共同事业产生的债务，包括合同、执行事务侵权及其他债，再谈连带；个人债务不能混入。书中倾向所有合伙均先以合伙财产清偿、再由个人承担补充连带，并将新入伙旧债、退伙前原因形成债务纳入责任。这些超出本章简短条文的部分属于解释及特别法类推，契约型合伙尤其须核当前裁判，不能直接赋予未获确认的先诉抗辩。

正常经营亏损与擅自处分、违反决策造成损失不同；编者支持有过错者内部多担责任。实际出资、分红但不参与经营者的身份和责任，不能仅按“不管事”排除，须审各方真实合伙合意及特别制度。

### 5. 份额转让与个人债权人权利（PDF2851—2855）

**法条层：**向外部人转让全部或部分财产份额，除合同另约，须其他合伙人一致同意；个人债权人不得代位行使合伙人的身份性权利，利益分配请求权除外。

**编者解释：**份额转让不等于分割合伙原物。向其他合伙人转让通常不需全体同意，但书中主张通知；终止后的剩余财产请求权转让，则不受同样人合限制。未经应有同意的外转，编者认定转让无效，实案需分别审转让合同效力、资格取得和其他合伙人追认，不把一个层次替代全部层次。份额设质书中也要求相应同意，应核现行设质及登记规则。

利益分配债权及终止后的剩余财产请求权，在符合代位一般要件时可以代位；管理、监督、表决等资格性权利不可代位。个人债权人欠合伙的钱，原则不能用其对某一合伙人的个人债权抵销，否则侵害其他人的共同财产。

### 6. 期限、退出、主体变故与清算（PDF2856—2863）

**法条层：**期限未约或不明，经补充等仍不能确定才视为不定期；期满继续执行事务、其他人无异议，原合同延续为不定期。可随时解除不定期合伙，但须提前合理期间通知。合伙人死亡、丧失行为能力或终止，原则发生终止，另约或事务性质不宜终止有例外；终止后先支付终止费用及清偿债务，再分剩余。

**编者解释：**只处理期内未了事务不等于继续经营。一个合伙人退出是否使全伙解散，要看其余人继续合伙情况；退出结算并不等于外部旧债免责。继承人能否继承合伙资格，还须看约定、法定资格及其他要件，不能把财产继承自动等同资格承继。书中将丧失行为能力包括限制行为能力，与委托章解释不同，应分别保留并核法。

清算需处理未了合同、收债、盘点有形无形资产及偿债。书中明确终止后未经清算不当然挡住分割诉讼；证据不能证明可能导致实体请求不支持，已明确的财产债务可审先行裁判。不得把“可以起诉”误作未经查账即可按原出资全额退款。

## 判断步骤与证据（应用推演）

1. **身份和制度：**收工商登记、协议及补充、加入退出记录、资金性质和分红事实，先定位合伙企业或契约型关系，列出全部可能合伙人。
2. **出资账：**分别列约定与实缴，核银行流水、收据、设备交付、权属登记、技术或劳务履行，区分所有权与使用权出资；垫付费用不得未经判断直接转资本。
3. **经营账：**决议、执行授权、异议通知、账簿凭证、合同、收付款与财产去向对应；查账缺失时先明确谁控制资料及证明责任。
4. **债务账：**逐笔核债务形成原因、日期及共同目的，标注入伙退伙节点、内部比例、外部清偿证据；追偿须证明实际清偿及超额，而非凭对方口头说已欠债。
5. **退出清算：**核期限与通知、是否仅部分退伙、是否继续经营，固定结算基准日；先清未了事务和债务，再评剩余财产，留有担保、税费及或有债务处理安排。

## 书中具体例证重构

**节日庙会合伙（PDF2857）：**合伙人共同出资购买食品，约在元宵节或中秋节庙会当天卖出，即使未写起止日，也可能依共同目的确定期限。只有合同解释仍无法确定，才进入不定期随时退出规则。证据重点是采购计划、约定销售场景和后续是否另行经营。

**客运债务追偿（PDF2847—2848）：**甲乙丙合伙客运，甲内部亏损份额40%，书中假设债务100万元全部从甲财产执行，指出甲可就超出自己份额的60万元向乙丙追偿。金额均为原书例证；乙丙各自分担仍需另查约定和实缴，不能据该例自行均分。

**使用权出资（PDF2834—2835）：**一名合伙人把房屋一定期间使用权折价出资，原物所有权仍归其本人，合伙取得约定的使用利益。清算应识别权利期间与剩余价值，不能将整套房屋当合伙所有权资产出售。
