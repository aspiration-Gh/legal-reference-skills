# 第二十二章 仓储合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记日期2020-07-15。顺序阅读ch22.txt全部原文，覆盖PDF第2478—2559页；以下均为PDF文件页码。法条规则、编者解释及应用推演分别标识。旧书不是现行法证明，具体使用前应核验法律版本、行业规范、司法解释及生效时点。

## 核心问题与适用入口

仓储处理专业经营者为存货人储存动产并收取费用的关系。核心是入库验收、仓单权利、专业保管、期限退出与费用保障。先区别普通保管、场地租赁、港口作业附属堆存和独立仓储；物流、买卖、融资链条中的实际货主、存货人、持单人可能不同，不能凭交货行为或所有权单独判定仓储合同当事人。

## 八项核心规则

### 1. 定性、成立与港口管辖

**书载规则及编者解释：**仓储为诺成、有偿、双务、不要式合同，意思一致即成立，交付货物和出具仓单属于履行环节。签约后无正当理由拒收、拒交可以构成违约，不能套用普通保管的实践性。仓储经营者应具备相应设备与专业条件；涉及危险品、港口等还须具体查许可（PDF第2478—2486页）。

港区内仓库不必然发生港口作业纠纷。应检查该储存是否承接水路运输、卸货并为交付或转运临时堆存，是否属于港口作业环节；独立储存目的和经营主体资质也要考察。书中关于一般仓储营业许可、以及无港口许可即可排除港口合同的概括应结合现行监管与管辖规则复核，不能只凭营业执照文字决定全部性质和效力。

### 2. 危险品和易变质品：说明与保管条件双向审查

**书载规则：**存货人说明危险或易变质性质并提供资料；违反时保管人可以拒收，接收后发现可采取措施避损，相关费用依规则负担。保管人储存危险物必须具备相应条件（PDF第2487—2490页）。

**编者解释：**合同应明确分类隔离、温控、应急安排和资料清单。保管人作为专业者须辨识货物需要，不能仅以危险品细类无专门强制条件主张已尽责。第三人的货物诱发事故，不当然免除对本合同货主的责任，赔付后能否追偿另查因果与过错。

### 3. 入库验收：验收范围决定瑕疵责任的边界

**书载规则：**按约验收，发现与约不符及时通知；验收后发生品种、数量、质量不符的，承担相应赔偿（PDF第2491—2493页）。

**编者解释：**验收项目、方法和期限分别查明。通常项目包括品名、规格、数量、外包装及无需拆包即可识别的质量，不当然要求拆箱检验；全验、抽验应先依约。接受货物却未记录可见瑕疵，事后以“原本劣质”免责会面临证明困难。质量责任仍须结合检验能力、隐藏缺陷、存货人告知和自然性质判断，不能理解为验收即保证所有内在质量。入库前运输、保管可能造成的隐患宜记录并取得确认。书末关于借鉴买卖检验规则的意见，应保留其参考性质（PDF第2558页）。

### 4. 仓单、入库单与提货权：不要由持单直接跳到所有权

**书载规则：**交货后应出具仓单、入库单等凭证；仓单记载存货人、货物识别及质量数量包装、损耗标准、场所、期限、费用、已投保信息、填发事项，并由保管人签章。仓单经持有人背书并经保管人签章，可以转让提取仓储物的权利（PDF第2494—2509页）。

**编者解释与分歧：**仓单兼具关系证明、收货及提货依据，并可流转、设质；仓单物权或债权证券性质、记载欠缺的后果存在学说争议。编者重视交易信赖，区分未流通时的事实证明效力与进入流通后的证券效力，不能将缺一项必然无效或任何单据均有物权效力定为统一结论。没有仓单时查合同及事实合意，实际交货人未必就是存货人；须综合协商、交货、费用承担和买卖交付目的。

转让核对背书链、保管人签章及交付；质押还应独立查权利凭证、设立方式和现行担保规则。书中关于未签章转让仍在双方间有效、签章切断抗辩及空单不能对抗善意受让/质权人的观点，属于解释意见，不能直接当作已确认法条。空仓单没有真实货物时尤其要区分保管人赔偿责任与对具体货物的优先受偿。

### 5. 检查取样、异状通知与紧急处置

**书载规则：**保管人应同意存货人或持单人检查、取样；发现入库物变质或损坏须及时通知；危及其他货物安全、正常保管时催告权利人处置，紧急时可作必要处置并事后及时通知（PDF第2510—2522页）。

**编者解释：**检查应在诚信和必要范围内进行，不得借取样任意改变场所、抽走过量货物。要求另行出具现状证明可能形成委托关系，虚假证明另生责任。仅本批货物存在变质危险，与已危及其他批次的法定紧急处置条件不同；前者的处置授权、协助或无因管理基础需分别说明。应保存不能及时联系、危险紧迫、措施必要及费用合理的证据。自有瑕疵可能免除原始损失赔偿，但不当然免除通知、避免损失扩大的义务。

### 6. 储存期限、提货与费用：入库日期不是储存时长

**书载规则：**无明确储存期限时可随时提取或请求提取，但须给必要准备时间；期限届满凭仓单、入库单等提货，逾期加收、提前不减收仓储费（PDF第2523—2532页）。

**编者解释：**先用补充协议、合同条款和交易习惯探究期限，不能一看未写结束日就认作不定期。例如约定每半年一个储存周期，即可能据此确定时长；仅写某日入库并按日计费，则确定开始履行日期但未必确定储存期限。仓储系为商业存货预留设施，提前取货不减费旨在保护预期收益。到期继续履行的默示更新、计费标准和不定期退出，是编者解释，需与明确催告、拒绝续存区分。

同批既有仓单又有入库单，书中主张涉及第三人信赖时优先核验仓单，不应仅凭入库单放货；双方内部未发生流转时仍须结合真实存储关系。

### 7. 到期不提与提存：催告不是完成清偿

**书载规则：**期限届满不提货，可催告合理期限内提取，逾期仍不提可依法提存。有效提存范围内发生交付、清偿及风险转移效果，提存后履行通知义务（PDF第2533—2541页）。

**编者解释：**催告内容须有到期事实、明确提货或处置要求及合理准备时间。申请提存应提供合同、仓单副联、货物明细、对方信息、催告与未提货证据。特殊物品是否不适宜实物提存、费用是否过高，决定能否依法变价后提存；不能将作者因机构能力而倾向变价提存的建议，升级为所有仓储物一律变卖。提存申请、另找仓库或口头通知不等于提存已成立；已查封货物还须协调执行程序。

书中第2540页关于提存人取回权的引文与后续概括，在五年期限及条件连接上不一致；仅保留其提示的取回问题，具体条件查官方法条，不能据旧书概括自行取回或占有货物。

### 8. 专业保管责任与补充适用普通保管

**书载规则：**保管不善造成损失应赔；自然性质、包装不符或超过有效储存期导致变质损坏，适用相应免责。仓储章未规定的补充适用保管章（PDF第2542—2559页）。

**编者解释：**仓储归责存在严格责任与过错责任之争，编者支持过错责任，理由是“保管不善”这一文义及专业注意义务结构，并主张由保管人证明已妥善保管或存在免责原因。其标准应达到该行业通常专业水平，不能以一般无偿保管标准免责。可补充亲自保管、禁止使用、场所方法、报酬支付及留置；不可用普通保管的交付成立规则覆盖仓储诺成性。欠费留置与提存目的不同，留置仍须适用物权规则，书中认为仓单流转不当然排除保管人基于该批货物费用的留置。

## 具体例证及论证重构

**锂电池与触摸屏火灾例，PDF第2489—2490页：**A科技公司将电子元器件交B物流公司仓储。火灾认定不排除仓内电池自燃；B将他人易燃电池与A的手机触摸屏混放，未有效隔离，也未充分证明消防验收及设施有效。法院据专业保管要求认定B存在重大过失，不能以可能是第三人电池起火或该危险品细类无强制条件为由免责。推理重点为独立保管义务、隔离及消防证据，不是“发生火灾即一律全赔”。原文匿名，未补造案号。

**空单融资论证，PDF第2509页：**书中设例为保管人与存货人虚开记载四万吨玉米的仓单，存货人持单向银行借款一千万元。编者以交易安全论证签发人不应凭空单免责。此为书中假设而非真实裁判；应用时应特别核验银行善意及审查义务、现行仓单质押规则、货物真实性、赔偿范围，不能据此宣布虚构玉米上已经成立可实现的物权。

## 应用推演：步骤与证据

1. 建立买卖—运输—仓储—融资关系图，查主体授权、仓库地点与港口作业关联，分别确定合同请求权及物权主张。
2. 将入库验收、存储、流转、出库时间线对应合同、仓单原件、入库单、签章背书、付款及放货指令；核实单货一致与重复出单风险。
3. 对货损调取温湿度、巡检、设备维护、消防、分区隔离、保险记录、事故鉴定和异常通知，查自然性质与管理不善各自贡献。
4. 退出时先确定期限、计费、留置或提存依据，再催告和依法处置；保留变价必要性、价格及余款处理证据，避免自行处置造成新的侵权。
