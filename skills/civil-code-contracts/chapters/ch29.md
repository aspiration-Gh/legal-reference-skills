# 第二十九章 不当得利

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15；全文阅读PDF2887—2902，源ch29.txt。法条层为书载规范概括，编者解释为旧书观点，应用推演是案件核查方法；实际使用须联网核验现行规则及事实发生时法律，不把旧条文、外国法或编者判断直接作为裁判依据。

## 核心问题与规则

### 1. 先找法律根据，再核损益关系（PDF2887—2890）

**法条层：**一方没有法律根据取得利益，受损人可请求返还，法定除外情形另论。

**编者解释：**构成须有得利、损失、损益因果关系及欠缺法律根据。其功能是去除无根据利益，与侵权填补损害不同；不以得利人一开始有恶意为成立条件。利益是具体财产利益，可以是取得财物、占有、使用、债权等，也可以是债务减少、节省本应支出的费用，精神满足不在返还对象内。

给付型关系先识别付款或交付的目的：债务本不存在、条件未成就、目的后来消灭等。非给付型则查权益归属、使用占有、无权处分获价、第三人行为或自然事件。书中对因果关系列直接与非直接两说，倾向由同一原因事实限定主体范围。三人关系尤其不能跳过基础交易，仅见最终受款人就认定其向原出资者返还。

**应用推演：**把“对方不公平获利”改写为具体请求：哪项财产、何次转移、原应归谁、对方依据何合同或法律保有、该依据为何欠缺或消灭。若有效合同、赠与或特别返还规则已能解释，先依该关系分析。

### 2. 原物、衍生利益和代偿物的返还（PDF2891—2892）

**法条层：**返还的是无根据取得的利益，善恶意影响责任范围。

**编者解释：**能返原物或转移权利的，原则返还或移转；不当设定负担、债权或占有，还须按其性质恢复。原物孳息、使用利益、原债权受清偿款及毁损保险金等代偿，也可能纳入。原物不在不等于利益已经消失：若转卖取得价款、以保险赔偿替代、节约原需支出，都应追查。

书中对旧司法解释“利用不当得利取得其他利益予以收缴”提出异议，倾向返还受损人。该讨论是旧规范批评，不可据此自由收缴或把所有经营收入一律全额返还。返还本金、衍生收益、费用扣除及额外损失应各自说明依据与范围。

### 3. 三类除外与不法原因给付（PDF2892—2895）

**法条层：**履行道德义务的给付、债务到期前清偿、明知无给付义务而作债务清偿，属于书载除外情形。

**编者解释：**道德给付结合社会观念、双方关系、标的价值判断，并与双方合意的赠与区分。主动酬谢救助者，书中倾向作为道德给付，不因法律原本不强制付报酬就允许讨回。若把他人错认成自己朋友而给婚礼礼金，是否先撤销还是直接不当得利返还，书中列两说并支持直接返还；必须核具体意思瑕疵与合同规则，不能普遍绕过撤销条件。

期前清偿有真实债务基础，不能只因还早了索回；与债务已经还过却误重复支付不同。明知非债清偿要求给付时明知无义务且以清偿特定债务为目的，误以为有债仍可审返还。“应当知道”“可撤销但未撤销”“明知没有债务”不是同一事实。

不法原因给付，书中比较禁止返还和按违法原因所在方分别处理的制度，并明确民法典未在本章给出统一规则。涉违法交易应联查民事行为无效、追缴及刑事特别规则，不能凭“双方违法所以钱归收款方”结束分析。

### 4. 善意得利人与利益不存在（PDF2896—2897）

**法条层：**得利人不知道且不应当知道取得利益无法律根据，利益已经不存在时，不承担相应返还义务。善意与利益不存在两个条件均要查，不能只举其一。

**编者解释：**原物存在返原物；意外灭失且无存续利益时可能免责；有偿转让仍有价款时不能直接说利益不存在。书中以受损人提出返还请求或诉前催告时考察现存利益，主张利益已不存在的得利人负相应证明责任；催告也可能成为得利人知道无根据的节点。实案须核催告内容、到达和客观认知，不能认定任何无理由索款短信都会使收款人恶意。

书中提出善意转让时结合实际获利与客观损失定额，并把某些类型通常善意、权益侵害型通常恶意。这些是解释概括，不能省略个案主观状态和价值判断。返还范围及是否存在独立损失请求须查当前司法立场。

### 5. 自始恶意与嗣后恶意分段（PDF2898—2900）

**法条层：**知道或应当知道获益无法律根据，受损人可请求返还取得利益并依法赔偿损失。

**编者解释：**自始恶意通常承担加重返还，原物灭失仍可能折价，不得仅凭“不在我手里”免责；嗣后知情以前按善意、以后按恶意评价。书中列原利益及其衍生利益、金钱利息、返还不足填补的损失，并讨论取得利益费用一般不得扣除、维持受领物必要费用仍可能扣除。

应用不能把返还和赔偿简单叠加导致重复受偿，也不能仅凭恶意就免去损失金额及关联性的证明。书中“法定利率”未提供可直接适用的统一计算标准，当前应查利率、起算点和适用依据。

### 6. 无偿转给第三人及善意取得（PDF2901—2902）

**法条层主题：**书中最后一条处理不当利益无偿转移后的第三人返还责任，条文框未完整提取，以下具体范围主要来自编者解释，不补造原文。

**编者解释：**书中以善意原得利人无偿转移、自己利益不存而免返还的情形说明，受损人可向无偿受领第三人主张。第三人善意无偿取得，编者以现存利益及代偿物为限；第三人恶意，应另评加重责任。若有偿取得且满足善意取得全部条件，则保护第三人，原得利人取得的对价转为返还对象。

原物请求与价值返还不能混同：先核原处分人有无权、第三人善意、合理对价及物权公示，不得把“付了钱”直接当善意取得。书中要求受损人证明无偿转移以及原受领人因此免负返还的事实；该附加前提与诉讼结构，实际使用应核现行规则，不擅自增加请求门槛或推定原、后手必负连带责任。

## 判断步骤与证据（应用推演）

1. **建立利益链：**列给付人、收款人、中间人及最终受益人；核转账、财物交付、使用记录、所有权登记、第三方代付说明，避免账户与真正法律受领人混淆。
2. **排查保有依据：**合同及履行、赠与、道德给付、债务清偿、撤销解除或条件未成就；同时检查是否有无效合同返还、执行回转、婚姻家庭等特别请求路径。
3. **确定举证事项：**主张无根据应提供与特定转移匹配的事实，收款方提出借款清偿、赠与等抗辩时核其证据；本章未完整规定各类案件证明责任，不补造统一倒置规则。
4. **固定认知时间：**发现误付、账务核对、律师函、回复、承认及诉讼材料到达，分别判断实际知道与应当知道；保留此前处分是否基于合理信赖的证据。
5. **追查现存利益：**原物、替代购置、转让对价、保险赔偿、孳息和费用节省逐项盘点；要求主张利益消失者说明去向，不只接受账户余额截图。
6. **分项请求：**原物或折价、衍生利益、利息、必要费用、额外损失以及第三人返还分列；对同一价值设置不可重复受偿的处理方式。

## 书中例证与论证重构

**洪水串塘（PDF2888）：**洪水使甲鱼塘中的鱼进入乙鱼塘，得利可由自然事件造成，不需要乙实施违法侵害。先查鱼的归属、转移及保有根据，再审能否返鱼或价值，不能以乙无过错直接免除全部返还。

**无权卖车与善意取得（PDF2897）：**甲无权把乙的汽车卖给丙，丙构成善意取得；甲得价款，乙失所有权，损与益不必是同一种财产。应审乙向甲的价款返还，而非当然从善意丙处要回汽车，具体侵权及返还竞合另核。

**房屋墙壁广告（PDF2896）：**未经同意利用他人墙壁做广告，所受利益是使用利益；书中认为房主原本有没有出租广告位计划，不决定该权益应归谁。该例支持先按权益归属识别利益，不以账面未少现金否认受损。

## OCR、原文疑点与现行核验

PDF2887、2898法条框严重乱码，PDF2896“不存在”一处识别残缺，PDF2901条文未完整提取，均以连续释义概括。PDF2899同时写“知道或应当知道”和“不包括因过失不知”，存在内部张力；应保留法条层的并列要件，不能以编者单句排除应知。PDF2889关于侵权损害仅含直接损害的概括不作一般规则使用；PDF2899损害赔偿过错主体用语亦有疑点，未擅自复原。
