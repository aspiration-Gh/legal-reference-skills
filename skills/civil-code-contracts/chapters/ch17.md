# 第十七章 承揽合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15。已顺序读完 ch17.txt，覆盖 **PDF1858—1964页**。页码均指PDF文件页码。本章保留旧版书载规范与解释，不代表已核验现行法；个案须查适用时点的法条、司法解释和过渡安排。“应用推演”为根据原文归纳的处理方法。

## 核心问题

先判断交易是否以独立完成特定工作成果为目的，再沿“工作主体—供料和图纸—变更协作—验收付款—保管保密—解除清算”查责任。承揽一般是诺成、有偿、双务、非要式合同，涵盖加工、定作、修理、复制、测试、检验等，不限于有形物制造；建设工程另受特别规则约束。

## 八项核心规则

### 1. 合同定性及条款缺漏（PDF1858—1876）

**书载规范及编者解释：**承揽以工作成果而非单纯劳务为给付目的。与雇佣比较，综合控制、支配和从属程度，工具设备来源，付酬方式，持续劳务或一次成果，以及劳务是否融入用人方经营组织。单有按小时计费、自带工具或现场协调，均不决定性质。

与买卖比较，查特殊制作目的、对生产者设备技术的信赖、过程检验、保密及合同整体内容。图纸、型号、预先订货、原料由制作方提供均非单独充分标准；内容与名称冲突时以实际权利义务为先。书中关于难以辨别时按用语频率推定的意见，仅是解释方法，不应机械计词。

标的和数量须能确定；质量、报酬、材料、工期、验收方式要明确。报酬不明按补充协议、相关条款或习惯，仍不明再参考订约时履行地市场价格及适用定价。不要把提示性条款全部写成合同成立的强制要件。

### 2. 主要工作、辅助工作及共同承揽（PDF1877—1884、1954—1956）

**书载规范：**原则上承揽人以自己的设备、技术和劳力完成主要工作，另有约定除外。主要工作未经定作人同意交第三人完成，定作人可解除；辅助工作原则上可转交，但承揽人仍对成果负责。**编者解释：**技术性强的工作重在质量决定、核心或高难度部分；简单工作可以数量上的大部分判断。禁止转交全部工作的约定亦应审查。

转承揽产生两个合同，次承揽人通常不能直接向原定作人请求报酬，原定作人也不能直接请求其履约。改变责任配置须核定作人同意及第三人承诺。共同承揽则是多人共同与定作人订约，原则上对外连带，另有约定除外；内部份额不能当然对抗定作人，超额承担后另行追偿。诉讼主体的追加按请求类型和当时程序规则核验。

### 3. 供料、检验及材料风险（PDF1885—1897）

**书载规范：**承揽人供料，应按约选材并接受定作人检验；定作人供料，应按约提供，承揽人及时检验，发现不符及时通知更换、补齐或补救，不得擅换材料或无需修理的零件。

**编者解释：**检查规格、数量、质量及供料时间；检验或补救迟延与工期、费用的因果关系应单列。定作人供料的检验以专业的善良管理人注意为尺度；显见瑕疵未发现可能有过错，超出合理检验能力的隐蔽瑕疵不当然由承揽人承担。材料过度消耗可请求补足、赔偿，严重影响成本或工期时再审解除条件。

**书内分歧必须保留：**PDF1875倾向无法确定供料方时由承揽人供料；PDF1886—1887认为可能影响合同成立，并倾向由定作人供料。前者强调履约效率，后者强调定作人的特殊要求与材料决定权。不得选其一冒充统一法定规则。PDF1891以定作物“基本成型”分配承揽人供料时风险，PDF1922—1923又以交付作为成果风险转移时点；二者边界不明，须结合约定、所有权及风险规则核验，不可简单认定成型即全风险转移。

### 4. 图纸、变更、协助与监督（PDF1898—1918）

**书载规范：**发现图纸或技术要求不合理应及时通知；定作人怠于答复造成损失应赔偿。定作人中途变更工作要求造成损失应赔偿；必要协助不履行导致不能完成，承揽人可催告、顺延，合理期限届满仍不履行可解除。监督检验不得妨碍正常工作。

**编者解释：**通知要列具体问题及可预见后果，保存到达证据，问题工作暂停等待答复，不擅改图施工。工期顺延起点，书中反对只从定作人承认图纸错误时起算，倾向通知到达时起算，以防其拖延答复；这是解释立场，仍须证明合理停工及影响。

中途变更限于原合同工作要求，不能无限扩展至新合同或超出技能资质。变更原则上面向未来，已按旧要求完成的工作不溯及变为违约。核算已完报酬、已耗材料、增加成本及顺延工期，扣除报酬中已包含项目；新要求不合理、不能完成或报酬调整失败时再审解除依据。单纯工期顺延与解除前催告的条件不同。

监督未发现隐蔽瑕疵不当然免除承揽人责任；定作人坚持不合理指示、妨碍作业或擅自接触设备造成损失，应分析其过错与承揽人安全管理责任。

### 5. 交付、验收及瑕疵救济（PDF1919—1932）

**书载规范：**完成后交付成果、必要技术资料及质量证明，定作人验收；不符合质量要求，可合理选择修理、重作、减少报酬、赔偿损失等。**编者解释：**成果交付属主给付，资料属从给付。预验收并非正式验收，通常先要求整改，不能仅因预验收不合格当然解除。

分别记录整体、部分、现实及合同约定的拟制验收。书中参照买卖检验通知规则：有期限依期限，无期限依发现或应发现后的合理期限，并讨论收取成果后两年、质量保证期以及承揽人明知或应知不符的例外；这些应标为参照解释，不能把两年当统一诉讼时效。未经检验即使用的处理也保留根本质量问题例外。

质量瑕疵责任的过错性质书中存在讨论，特别强调定作人原因；不能仅凭成果不合格就忽略供料、指示及告知责任。本法未明定必须先修补才可减酬，但选择须合理。修理重作不适宜或费用过高，应审查继续履行限制；承揽人无正当理由拒修，定作人自行或委托第三人修复的合理必要费用可请求赔偿。轻微迟延解除则应综合完成程度、原因、损失和合同目的从严判断。

### 6. 报酬及留置与拒绝交付（PDF1933—1943）

**书载规范：**付款期限依约；补充规则仍不能确定，在交付成果时支付，部分交付相应支付。未付报酬或材料费等价款，承揽人可依法留置成果或拒绝交付，另有约定除外。

**编者解释：**拒绝交付属履行抗辩，不直接产生优先受偿；留置属法定担保物权，须审查动产、合法占有、债权到期、关联关系及排除约定。已交付后不能自行取回充作留置。保管责任不因留置消失，实现时依法折价、拍卖、变卖并结清余款，不能直接据为己有。书中同时提及企业间留置的关联性例外，不能把后文同一合同要求绝对化。被查封时，书中主张优先参与分配而非凭优先权排除执行，程序须查最新规定。

以质量不符拒付或减付，定作人须举证。以未来不确定事实作为付款节点，书中倾向按期限不明处理；个案须区分条件、期限、第三方付款安排及诚信限制，不能不加解释一律失效。

### 7. 保管与保密（PDF1944—1953）

**书载规范：**妥善保管定作人材料和已完成果，保管不善造成毁损灭失应赔偿；按要求保密，未经许可不留复制品和技术资料。

**编者解释：**保管的注意程度应匹配专业能力和物品性质，由实际控制物品的承揽人证明已妥善保管。材料自然损耗、隐瞒瑕疵或不可抗力须结合已尽义务判断，不将保管责任等同一切意外风险。

保密贯穿缔约、履行、终止后，包括不得不正当使用及终止后返还资料；无明确保密条款亦不当然免责。自研图纸若服务定作人特殊需求且设计成本主要由其承担，书中倾向亦负保密义务。归责上编者区分先、后合同过错责任与履行中合同责任，侵权竞合另论；须证明受保护信息、接触利用行为、损害及因果关系。

### 8. 任意解除及清算（PDF1957—1964）

**书载规范：**定作人在承揽人完成工作前可随时解除，造成损失应赔偿。**编者解释：**解除权并不属于承揽人；已按约完成但尚未交付不能当然继续任意解除。通知到达发生解除效果，异议诉讼通常是确认效力，不当然推迟解除时点。

清算时交付已完部分、返还剩余原料、核抵预付款及已完报酬，停止无必要后续工作并减损。任意解除可否约定放弃、是否全赔可得利益均有争议：编者反对约定排除，反对不加区分等同违约赔偿全部履行利益，要求结合履行状况。理由分别为法定赋权、自由与效率、相对人利益平衡。不得写成一律仅赔成本或一律赔全部利润。建设工程发包人任意解除须受特别限制，与ch18末尾原则否定的论述一并阅读。

## 书中具体例证重构

**挖掘机连人作业（PDF1862—1864）：**燕某自有挖掘机，聘司机余某，按月支付3500元；为王某宅基地装渣土按小时100元结算，油费、维修由燕某负担。作业退出时铲斗撞伤渣土车上的米某。书中将燕与余认定为雇佣，将燕与王认定为承揽：前者受燕安排、按月领酬；后者以自有设备技能完成装土成果并自担运行成本。现场协调不改变独立作业性质。此例说明应先分层建立法律关系，再确定侵权主体，而非把所有现场参与人并列为雇主；损害责任须另核现行侵权及用工规则。

**工作分层例（PDF1884）：**玉饰雕刻形成所需式样是主要工作，大块切割和完成后的抛光可为辅助；服装量体裁剪、整体缝制是主要工作，锁边、缝扣、熨烫可为辅助。应用时仍依具体合同的技术和信赖要求，不能照例给所有行业固定分类。

## 应用推演：办案与证据顺序

1. 取得完整订单、报价、图纸版本、样品及沟通记录，先定性、确定工作范围、供料方和完成标准，核查劳动用工及建设工程特别规则。
2. 建立材料交接、检验异议、转承揽同意、变更指令、停工催告时间线；将每项费用及延迟分别对应责任原因。
3. 核对交付、使用、预验收、正式验收及瑕疵通知时间；收集检测、照片、维修方案与费用，先明确需鉴定的技术问题，保留损失和减损证据。
4. 将请求分为履约、减酬、损害赔偿、违约解除或任意解除，并核款项是否重复；主张留置前核占有和权属，主张保密责任前固定信息范围与接触路径。

## OCR未决与现行核验

法条框在PDF1858、1877、1880、1885、1903、1909、1919、1927、1933、1937、1957等处缺失或乱码，本文只依完整释义概括。PDF1923对“验收是否包括受领”表述自相牵连；PDF1939留置履行期限写作“两个月”，未将其替换为现行法定期间；PDF1955关于免除部分共同承揽人责任对全体效力的表述过宽，均需核对原页和正式规范。

优先核验：供料约定不明的补充解释、交付前风险、隐蔽瑕疵和检验通知、留置实现期限与企业留置、共同诉讼及债务免除效力、任意解除的放弃和赔偿范围、建设工程准用边界。书中早期管辖和人身损害规则不可直接沿用。
