# 第二十一章 保管合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记日期2020-07-15。顺序全文阅读ch21.txt，覆盖PDF第2436—2477页；引用为PDF文件页码。下文以书载法条规则、编者解释、应用推演区分依据层次。制作时未全量核验法律更新，使用前须按事件发生时间核验民法典、司法解释、消费者保护及相关裁判规则。

## 核心问题与适用范围

先问是否为他人保管并返还物品、是否交付占有、是否有偿，再问毁损原因和保管人的注意程度。普通保管以保管为目的，原则上只转移占有，不转移所有权或使用收益权。存放在商店、饭店、酒店指定场所的法定保管，与消费者自己保管的物品、单纯场地使用及经营者安全保障义务须区别；仓储为专业有偿保管，成立及期限规则另见ch22。

## 七项核心规则

### 1. 成立时间与法定保管：交付规则有例外

**书载规则：**一般保管自保管物交付时成立，当事人另有约定除外。保管凭证用于证明接收、关系存在及履行内容，不是成立的额外要件；交易习惯可影响是否给付凭证。消费者为购物、就餐、住宿等将物品放在指定场所，视为保管，另有约定或交易习惯除外（PDF第2436—2444、2447—2450页）。

**编者解释：**“指定”比是否有人值守、室内室外更关键；去超市未买到商品不当然排除法定保管。自助柜是特殊保管关系，经营者须提供通常安全的锁具并注意外部环境，但顾客仍须证明存入何物。不要直接把旧判决关于自助柜仅为借用的结论，作为民法典新增制度后的统一答案。

### 2. 有偿、无偿与费用：免费标示不是全部事实

**书载规则：**保管费依约；没有约定或不明，经补充协议、相关条款及交易习惯仍不能确定，视为无偿。有偿保管费支付期限依约，仍不能确定的在取物时支付（PDF第2445—2446、2474—2475页）。

**编者解释与争议：**职业寄存经营及具体交易环境可支持有偿解释；宾馆免费停车可能已由住宿费覆盖，编者赞同隐含有偿的思路，但对没有真正消费的寄存者承认仍有争议。应先判定费用结构，再确定责任标准。保管费是报酬，必要费用是维持、修缮、饲养、救护等支出；无偿不等于保管人必须承担一切必要成本，有偿约定已含成本的不得重复计费。

### 3. 妥善、亲自保管与禁止使用

**书载规则：**保管人须妥善保管；约定场所、方法不能擅改，紧急情况或维护寄存人利益除外。不得转交第三人保管或自行、许可第三人使用，另有约定除外；违法转保管造成损失应赔偿（PDF第2451—2460页）。

**编者解释：**履行辅助人参与不等于另行转保管，其行为由保管人负责。经同意转保管后是否仅承担选任、指示过错，书中作为参照委托规则的学说列出，并非明确法条结论。违法转保管与无偿保管免责之间的协调也须具体查明故意、重大过失，不能认为无偿即可随意转交。擅用未损坏时，书中提出借用及补偿解释，不能据此认定寄存人已同意使用。

### 4. 瑕疵、特殊性质和贵重物品：告知对象不同

**书载规则：**物品有瑕疵或性质要求特殊保管措施，寄存人应告知；未告知导致保管物损失的，适用相应免责规则。若保管人受损，须同时考察其是否知道、应当知道且未补救。货币、有价证券及其他贵重物应声明并由保管人验收或封存；未声明时可按一般物品赔偿（PDF第2454—2455、2465—2466页）。

**编者解释：**声明包括种类、性质、价值或数量，目的在使保管措施与风险相匹配。不能仅以“贵重”主张实际高额价值，也不能把未声明解释为对任何损害完全免责。保管人发现危险后仍应通知、采取合理措施，货方未告知不自动免除其独立过失。现金封存后须返还原物，与货币消费保管不同。

### 5. 毁损责任：保管不善、因果关系及无偿免责

**书载规则：**因保管不善造成毁损、灭失，保管人应赔偿；无偿保管人证明自己没有故意或重大过失的，不承担赔偿责任（PDF第2463—2464页）。

**编者解释：**有偿保管按过错责任分析，注意场所、方法、保管措施和实际控制；无偿保管的一般过失与重大过失必须区分，且免责事实由保管人举证。只证明物品损失仍需连接保管关系、损失发生阶段和相应责任事实。贵重物声明、寄存人擅改保管安排、物品自身性质，均可能影响责任及数额。

### 6. 返还、期限与第三人争议

**书载规则：**寄存人可随时领取；无明确期限时保管人也可请求领取，有期限则无特别事由不得要求提前领取。应返还原物及孳息；第三人主张权利原则上不使保管人免于返还，但法院依法保全或执行的除外，诉讼或申请扣押情况须及时通知（PDF第2461—2462、2467—2470页）。

**编者解释：**重病、丧失保管能力或严重环境变化可能构成特别事由；提前领取的费用与损失应分开核算，按实际保管期间计费的意见不是仓储“提前不减费”规则。法院查封后继续保管的费用也需安排，协助执行不等于无限期免费保管。返还地点查特别约定、交付场所和履行地点补充规则，不能仅因物在异地就免除返还义务。

### 7. 消费保管与留置：不要混同所有权和欠费救济

**书载规则及编者解释：**货币可以同种同量返还，其他可替代物依约可同种、同质、同量返还。书中以允许消费及所有权移转解释消费保管，风险承担、破产取回与普通原物保管因此不同；封存特定现金仍属普通保管，借贷与储蓄另看交易目的（PDF第2471—2473页）。书中关于定期消费保管不得随时取回的意见同时承认本法无明确规定，不得提升为确定法条限制。

**书载规则：**欠付保管费或其他费用，可依法留置保管物，另有约定除外。实现留置须遵守期限及变价程序，期间仍应妥善保管，余额返还、不足继续清偿（PDF第2476—2477页）。书中引文保留当事人约定履行期限及鲜活易腐例外，不能把其后概括的“不少于60日”理解为所有案件不可变动的条件。

## 具体例证重构

**书中泳馆衣柜例，PDF第2452—2453页：**甲获配240号柜，发现已被占用后未联系工作人员，改用233号柜，只用明锁，物品丢失。法院认定甲擅改柜位、未使用暗锁，未能让全部安全措施实施，承担主要责任；泳馆不能证明锁具被替换无过错及其他钥匙已销毁，承担次要责任。手机未作贵重物声明，按一般物品规则处理。编者用此说明新增法定保管的“指定场所”条件，以及顾客过错不必消除经营者独立过错。原文脚注标题与泳馆事实不一致，故仅按正文匿名事实重构，不补案号；手机是否属于需特别声明的贵重物也须按实际案件与现行口径核验。

## 应用推演：实务判断与证据顺序

1. 确定交易目的、寄存时间、交付占有或指定存放、保管凭证、钥匙控制；固定消费订单、收费项目和现场告示，核查免责条款的订入与效力。
2. 由物品清单、购买记录、照片、同行者证言、柜内残留物和监控证明寄存内容；生活经验推定可以反证，不等于仅凭陈述认可高额现金。
3. 对照约定保管标准，调取巡查、锁具维修、访问日志、转保管记录、通知送达、事故鉴定，分别识别寄存人、保管人和第三人的原因。
4. 将返还物、赔偿、孳息、保管费、必要支出和留置分项处理；已被司法扣押的通过执行程序协调，不能自行放货或处分。
