# 第二十五章 行纪合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15；完整阅读PDF2748—2797，源ch25.txt。法条层是书载规范概括，编者解释不等于统一裁判规则，应用推演是处理案件的方法。适用时核验事件时点及现行规范、行业特别法。

## 核心问题与规则

### 1. 从交易结构识别行纪（PDF2748—2757）

**法条层：**行纪人以自己名义为委托人从事贸易活动，委托人支付报酬。

**编者解释：**行纪有偿、诺成、不要式；对内为行纪合同，对外由行纪人直接与第三人订约。贸易不限传统动产买卖，书中倾向广义理解，但证券、货运等须结合特别规则。行纪经营资质依行业判断，不能把“原则需资质”推为所有寄卖主体一律须特别许可。自然人、个体户依合法行业惯例开展业务，也可能适用本章。区分代销与买卖时，退货权、报酬约定及谁承担独立经营盈亏是主要线索，名称并不决定关系。

**应用推演：**画出货、款、发票和报酬四条流向，检查对第三人使用谁的名义，再判断委托人承担的是交易结果还是把货物已经卖断。书中将货运代理广泛类比行纪，实案应另读货代约定及相关司法解释，不能将一切“代理”机械定为行纪。

### 2. 费用、保管、风险与破产财产分开（PDF2758—2766）

**法条层：**费用原则上由行纪人负担，另有约定除外；占有委托物应妥善保管。

**编者解释：**报酬通常包含费用及利润；书中支持在双方明知的行业习惯下调整费用分配，并认为通常费用可包括必要和有益费用。委托物不只货品，还可能有金钱、权属凭证。行纪是有偿商事服务，保管应尽善良管理人注意；交给别人实际保管，不当然免除对委托人责任。有特别投保指示而未遵守，应另审损害。

书中区分卖出与买入：卖出物交行纪人通常不转移所有权，不可归责行纪人的意外损失倾向由委托人承担；买入后未交委托人，编者倾向由行纪人承担意外风险。买入物交付前究竟归行纪人还是委托人，书中列两说并支持前说，据此讨论破产取回与债权申报。此属争议分析，须结合实际交付方式、货物特定化、物权变动及破产规则，不能仅凭账户付款者或占有人作结论。

### 3. 瑕疵和易腐物的检查、通知与紧急处置（PDF2767—2770）

**法条层：**交付时有瑕疵或易腐、变质的委托物，征得委托人同意后可以处分；不能及时取得联系时可以合理处分。

**编者解释：**先检查、留存瑕疵记录、通知并请求指示；紧急例外仍受合理方式与价格约束，不是任意低价处理。书中对处分属于权利还是义务列三说，支持兼具两面：保护利益所需时怠于通知及处置，可因损失扩大负责。因保管不当才致腐坏不能反用紧急处置免除先前责任。购入物存在瑕疵，须审是否应拒收、是否依特别指示接受及是否及时转交，不直接套用受托卖出物的所有判断。

### 4. 价格指示、额外利益与自我交易（PDF2771—2780）

**法条层：**低于指定价卖出或高于指定价买入须委托人同意；未经同意但补足差额的，对委托人发生效力。以更有利价格成交，增酬依约或补充确定，不能确定时利益归委托人。有特别价格指示不得违反。对有市场定价商品，委托人无相反表示时，行纪人可自己成为买卖相对人，仍可请求报酬。

**编者解释：**普通最高、最低限价与必须以某固定价销售的特别指示不同；后一情形不能当然用补差价补救。为额外利益额外支出的合理成本，编者倾向从收益扣除后向委托人结算，与通常费用自负规则有张力，须列为解释争点。有市场定价不等于任意一笔成交价格；自我交易应取符合指示交易时点的市场价，不得选对自己有利的日期。指定拍卖、招标可能默示排除自我介入；行业法禁止自营或交易方式另有限制时优先适用。撤回委托与介入通知须核到达先后。

### 5. 第三人违约不当然使行纪人退出（PDF2784—2786）

**法条层：**行纪人对与第三人订立的合同直接享权担责；第三人不履行致委托人受损，行纪人承担赔偿，行纪人与委托人另有约定除外。

**编者解释：**不能只称自己无过错就把第三人违约风险推给委托人。对外履行与内部追偿分开，原则上不能跨不同合同相对人抵销。书中讨论“披露委托人后直接对其生效”与“保持行纪相对性”两说，支持后者：本章已有特别规定，不能参照委托隐名代理、介入及选择规则免除行纪人。欲使委托人直接向第三人主张，可审合法债权转让，而非只靠披露身份。

### 6. 提存、报酬、留置及参照委托的边界（PDF2781—2783、2787—2797）

**法条层：**按约买入后委托人应及时受领；无正当理由拒收，或卖不出、撤回出卖后经催告不取回、不处分，可依法提存。完成或部分完成事务，支付相应报酬；到期未付，符合条件可以留置，另有排除约定从约定。未规定事项参照委托规则。

**编者解释：**提存前保留催告和合理期限，实物不适提存或费用过高才考虑依法变价提存，不得直接没收。留置以合法占有、报酬到期且无正当拒付事由、无排除约定为前提，须依法给付履行期限、变价、返还超额，不能据“欠佣金”立即自取货物。书中讨论货币留置与同时履行，实践应分别核具体担保、抵销与履行抗辩依据。

未成交若不可归责行纪人，编者倾向参照委托的相应报酬规则，以已投入劳务、费用及合理利润定额，不能当然收全部佣金。撤回、第三人尚未履行及部分完成各自核结算。可以参照指示、报告、转交财产、任意解除，但不可套无偿委托较低过错标准。已经按约买入或卖出、仅剩内部交付时，编者主张不再允许任意解除，以维护已完成交易；这是有争议的阶段限制，不是本技能新增法定例外。

## 判断步骤与证据（应用推演）

1. **定性：**取行纪及对外合同、报价、销售凭证、退货约定、报酬与盈亏安排；确认是否属于监管行业及特别法适用。
2. **查指示：**分别标记价格区间、固定价格、交易方法、地域和自我介入限制；保留变更同意、撤回及介入通知时间。
3. **查货物：**入库点验、瑕疵照片、温控保管、出入库单、保险、第三方仓储记录；区分原有瑕疵、保管致损和意外风险。
4. **分层结算：**列对外价款及索赔、对内转交义务、正常报酬、额外净利益及特别费用；各项扣减说明约定与证据，避免费用既计佣金又报销。
5. **选救济：**追偿第三人、对内赔偿、受让债权、催告取回后提存、符合法定条件留置各有前提；遇破产先核权属和取回对象，再决定取回申请或债权申报。

## 书中例证重构

**固定价空气净化器（PDF2772—2773）：**甲特别要求每台3000元，其他价不接受。乙不能因旺销改售8000元，也不能低售2000元后补1000元便强使甲接受。编者指出指定价可能服务市场份额或品牌策略，表面单笔获利不能替代交易目的。例中金额直接源自原文，非本技能估算。

**脐橙小果费用（PDF2760）：**收购大小橙同价，小果废弃，当地通常由委托人承担；合同未专列该项。书中支持双方明知且合法的习惯，并从公平、诚信解释费用安排。使用该例必须证明习惯存在及双方知情，不能把任何亏损泛称习惯成本。

**渔具代销定性（PDF2755—2756）：**经销者不能退货，自负产品经营责任，无独立受托报酬安排；二审按买卖关系处理，说明“办事处”“委托独立经营”字样不决定性质。退货权只是结合全部条款判断的重要证据，不能机械二分。
