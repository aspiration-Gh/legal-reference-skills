# 第十九章 运输合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记日期2020-07-15。全文阅读范围为PDF第2139—2319页（文件页码，不是印刷页码），对应源文ch19.txt。以下分为书载法条规则、编者解释和应用推演；制作时未作全量现行法更新，处理具体案件前须核验事件发生时适用的法律、司法解释、运输公约及行业规则。

## 核心问题与适用入口

先确定运输对象、运输方式、国内或涉外、合同承运人与实际履行者，再处理费用、损失和追偿。运输合同的特征给付是实现旅客或货物位移并取得运费；安排运输而仅收代理报酬，可能属于委托。赚取运费差价、合同名称含“物流”或“货代”，都不能单独决定性质。货物买卖、运输、保险、结算各有法律关系，货物所有权与运输合同请求权也不能混同（PDF第2139—2150页）。

## 八项核心规则

### 1. 主体和规范层级：先查谁向谁承诺全程运输

**书载规则及编者解释：**运输章提供一般规范；铁路、航空、海运及适用国际公约的特别规范，可能改变责任期间、免责事由、限额、通知和时效。书中按当时海商法区分国际海上货运与国内水路货运；该边界属于使用时必须复核的旧法前提。一般货运合同当事人为托运人与承运人，收货人直接履行或索赔请求权须查法定或约定依据，不能仅凭被列为收货人推定全部合同权利义务。编者主张可以结合合同目的和交易习惯解释第三人请求权，但强调谨慎论证，必要时通知托运人参加诉讼（PDF第2145—2150页）。

**判断分支：**查运输订单、委托范围、签单身份和付款路径；先识别承诺运输还是代为订约，再核验提单或运单权利。侵权与违约竞合不等于可规避运输特别法的抗辩及赔偿限制（PDF第2143—2144页）。

### 2. 公共运输与正常履行：拒载、路线和时间分别判断

**书载规则：**公共运输承运人不得拒绝通常、合理的运输要求；须按约定或合理期限安全运到约定地点，按约定或通常路线运输。因承运人偏离路线而增加的费用，旅客或货方可以拒付增加部分（PDF第2151—2178页）。

**编者解释：**公共运输重在公益性、公用事业性及承运人的优势地位，国际集装箱班轮虽定期定线，也不当然属于公共运输。义务不仅涉及缔约，还贯穿履约。满载、违禁品、违法超速要求以及有法定依据的限制乘坐，须分别评价；商业“黑名单”不能仅凭经营者声明取得正当性。通常路线不必是几何最短路线，合理绕行须看安全、共同利益和运输条件。未明确写明到达日，但约定速度或运输天数可计算期限的，仍属约定期限。

### 3. 客运成立、票证与服务：核对最终有效客票

**书载规则：**客运合同原则上自出具客票时成立，另有约定或交易习惯除外；须按有效客票时间、班次、座位乘坐。实名客票遗失可请求挂失补办，不得再次收取票款或不合理费用。旅客自身原因错过班次，与承运人迟延或提前发运，应分开处理。随身行李受限量、品类约束；危险物品处理、旅客配合安全安排均有专门要求（PDF第2179—2195页）。

**书载规则及编者解释：**不能正常运输时，即使损失不可归责于承运人，也须及时告知、提醒、采取必要安置措施，并按旅客要求处理改乘或退票；损害赔偿另查归责和特别法限额。降级服务可请求退票或减价，承运人单方升级不得加价；服务标准不限于换车换船，也包括座席和约定服务。已告知并取得旅客真实同意的变更，应与擅自降低区分（PDF第2196—2205页）。

### 4. 人身、随身物和托运行李：三种责任基础不能混用

**书载规则：**运输中的急病、分娩、遇险须尽力救助；旅客伤亡原则上由承运人赔偿，自身健康原因或旅客故意、重大过失等须依相应规则审查。法定免票、优待票、经许可无票搭乘的旅客，也受人身安全保护。随身物损失以承运人过错为基础，托运行李适用货运规则（PDF第2206—2218页）。

**编者解释：**“尽力”用可实施的客观措施评价，包括寻找专业人员、联络救援、合理临时停靠，并非保证抢救成功。自身疾病免责仍须结合救助义务；一般过失不能直接等同于重大过失。场站与运输工具交接处还须划清各经营主体职责。随身物主张应先证明物品、损失、运输期间及承运人过错，托运行李票证则可证明交付掌管。

**边界提示：**PDF第2215—2216页关于超量、违规品类物品“无论承运人过错与否”免责的表述过于概括；仅记为书中观点，不能直接据此排除故意侵害或其他法定责任。

### 5. 货方配合与途中变更：资料、包装、危险品及可操作性

**书载规则：**托运人应准确申报货物与收货信息，提交必要审批、检验等文件，并依约妥善包装；危险品须按法定要求包装、标识并提供书面资料。危险品义务不能通过普通包装约定排除。交付收货人前，托运人可要求中止、返还、改目的地或收货人，并赔偿承运人因此受损（PDF第2219—2239页）。

**编者解释：**包装应区分材料、方法、形式及内外包装；承运人参与包装的，不能一概用包装缺陷免责。申报不实与损失之间仍须有因果关系。任意变更受合法性、经济合理性及实际可执行性约束；提单已转让时还须保护持单人。不可执行的指示应及时说明原因，不能沉默放任。

### 6. 货损索赔：责任期间、检验、免责和数额依次处理

**书载规则：**货物在承运人掌管的运输过程中毁损、灭失，原则上承担赔偿；承运人证明不可抗力、货物自然性质或合理损耗、托运人或收货人过错等，并证明因果关系，才可能免责。赔偿额先查有效约定、补充解释，仍不能确定时依交付或应交付时到达地市场价；特别法另有计算方式或限额的另行处理（PDF第2242—2257页）。

**编者解释：**一般运输中，迟延验货或异议是完好交付的初步证据，可被相反证据推翻，不等于当然丧失赔偿权；但航空等特别法异议制度须单独核验。火灾、台风、暴雨不能仅凭名称认定不可抗力，要查预报、预防措施、通知及是否已迟延履行。投保货运险不消灭承运人责任，保险赔付后另处理代位；保价不等于固定额赔付，实际损失、保价上限、残值及节省费用分别核算。检验、分拣、合理处置等直接费用也可能属于损失。格式限赔条款须核查订入、提示说明、合理性与解释，不能一律有效或一律无效。

### 7. 运费、留置与无人提货：结算和返还不要混为一谈

**书载规则：**不可抗力导致货物灭失，原则上不得收取对应运费，已收可请求返还，法律另有规定除外。费用欠付时可依法留置相应货物，另有约定除外；收货人不明或无正当理由拒收时，可依法提存（PDF第2264—2278页）。

**编者解释：**到付只确定付款时间，不当然确定收货人是债务人；收货人始终拒绝提货，与已主张权利后迟延提货不同。留置须核查到期债权、合法持续占有、牵连关系、价值相当、禁止留置及替代担保；与企业间商事留置区分。无人提货仍应通知、保管，提存不同于随意另存或自行弃货。

**书内分歧：**PDF第2174—2176页以完成运输及避免双重损失解释，认为承运人应负责原因致灭失原则上不能赚取运费；第2264页又概括称承运人过错致毁损、灭失不使运费请求权消失。两处范围存在张力。实务应区分损坏、全部或部分灭失、是否可交付、有效风险约定及特殊规范，不能自行将两说合并为确定规则。书中援引的“运费不可触动”及水泥遇水结块、硫酸被大量水稀释的例子，是比较法辅助论证，不是普遍的该法域法抵销禁令。

### 8. 联运：先区分单式与多式，再定位损失区段

**书载规则及编者解释：**单式联运合同承运人负全程责任；货损可定位时，与该区段承运人承担相应连带责任，不是所有区段一律连带。货方先提供区段初步证据，相关承运人再反证交接一致。多式联运经营人自行或组织履行均负全程责任，内部区段协议不能对抗货方；不能直接套用单式联运条款判令全体连带（PDF第2258—2263、2279—2294页）。

多式联运单据有合同证明、收货及交付依据功能，可转让性与是否为物权凭证须分开；未签单时仍依有效交付指示。托运过错责任不因单据转让消失。损失可定位则按相关区段责任及限额处理，不可定位则按适用的全程合同制度处理。涉外还须确定准据法，不能机械适用该法域同类运输法。书中对诉讼时效是否随区段适用存在两说；不要把网状责任制当然扩张至时效，也不要把未生效公约或民间单证规则作为直接强制依据（PDF第2295—2319页）。

## 具体例证重构

**书中案例，PDF第2238—2239页：**隆达公司经货代安排不锈钢产品由宁波运至科伦坡，途中要求改港或退运。马士基及时回复距到港不足两日、原船退回不可操作，并说明目的港清关及申请退运程序。货物到港长期无人处理，后被海关拍卖。一审驳回货损请求，二审部分支持，再审恢复一审结果。论证链是：海运特别法未规定航程中变更时补充一般合同规则→托运人的变更权受实际可执行性限制→班轮还承载其他货主利益→承运人及时说明障碍→托运人明知到港而长期不处理，不能把后续风险全部转嫁。此处不补填源文未载的指导案例编号。

## 应用推演：办案和合同审查步骤

1. 固定订单、全程及分段合同、客票/运单/提单正背面、代理授权、装卸与交接记录，画出主体和掌管时间线。
2. 将诉求拆为人身、随身物、托运行李、货损、迟延经济损失、运费或仓储费；分别确认请求权人和义务人。
3. 固定损失发生区段、签收保留、照片、封志、温控和定位数据、检验鉴定、救援与天气记录，立即核查通知期限、诉讼时效和追偿时效。
4. 单列免责事实、因果关系、限赔条款、实际损失、残值及保险已赔，避免重复受偿；变更和拒收争议保存通知送达与操作障碍证据。
