# 第二十六章 中介合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15；全文阅读PDF2798—2823，源ch26.txt。法条层为书载规范提要，编者解释保留历史立场，应用推演为案件分析方法。使用前核验现行法律、司法解释及行为时规则；本章未实施全量现行法更新。

## 核心问题与规则

### 1. 识别报告中介、媒介中介与混合服务（PDF2798—2803）

**法条层：**中介人报告订约机会或提供订约媒介，委托人支付报酬。旧“居间”更名为“中介”。

**编者解释：**报告中介侧重提供机会，媒介中介还包括居中斡旋、传达意思、促成合意。中介不以自己或委托人名义直接成为交易合同一方；若另有代签、收付款、过户服务，须分别识别授权与委托内容。合同是有偿、诺成、不要式；中介合同成立不以最后交易成功为条件。书中以平台注册及接受服务协议说明：用户借款失败，并不当然表示平台服务合同没成立，交易成功属于报酬条件的另一层判断。该平台例是旧业务背景，不表示相关经营当前合法。

技术中介还可能涉及履行阶段的专门服务，书中引用草案及技术合同司法解释单独讨论费用、报酬及交易无效的影响，实务须核现行特别规则，不能把草案编号当生效条文。中介资质亦须按行业核验，不仅凭普通中介定义确定。

### 2. 忠实报告、尽力与保密（PDF2804—2807）

**法条层：**中介应如实报告有关订约事项；故意隐瞒重要事实或提供虚假情况、损害委托人利益，丧失报酬请求并承担赔偿。

**编者解释：**报告中介要尽力提供有用机会，媒介中介还须斡旋；不得为一方利益不当妨害订约，应保护相关商业信息。书中比较仅免佣、限缔约损失及按实际损失赔偿的观点，主张免佣与赔偿可以并存，损失评定结合过错与主观恶意。但适用仍须证明义务违反、损害及因果关系，不能以主观不满代替证据。

**应用推演：**核中介知道什么、何时知道、向谁作了何种表示，特别是资格、权属、抵押查封、付款及融资条件等影响订约的重要事实；具体调查范围以合同、行业规范及现行规则为准，不自行增加无限担保责任。

### 3. 成交报酬与未成交费用分列（PDF2808—2814）

**法条层：**促成合同成立，按约支付报酬；数额无法依补充协议、相关条款和交易习惯确定的，按劳务合理确定。媒介促成成立，原则上由交易双方平均负担，另有约定从约定。促成交易的中介活动费用由中介负担；未促成成立不得请求报酬，可以按照约定请求必要费用。

**编者解释及争点：**书中强调“成立”与“履行完成”不同。具体合同若包括贷款、登记等分阶段服务，应核报酬支付节点和未完成义务，不能仅以通用定义否定明确约定。未成交费用方面，PDF2813列两说：有约定才可索费，或无约定也可索费；编者倾向后说。这一解释与新增“按照约定”的文字关系紧张，必须标为待核验，不能直接输出“没约定也一定能报销”。必要费用需实际支出、用于该次中介且合理，不可把佣金改名为交通费规避未成交不付酬规则。

中介收费高不等于法院可任意调整。书中在PDF2813—2814区分订立时显失公平的撤销与成立后情势变更：前者还须利用危困、缺乏判断能力等要件，后者须不可预见、超出商业风险的基础重大变化、继续履行明显不公平并先协商。不能只凭“同行更便宜”套用。

### 4. 交易落空：先查中介义务和原因（PDF2806—2807、2810—2811）

**编者解释：**房屋合同签订后因限购限贷不能履行，有观点支持退佣扣必要费用，有观点认为促成即应得佣；编者从忠实履职分流。中介忠实提供信息并促成成立，交易后来因政策不能履行，不当然退佣；明知不具资格或不能贷款仍作虚假承诺、隐瞒事实，则可能退佣并赔偿。此结论须结合约定成果及付款节点。

“阴阳合同”佣金基数，书中比较备案价与真实价并倾向真实成交价。其反避税及效力论证含旧术语，实务应分别核真实意思、隐藏行为效力、税收处理及中介参与违法行为的责任，不能从计佣基数推得全部交易合法。

### 5. 跳单核查接受、利用与绕开（PDF2815—2819）

**法条层：**委托人接受中介服务后，利用其提供的交易机会或媒介服务，绕开中介直接订立合同，仍应支付报酬。

**编者解释：**逐项查中介关系及服务接受、该服务对成交的利用、绕开行为。绕开可表现为私下成交、借另一中介完成已基本谈成的交易、借亲友名义交易；不能只凭先带看就认定利用。多家中介掌握同一房源时，须核信息来源、服务内容及最终达成交易的路径，保护合法选择权。

跳单报酬性质有履行对价与违约责任两说，编者倾向违约责任，并主张结合已完成服务程度定数额；不能把此解释写成法条当然只付部分佣金。禁止跳单格式条款仍须接受提示说明、效力及不合理限制主要权利的审查，“看过房就禁止经任何其他渠道购买”不能自动取得效力。

### 6. 有选择地参照委托，处理解除与终止（PDF2820—2823）

**法条层：**本章未规定事项参照委托合同规定。

**编者解释：**可以就受托事项范围、遵守及变更指示、报告、解除、主体变故终止等考察相似性。编者倾向双方可随时解除，有偿关系的解除损失包括直接及可得利益；但须与本章促成报酬、未成交费用的特别规则协调，不能通过“解除赔偿”无证据转成全额未赚取佣金。委托人死亡、终止及中介人死亡、丧失行为能力、终止，原则上终止，约定或事务性质另有例外；为防终止损害利益可有必要继续处理。书中“亲自处理及转委托”标题主要讲变更指示，未详细给出中介转委托机制，不以标题补造具体规则。

## 判断步骤与证据（应用推演）

1. **拆分服务包：**报告信息、撮合、代签、贷款协助、登记等分别列合同依据、成果及收费条件；确定中介合同与交易合同各自成立时间。
2. **查忠实履职：**收委托书、服务协议、挂牌资料、权属核验材料、聊天录音、风险提示签收、带看记录、磋商稿；核信息真假、重要性、中介认知及委托人依赖。
3. **查成果及因果：**交易是否成立、谁撮合、后来未履行的原因是什么。政策变更、新旧资格限制、中介误导、交易方违约不得混作同一原因。
4. **算请求：**佣金、必要支出、返还、赔偿、跳单约定违约金各列依据；标记已付金额、应付阶段、未完成服务及节省费用，审是否重复补偿。
5. **跳单专线：**比较各中介信息获知日期、独立来源、报价及谈判贡献，调最终合同及实际买受人关系；先证明利用，后审禁止跳单条款及金额。

## 书中例证重构

**政策与虚假贷款承诺（PDF2806—2807）：**中介如实促成买卖，后因政策无法履行，书中不支持仅凭这一事实退佣；若明知买方受限贷仍承诺能办贷款，并向卖方隐瞒相关限制，导致交易不能履行，则支持返还与损害赔偿。应用时需要对照政策生效日、承诺日及中介已知事实。

**非独家房源选择（PDF2816—2819）：**多家中介均掌握同一房源，甲中介先带看，不自动排除买方经乙中介合法成交。若甲已谈成主要条件，买方仅为省费转向乙签约，书中认为可能跳单。区别在最终是否利用甲的机会和服务，而非单纯看房先后。

**保证中标协议（PDF2803）：**书中认为仅报告公开招标信息、以保证中标收钱的约定，不符合其分析的普通中介服务特征。实务应继续审真实服务及招投标合法性，不得据此反推该协议有效或保证结果可以强制实现。
