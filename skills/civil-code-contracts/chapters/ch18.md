# 第十八章 建设工程合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15。已顺序读完 ch18.txt，覆盖 **PDF1965—2109页**。引用均为PDF文件页码。本章是旧版书籍提炼；书载旧司法解释、利率和权利行使期间不得直接作为现行依据。使用时先确定事实发生时间，再核验官方现行规范与过渡规则。“书载规范”“编者解释”“应用推演”分层使用。

## 核心问题与范围

建设工程是特殊承揽，处理主线为“合同和主体—效力—已完成工程质量—价款与损失—解除—优先受偿”。勘察、设计、施工分别有合同；监理本质属委托。工程的公共安全影响使资质、招标、强制技术标准及使用条件限制当事人自治，不能将普通承揽规则全部移植。

## 八项核心规则

### 1. 定性、形式及文件体系（PDF1965—1974、1998—2000）

**书载规范及编者解释：**工程包括相关土木建筑、线路管道设备安装、新扩改建及大型装饰活动。与普通承揽的界限，应结合投资、技术、用途及主体综合判断；书中将部分自用住宅、简单修缮和临时简易建筑列为承揽情形，不能据此把所有自建房或家装排除于工程监管。

建设工程应书面订立；未签书面合同但主要义务已履行、对方接受，先审是否成立，再审效力。质量合格且能证明价格约定的，有效合同依约付款，无效合同参照约定折价补偿；价格不能查明再考虑市场造价鉴定。不能因缺书面合同一律扣除利润返还成本。

合同文件包括协议书、招投标文件、专用和通用条款、图纸、工程量清单及合法补充文件。签证应查签署人的授权、职权、范围及内容真实性；会议纪要查有权代表签署，函件查双方合意或单方确认。书中2017示范文本属非强制文本，其文件顺位不能超越招投标强制约束。国家重大工程另查批准投资计划、可研及订约程序。

### 2. 招投标、黑白合同与变更（PDF1975—1987）

**书载规范：**依法必须招标而未招标或中标无效，影响施工合同效力；招标、投标、中标分别涉及要约邀请、要约、承诺。书中详列串通、泄密、借名、弄虚作假、违法谈判、违法选定中标人等情形，需核具体法定要件，不能仅因程序瑕疵笼统无效。

**编者解释：**先查中标合同是否有效，才谈与之实质背离的另行协议。实质内容通常为范围、工期、质量、价款及影响公平竞争的条件；正常施工细节完善并非当然“黑合同”。中标合同不以备案为本质条件。仅有招标前意向书也不能直接推定串标。

非必须招标工程自愿招标后，也原则遵守中标条件；书中保留招标时难以预见的客观重大变化例外，如异常材料设备价格、人工价格或规划设计变化。多份合同均无效而质量合格，书中主张参照实际履行合同，无法确定再参照最后签订合同。已结算完毕欲推翻结算，还须审查胁迫等依据。

中标通知到达即本约成立，还是成立预约，书中并列两说未定论；无论采取何说，拒绝签约的责任、保证金返还和实际损失均应单独查明，不能虚称已有统一答案。

### 3. 承发包链、资质及实际施工人（PDF1988—1997、2014—2016）

**书载规范：**禁止支解发包、转包及违法分包；合法分包需相应资质、发包人同意，不得违法再分包，主体结构由承包人自行完成。总承包人与分包人对分包成果向发包人负连带责任。不能借普通承揽的同意规则使法律禁止的工程转包合法化。

**编者解释：**分清总包、专业分包、劳务分包、转包和挂靠，不按名称认定。劳务作业分包与专业工程再分包不同，书中允许符合资质的劳务分包并要求劳务承包方不再转交，其监管条件须查新规。

实际施工人特殊请求与代位权是两条路径。书载特殊路径要求查明其对转包、违法分包人的债权和发包人欠付价款，追加相关第三人后在欠付范围内判责，不能只判一个无法执行的抽象范围；工程质量须满足请求价款条件。代位诉讼另查到期债权、怠于行使、影响债权实现及非专属性，不得省略要件。书内在不同段落对实际施工人是否含挂靠者的用语较宽窄不一，不能由概念包含直接推出其享有特殊请求权。

挂靠、出借资质造成损失，书中支持借用与出借方连带赔偿；对非质量损失仍须证明因果关系，发包人明知或未减损的过错不等于承包人后来所有履行责任均减免。

### 4. 无效、质量与折价补偿（PDF2001—2016）

**书载规范：**合同无效而工程验收合格，可参照约定工程价款折价补偿；不合格须区分修复后合格与仍不合格，前者处理修复费用和补偿，后者不支持相应价款请求；发包人对不合格有过错亦担责。已完成部分未竣工也应独立审查质量，不能只因未竣工否定全部补偿。

**编者解释：**质量合格不使无效合同转为有效；折价补偿不是有效合同履行价款请求。参照约定可减少鉴定成本，防止一方恶意主张无效以获得额外利益，也避免利润价值无偿归发包人。无资质、超资质、借名、应招未招、转包违法分包、规划审批缺失等分别查，书中还讨论竣工前补足资质、起诉前补办规划的例外；不能把所有行政违法都认定为民事无效。

另行赔偿须证明过错、实际损失和因果关系，区分导致无效与导致质量缺陷的原因。编者通常将无效赔偿定位为信赖利益损失，不当然包含可得利益；实际损失难确定时可参照约定质量、工期、付款节点量化，不是直接执行无效违约金条款。欠款利息在书中另按法定孳息讨论，不混入按过错分摊的损失。

### 5. 勘察设计、造价结算与监理（PDF2017—2037、2053—2058、2088—2091）

**书载规范：**勘察设计约定资料提交、质量、费用和协作；施工合同通常约定范围、工期、造价、供料、拨款结算、验收及保修。勘察设计须符合强制标准，不能以发包人要求免责；文件修改须由适格主体进行，交付后仍负设计交底、解释和现场问题协助义务。因发包人变更计划、资料错误或条件迟延增加工作量，按实际消耗增付费用，并审工期和其他损失。

**编者解释：**新增或设计变更部分先依约计价，不能协商时书中参考原订约时当地计价标准；仍以质量合格为支付条件。逾期不答复视为认可结算，必须有明确约定、书面递交证据及期限内未答复，不能仅凭承包人单方报送产生最终结算。

欠款利息先查约定与应付日；无明确付款时间，书载顺序考察实际交付、提交竣工结算文件、起诉等时点。编者认为无效合同亦可参照约定利息，以避免鼓励恶意占款；此属争议立场，旧贷款利率及利率上限不得径用。

监理合同属书面委托，先核资质、强制监理和招标要求、授权范围及通知。监理不履职造成损失与施工责任分别判断；与承包人串通致损才据相应规则论连带，不能一有质量问题就令监理承担全部责任。

### 6. 施工协作、隐蔽工程、停工与垫资（PDF2038—2045、2078—2091）

**书载规范：**发包人可不妨碍正常作业地检查进度质量；隐蔽前承包人应通知检查，发包人迟检可导致顺延与停窝工赔偿；发包人未按约提供材料、设备、场地、资金和技术资料，或其原因造成停建缓建，应处理相应工期、损失及已完工程价款。

**编者解释：**一般检查权与隐蔽、节点验收义务不同。先自检、再通知、检查确认、必要返修复检后覆盖，保留记录。示范文本中的提前通知、延期和视为合格机制须查是否纳入合同；未按时检查不等于实际质量永远免责。擅自隐蔽而不能证明通知，承包人面临揭开检查费用及工期风险。

停窝工须区分发包人、承包人、共同原因及不可抗力，证明具体影响；损失可依索赔签证、合同标准、鉴定或有依据估算，且须减损。施工单位对甲供料仍负检测义务，不合格不得用；乙供料中的违法指定、图纸错误也须分因。

垫资约定、未约定而形成欠款、垫资利息、逾期利息应分别核算。书中认为垫资原则有效，无约定垫资利息不当然支持；对政府投资不得垫资的规定，编者倾向管理性解释以保护承包人利益。该立场不能转化为可规避政府投资禁令的建议，适用时重点核验规范性质和时效。

### 7. 验收、保修及质量损害（PDF2046—2077）

**书载规范：**竣工应及时验收，合格接收并依约付款；未验收或不合格不得交付使用。施工人原因致质量不符，应合理期限内无偿修理返工改建，造成逾期交付仍担责。建设工程合理使用期限内因承包人原因造成人身财产损害，应承担赔偿。

**编者解释：**发包人擅用未经竣工验收工程，对已使用部分的质量主张受限制；未使用部分、使用前已证实且要求修复的缺陷，以及地基基础和主体结构责任须区分，不能理解为使用即免除所有质量责任。轻微可修复问题不当然支持拒付全部价款，修复费用与责任范围应匹配。

保修期、缺陷责任期、合理使用期限、土地使用年限不是同一概念；质保金返还不消灭保修义务。书中列举最低保修期限和返还节点，使用须核正式规范。编者关于可参照保修期认定合理使用期限、期限外免责的论断，须与设计年限、损害形成原因及侵权规则另行审查，不能压缩为保修一过绝对免责。

举证结合阶段：未完工程价款请求要说明已完质量；验收后再主张缺陷一般由主张者举证，名义验收亦不终局排除质量审查。明显裂缝、渗水可凭照片、录像、勘验等证明，不是所有争点必须鉴定；专业鉴定须经质证，不能以鉴代审。损害另分工程自身瑕疵与他人人身财产损害、对发包人与对第三人责任。

### 8. 解除、优先受偿与准用限度（PDF2092—2109）

**书载规范：**转包、违法分包可使发包人取得解除权；主要材料设备不合强制标准或协助不履行，导致无法施工，经催告合理期限仍不履行，承包人可解除。未付款、根本违约等另联通则。解除后已完合格部分依约支付，不合格按修复规则处理。无权解除的通知不因对方未及时异议自动有效。

工程价款优先受偿须核主体、欠款、催告、工程适宜折价拍卖、质量及行使方式。书中认为系法定优先权，不以占有、登记、合同有效或全工程竣工为必要。原则主体为与发包人订施工合同者；勘察设计、实际施工人及分包人不当然享有。支解发包仅主体工程承包人享有、挂靠时权利主体如何认定，属于书中解释或未决讨论。

书载优先范围包括规范确定的工程价款，排除逾期利息、违约金和损害赔偿；装饰装修还查发包人是否所有权人及增值范围。与商品房消费者、抵押权、普通债权冲突必须另核规则。书中将优先权期间记为“自应付款日起六个月”，仅是旧版记载，**不得据此设定现行办案期限**。约定放弃或限制且损害建筑工人利益的，不能据之否定优先权。行权是否充分应逐一查诉请、协议折价等行为，不用“曾催款”替代法定审查。

建设工程欠款不能直接依承揽规则留置不动产；PDF2109明确发包人原则上不享有普通定作人的任意解除权。

## 具体例证与论证重构

**专业分工或支解发包（PDF1991）：**书中举一幢房屋供水管线，不宜拆成若干段给多个承包人；但供水管线与空调安装技术专业不同，可分别发包。判断依据是工程性质、技术联系和统筹质量责任，不是仅看是否同一建筑或合同数量。

**明显缺陷与鉴定（PDF2069）：**承包人完成主体后因欠款停工，双方解约，移交时墙体、屋顶有明显裂痕，承包人拒修而起诉工程款。编者认为照片、录像、现场勘验即可形成质量证据，不宜强迫发包人为显见缺陷先作鉴定。该例仅支持证据路径；缺陷成因、修复方案及金额仍可能需专业认定。

## 应用推演：判断步骤与证据

1. 绘制业主、签约承包人、实际作业者、勘察设计监理的合同链，收集资质、审批、招投标及资金性质；分开成立、效力与履约。
2. 用图纸版本、工程量、签证授权、材料检测、隐蔽记录、监理日志确定已完范围与质量，选择真正需鉴定的争点。
3. 以变更指令、付款流水、停复工通知、人员机械台账和关键工序记录证明迟延、因果关系与损失，核减损及重复索赔。
4. 固定验收申请、送达、实际使用、结算报送及回复，拆分本金、修复扣款、质保金、利息与损害赔偿。
5. 解除先核权利与催告、再做移交清算；优先权另核法定期限、主体、对象、范围及竞争权利，不能待普通欠款诉讼结束再开始检查。

## OCR未决与现行核验

多处条文框损坏，依正文释义提炼未补造条号。PDF2052有“修复后仍然合格却无权请求价款”，与相邻反复论述冲突；按上下文只作“修复后仍不合格不支持”的释义，原页疑似漏字未决。PDF2103“不合格工程一般也适于折价拍卖”同样疑似漏否定词，本文未照此提出结论。PDF2089—2090资料表跨页错列，未将其天数复制为普遍义务。

优先联网核验：建设工程司法解释整合与新规则；实际施工人、挂靠及代位权边界；资质改革、规划补正、必须招标范围及金额；质量强制标准、验收和质保金规则；政府投资垫资、付款条件及利率；优先权期限、装饰装修对象、商品房消费者权利顺位与执行程序。制作本章未进行全量法律更新。
