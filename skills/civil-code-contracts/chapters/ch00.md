# 绪论：《民法典》编纂概述——案件定位与新旧规则分流

## 来源与阅读覆盖

《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，人民法院出版社；据任务元数据后记日期为2020-07-15，版次未确认。源文 `ch00.txt` 已顺序完整阅读，覆盖 **PDF第32–45页**，不含第46页分编扉页。绪论没有连续逐条释义范围；第38–45页按通则、典型合同、准合同介绍制度变化。

标识约定：**【书中法条】**仅表示原书转述或引述的法律内容；**【编者解释】**为原书理解、评价或比较；**【应用推演】**为据此组织的实务操作。均不代表已核验现行法，办理具体事务须先确定事实时间，再联网查官方有效文本及过渡规则。

## 核心问题

【编者解释】编纂是既有民事规范的整合、修改及补充，并非将旧法简单合订，也不是完全重新制定规则（PDF第32–37页）。实务价值在于识别：案件处在合同生命周期哪一步，是否存在典型合同特别规则，以及新旧法之间哪一项变化足以改变结果。绪论的历史、制度意义部分用于理解体系，不作为独立请求权依据。

## 适用条件与例外：全书入口

- **订立和效力**：电子订单成立、预约合同、格式条款分别进入第二章；批准生效及报批义务进入第三章。特别注意条款“未订入”与条款“无效”的不同（PDF第39–40页）。
- **履行及债权实现**：多数人之债、绿色履行、情势变更进入第四章；代位权和撤销权进入第五章。债权尚未到期并不意味着任何保全措施都不可用，绪论专门介绍到期前代位保护的特殊情形，但须查相应构成要件（PDF第38、40–41页）。
- **主体和债务变化**：债权转让、从权利转移、债务加入进入第六章。书中区分金钱与非金钱债权禁止转让约定的对外效力，不得用一句“禁止转让”处理所有情形（PDF第41–42页）。
- **终止与责任**：不足清偿的抵充顺序、解除通知和解除后责任进入第七章；定金、替代履行、与有过失进入第八章。约定定金及违约金不等于可以重复取得两项救济；不足损失的补偿另作判断（PDF第42–43页）。
- **典型合同**：保证、保理、物业服务、合伙是本书列出的新增类型。买卖中的无权处分、检验、所有权保留；借款利率；租赁登记及优先权；客运安全和迟延安排，分别进入对应专章（PDF第43–45页）。
- **非合同之债**：【书中法条】第468条采用特别规定优先、通则补充并受性质限制的路径。无因管理、不当得利不能因编入合同编就被当作有合意的合同；分别读取第二十八、二十九章（PDF第38、45页）。

## 实务判断步骤

【应用推演】

1. 建立时间轴：接触、订约、交付、违约、变更及争议发生日期分别记录，不能仅以起诉日期选择实体规则。
2. 写明请求的法律效果：要求成立、履行、解除、返还，还是损害赔偿；据此选通则章节。
3. 按给付内容识别合同类型，不只看文件名称；再进入典型合同章节查特别要件。
4. 把影响结论的书中“新增、改变、完善”规则列为核验清单，核对旧法、民法典及适用时点司法解释，避免拼接不同年代规则。
5. 形成两层结论：“书中如何分析”与“案件适用规则核验后如何分析”；未核实的问题保留条件式结论。

## 证据清单

【应用推演】完整合同及版本、订约和履行时间证据、主体及授权资料、电子订单和提示页面、报批材料、支付与交付记录、债务及担保关系图、解除通知及到达凭证。证据收集范围由实际争点决定，绪论本身不提供通用举证责任分配。

## 书中论证的压缩重构

**保证方式为什么必须先分时点（PDF第43页）**：【书中法条】原书明确介绍第686条第2款：没有约定或约定不明确时，按一般保证承担责任；【编者解释】强调其改变了原《担保法》的认定规则。压缩后的判断是：面对“没有写保证方式”的合同，先找适用时期及过渡规范，再到保证章判断责任，不能直接复制本书第二章旧案使用的默认连带责任结论。本例是书中立法变化论证的重构，不是新增判例。

**交易合同与权利转移分开（PDF第44页）**：【编者解释】介绍第597条时，以负担行为与处分行为区分为基础，说明未取得处分权导致不能转移所有权时的解除和违约救济。由此只能提出“合同效力与权利变动分别审查”的入口，不能直接认定所有无权处分情形结论相同。

## 争点、误区及需核验的现行法

不要把编者关于制度意义的评价当成法律层级规则；不要把绪论的“新增”理解为办案时仍属最新；不要从制度提要直接跳到责任金额。源文少量页眉及文字缺字，未据记忆补全文。

使用时核验：《民法典》及其时间效力规则、合同编通则相关司法解释、保证等具体争议领域的司法解释和特别法。官方来源优先使用国家法律法规数据库、全国人大及最高人民法院发布文本；记录公布、生效及修订信息，本章未进行全量法律更新。
