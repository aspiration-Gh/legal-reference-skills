# 第二十八章 无因管理

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15；完整阅读PDF2865—2886，源ch28.txt。法条层、编者解释、应用推演分别标注；书载外国法和已被替代旧法用于理解论证，不作现行依据。实际使用核验现行法及事实发生时规则。

## 核心问题与规则

### 1. 先排除既有义务，再审为他人管理（PDF2865—2869）

**法条层：**没有法定或约定义务，为避免他人利益受损管理其事务，构成相应法定债的基础。

**编者解释：**作为债发生原因的管理是事实行为，所管理的事务可包括事实或法律行为。客观上有无义务须先核实：误以为自己有义务不当然排除，实际有义务即不能只因自认为热心助人而成立。公法义务、私法义务均应审；连带债务人超额清偿自己的连带债务，应走内部追偿，不走无因管理。

主观上须把管理利益归于真正受益人，为自己也为别人保护利益的混合动机可成立；不必准确知道受益人姓名，误认甲的事务实属乙，不当然妨碍对乙成立。书中排除明知他人事务却据为己有、误把他人事务当自己事务等不真正管理，并区分适法、不适法的真正管理。不要只凭客观让别人获利就自动成立。

**应用推演：**先列合同、职务、法定救助及善后义务，再查事发时是否自愿承担他人事务及损失危险；已有物业交接或委托善后特别义务，应优先审其特别规则。

### 2. 真实意思与利益不能互相替代（PDF2868—2871）

**法条层：**管理不符合受益人真实意思，原则不享有通常费用及补偿请求；真实意思违反法律或公序良俗的除外。

**编者解释：**真实意思可由曾经明确表达、平常处理方式和客观情形推知，不以向管理人亲口下指示为必要；若本人已经明确委托且管理人接受，可能直接是委托合同。书中认为私人事务、合法且适合作为债务目的的事项才适用，专属性事务、公共事务及纯道德事项另论。主动洗路边车或把收藏古董高价卖掉，虽使他人受益，书中不认为就是避免其损失的正当管理。

公共利益例外须有实质根据。书中救助自杀者、代履行扶养等例子，体现真实意思与法定保护利益冲突的特殊衡量，不可据此泛化“我认为对你好就可强行管理”。涉及医疗自主、人身自由等，应另核相关特别规则。

### 3. 必要费用、实际损失与受益限额（PDF2869—2874）

**法条层：**符合一般管理要求，可请求偿还必要费用，因管理受损可请求适当补偿；不属于前述情形但受益人享有管理利益的，责任限于获得利益范围。

**编者解释：**必要性按支出当时客观情况，不能事后因救助失败便全部否定。损失补偿区分财产、人身实际损失与报酬、可得利益；书中不支持借损失名义变相收服务利润，对管理人故意重大过失造成自身损失另作排除。因管理向第三人负债，编者讨论代清偿，但应分别核对外签约名义及有无代理权，内部无因管理不自动使本人对第三人承担合同债务。

不适法管理的规则不能照搬一般无因管理的全部赔偿。须证明实际获益，费用加补偿不得突破相应获益边界。PDF2873又把本人是否“主张利益”作为重要因素，存在与法条“享有管理利益”用语衔接问题，应标记为解释争点；不能仅以本人拒绝付款推定从未受益。

见义勇为受伤时，还可能与第三人侵权及受益补偿规则交叉。书中对此引用多部旧法，当前应核对应现行规范及优先、补充关系，防止遗漏直接侵权人或重复赔偿。

### 4. 开始、实施方法与继续管理分阶段审查（PDF2875—2879）

**法条层：**管理应采取有利于受益人的方法；中断管理对受益人不利时，无正当理由不得中断。

**编者解释：**开始时能否成立无因管理、过程中方法是否妥当、最后是否成功，是三个问题；不能因结果不好一概否定开始的正当性。编者以无偿互助为由主张不苛求过高注意，并讨论紧急救助减责。但正文对注意标准及责任表述有冲突，不宜据此形成统一“只有重大过失才负责”的现行结论。是否紧急救助、管理人专业能力、当时可选方案以及特别免责规则应另核。

继续管理不是无期限义务。应比较停止会否比从未介入更危险，是否已由本人、继承人或代理人接手，继续是否违反真实意思或显然有害。需要停止时要采取合理交接或安全退出措施；这项安排是应用推演，具体义务仍依案件条件判断。

### 5. 通知、等待、报告与财产转交（PDF2880—2883）

**法条层：**能够通知应及时通知；不需紧急处理时等待指示；结束后报告情况并转交管理取得财产。

**编者解释：**通知以可能且必要为前提，不知受益人或客观无法联系，应保留说明；本人已经知道，不宜重复苛求。拒绝继续管理后原则停止，公序良俗例外另查。单纯沉默不能自动形成委托合同；继续管理仍依无因管理条件判断。

报告包括经过、结果、取得利益及费用支出，即便中断也须说明。取得金钱、物品、孳息及权利均应移交；以自己名义取得权利须办理移转，不能因无人主动询问便据为己有。对拒绝交付，书中还讨论不当得利返还，实务应先核原法定债请求并避免重复获偿。

### 6. 追认的溯及效力与委托关系（PDF2884—2886）

**法条层：**受益人追认后，原则自管理开始适用委托合同规定，管理人另有意思表示除外。

**编者解释：**须区分对管理授权的追认与仅认可工作效果、表示感谢；后者不当然建立委托。书中将追认视为有相对人的单方行为，通常要求明示；具体表现应依法核验。追认前后费用、责任和成果转移仍需按规则衔接，不当然转为有偿委托。

委托合同后来无效或被撤销，编者主张优先按该合同效力瑕疵的后果处理，不因客观欠缺有效合同就一律转成无因管理。书中保姆委托终止后继续照料无人看护孩子的例子，也应先排除仍存在的法定善后义务，再决定能否转换法律关系。

## 判断步骤与证据（应用推演）

1. **义务筛查：**合同、岗位、亲属扶养、法律规定、此前管理及后合同义务逐项排查。证明“没有约定”还需解释是否存在默示接受或授权。
2. **开始时事实：**损失危险、受益人事务归属、管理目的与本人既有意思；收现场影像、见证人、报警或求助记录、此前聊天，分别证明紧急程度与管理动机。
3. **履行时间线：**采取何措施、成本、可替代方案、何时通知、本人如何回应、何时可接手。记录失联尝试，避免事后只称“联系不上”。
4. **分项核算：**必要支出、管理人实际损失、取得并应交利益、本人实际获益分别列账；不适法分支另设利益上限，费用证明与损失证明不能互相代替。
5. **请求权竞合：**有侵权人先核侵权责任；有代理或委托追认核合同分支；无管理意思或仅被动得利转读不当得利。结论写清每条路径条件与不能重复获偿的范围。

## 书中具体例证重构

**失火邻居（PDF2868）：**帮邻居灭火兼有防止烧到自己家的目的，只要同时为避免邻居损失、使利益归邻居，仍可能构成无因管理。该例反对以管理人也受益为由直接排除，不免除既有法定义务的先行核查。

**揭去屋瓦后停工（PDF2877）：**管理人为他人修屋已揭瓦，突然离开使房屋比未修更易受雨损，应继续必要工作或妥善衔接。义务来自管理已改变风险状态，而非单纯“开始帮忙就必须无条件做到底”。

**暴雨修屋与委托（PDF2871）：**主人曾说房屋要修但外出未修，邻居遇暴雨主动修补，可依既有意思审无因管理；若主人已直接请邻居代修且被接受，则应审委托，不能同时忽视既有合同。
