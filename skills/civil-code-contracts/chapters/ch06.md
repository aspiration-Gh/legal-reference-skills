# 第六章　合同的变更和转让

## 来源、核心问题与边界

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记日期2020-07-15。源文PDF第585–623页已顺序全文阅读。使用本章分析“合同改了什么、谁可以向谁主张、谁仍负担债务”，并核验行为发生时的现行规范与过渡规则。下列书载规范、编者解释和应用推演分别标注；本章没有完成外部法律更新。

## 七组核心规则

### 一、内容变更须有明确合意，变更不明回到原约（PDF 585–590）

**书载规则**：当事人协商一致可变更合同；变更内容约定不明确，推定未变更。

**编者解释**：先确认有合法有效的原合同，再确认变更的是内容，而非主体替换。价款、数量、质量、期限、履行方式、担保、责任及解除事由等均可能调整。变更合意也须符合订约和效力规则；原合同无效不能只靠“补充协议”当然修复。需批准的特殊变更仍查相应法律，不能因总则删除旧报批条文便认为手续一律取消。

明知变更要求而不回答，不当然构成同意；明确行为接受变更履行可成为合意证据。双方若只是接受部分给付，尚不能跳过意思解释。除另有约定，变更通常向将来生效，不据此要求退回已按原约完成的给付；未变部分继续有效。形成书面变更有助减少证据争议，但形式要求仍须按合同类型、特别规定及双方安排判断。法定情势变更是另一路径，不属于一方有权任意改价。

### 二、债权转让先审可转让性，再审通知（PDF 591–597）

**书载规则**：债权原则上可全部或部分转让；性质、约定或法律禁止转让时分别处理。约定非金钱债权不得转让，不得对抗善意第三人；约定金钱债权不得转让，不得对抗第三人。

**编者解释**：金钱债权的约定禁转不能据受让人知情就否定受让效力，但不等于原当事人间的禁转约定不存在，更不排除法定或性质上的限制。受让前要核实债权存在、归属和处分权限，以及转让协议、特殊手续；不能只凭一张让与合同证明基础债权。

债权转让不以债务人同意为要件；未通知，只是不对债务人发生效力，不当然否定让与人与受让人之间的协议。书中部分段落概称“通知才生效”，应结合PDF 597、616页对内外效力的明确区分阅读。转让通知原则上不得撤销，经受让人同意除外。

通知对象是债务人或其有权代理人。编者允许受让人有充分转让证据时例外通知，也讨论口头、书面、登报方式，但不同债权的有效通知条件不能一概而论。负责通知者须证明内容、对象、到达及范围；“别人告诉债务人”不能直接替代有效通知。

### 三、从权利随转让，但要清点专属性与公示风险（PDF 598–599）

**书载规则**：受让人取得相关从权利，专属于原债权人自身者除外；取得从权利不因未办转移登记或未转移占有而受影响。

**编者解释**：区分从权利依法随主债权移转，与原担保权是否已经成立、是否存在第三人权利冲突。不能把无需再登记才取得，理解为原先从未设立的担保亦自动产生。应移交担保合同、登记信息、权利凭证和占有资料，并核对专属性、剩余期限、权利行使条件；涉及第三人时另查公示及善意保护规则。

### 四、抗辩保留，抵销另查特别条件（PDF 600–607）

**书载规则**：债务人接到转让通知后，对让与人的抗辩仍可向受让人主张。债务人在通知时已对让与人享有债权，且其债权先到期或同时到期，或者两项债权基于同一合同产生，可按相应规定向受让人主张抵销。转让增加的履行费用由让与人负担。

**编者解释**：转让不应让债务人丧失履行、时效、合同效力等抗辩，也不能使已存在的瑕疵被“洗白”。诉讼中是否追加原债权人为第三人，应看是否涉及原债权本身的抗辩，不能逢转让必追加。

抵销不是一般抗辩的同义词。分别记录通知时点、反向债权取得时间、两债到期日及同一合同关系。PDF 604页称同一合同项下到期及种类条件可不问，属于编者较宽解释，实际使用仍须核对现行司法解释与普通抵销规则，不能据此用任何未届期非同种给付直接冲抵。费用未偿还是否支持拒绝履行，也须有对待给付等条件；单纯增加费用请求与原债务通常不构成对待给付。

### 五、免责债务承担须债权人同意（PDF 608–610）

**书载规则**：债务全部或部分转移给第三人，应经债权人同意；债务人或第三人可催告债权人在合理期限表示，未表示视为不同意。

**编者解释**：债务人一旦就转移部分退出，第三人资信便直接影响债权实现，因此不同于单纯换债权人。全部与部分转移都须同意。债权人与第三人直接达成承担协议，与债务人同第三人私下安排，是不同成立路径。

债权人的行为可以表达同意，但应明确其是否同意原债务人免责。书中以受领第三人给付讨论行为同意，不能脱离第三人履行制度单独使用：收取代付款也可能只是接受清偿，并非放弃对原债务人的请求权。催告后沉默规则必须与有明确含义的行为区别。

### 六、债务加入是增加责任主体（PDF 611–616）

**书载规则**：第三人与债务人约定加入并通知债权人，或者第三人向债权人表示愿加入，债权人未在合理期限明确拒绝的，可请求第三人在愿意承担范围内与债务人承担连带责任。原债务不因此减免。

**编者解释**：第三人是新债务人，债权人可以直接请求其履行；只是代为清偿者并不因此承诺承担债务，债权人通常不能强制其未来代付。加入后的内部追偿先查第三人与原债务人的基础安排，不能一概适用法定债权转让。

债务转移生效后，新债务人可援用原债务人的抗辩；不能擅用原债务人对债权人的独立债权抵销，因为该债权并未随债务转移。若另有合法债权转让，再审普通抵销条件。抗辩与反向债权的归属必须分表记录。

### 七、从债务、保证与概括转让（PDF 617–623）

**书载规则**：新债务人承受相关从债务，专属原债务人自身者除外。权利义务一并转让须经相对方同意，并适用债权转让、债务转移的相关规则。

**编者解释**：利息、赔偿等随主债务的承担与第三人保证继续存在不是同一问题。书中结合保证规则指出，未经保证人书面同意的债务转移，可能使其对转移部分免责，另有约定则另查；债务加入通常不影响原保证责任。勿因“从随主”忽略保证人同意及担保范围。

概括转让应核合法债权债务、可转让性、相对方同意及依法应办手续；把权利转让文件命名为“项目移交”，不能绕过义务转移的同意要求。还须列明既有欠款、违约责任、从权利从债务、抗辩、抵销、结算和争议解决安排。未获同意时要分别判断内部协议与对相对方移转的效力，不机械使用书中概括的“无效”措辞。

## 应用推演：一份可操作的审查顺序

1. 用原约、修订稿、签章记录及往来邮件确定变更对象：条款内容、单项债权、债务、加入，还是整体合同地位。名称不决定性质。
2. 核签字权限、基础合同效力、权利余额、已受偿金额及特殊限制；让与人应交付能证明基础债权的履行凭证，受让人审查反向债权和抗辩。
3. 分开完成通知与同意：通知明确原债权、转移范围、受让主体和履行方式并留到达证据；承担协议明确原债务人是否及何时免责、债权人的同意范围。未取得同意，不据内部转移协议停止履行。
4. 清点担保、公示、专属义务、增费、抵销及第三人利益。对债务加入，留存第三人愿承担的范围，避免无限扩大责任。
5. 形成交割清单：生效条件、通知送达、担保材料、欠款和利息结算、原主体保留责任及争议协作。诉讼前再核原债权人或出让方参加程序的必要性。

## 书中具体例证重构

**房屋转售后的维修请求（PDF 598–599页）**：开发商甲售房给乙并完成交付过户，乙又转售给丙。丙发现漏雨，甲以与丙无合同为由拒修。书中认为，甲原承诺的一年维修义务仍存在，维修请求可随相关债权转移，使丙得主张。应用时要取得甲乙合同、维修期限、乙丙交易与权利移转证据，不可把“房屋过户”概括为所有合同请求一概自动转移。

**著名画家以肖像抵息（PDF 617页）**：乙借款并约定到期还本金、亲自为甲作肖像充抵利息。本金债务转移后，绘画义务因依赖乙个人能力而不随转，甲不能强迫新债务人作画。该论证用来识别人身专属从债务，不能把全部从义务都按货币价值统一转移。

## 误区、关联章与现行核验

误区：对方沉默即同意改合同；禁转金钱债权必然不能受让；让与未通知即内部协议无效；受领代付款即免除原债务人；加入与部分免责转移相同；新债务人可随意使用旧债务人的反向债权抵销。
