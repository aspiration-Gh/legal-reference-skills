# 第三章 合同的效力——生效障碍、权限归属与独立条款

## 来源与阅读覆盖

《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，人民法院出版社；后记2020-07-15，版次未确认。已顺序完整阅读 `ch03.txt`，**PDF第317–367页，书中第502–508条**，正文相互引述可证实条号。

**【书中法条】**表示原书法律引述；**【编者解释】**表示书中观点或论证；**【应用推演】**表示工作步骤。原书主要处于民法典编纂初期，不是现行规范汇编；具体使用须联网核对法律版本、生效时点和司法解释。

## 核心问题

成立、生效、对本人发生效力、无效、可撤销不是同一问题。效力审查既要找障碍，也要找推进或退出路径；主合同存在障碍，不当然连带否定报批或争议解决等独立条款。

## 适用条件与例外

### 一、一般生效及条件、期限（第502、508条；PDF第317–322、366–367页）

【书中法条】一般审查行为能力、意思真实、强制规范及公序良俗；依法成立原则上成立时生效，法律或约定例外除外。合同编未规定的效力事项，由第508条引向总则编第六章。

【编者解释】无行为能力、限制行为能力、虚假表示、重大误解、欺诈胁迫及显失公平分别处理，不能只贴“意思不真实”标签后一律判无效。条件指将来不确定事实，期限对应将来确定会到来的事实；约定生效条件与法定批准条件性质不同。形式要求要查究竟影响成立、效力还是其他法律效果，结合第二章的履行补正规则。

### 二、批准未完成：先确认审批对象，再组织请求（PDF第323–337页）

【书中法条】未办理批准等手续**影响合同生效的**，不影响报批义务及相关条款的效力；有义务者不履行，对方可请求承担违反该义务的责任；依法需批准的变更、转让、解除亦适用。

【编者解释】未经批准存在无效说、有效说、未生效说，书中以法定批准生效合同为前提采用未生效路径：具有不得任意摆脱的形式拘束力，但通常不能据此直接要求主给付及主合同违约责任；可经报批推进生效。须先查法源是否法律、行政法规，再查批准的是合同、项目、资格还是权利变动。书中金融股权、国资、外资、矿业列举是当时制度示例，不能仅见“审批”二字便判未生效，更不能把登记与合同效力一概挂钩。

【编者解释】报批条款独立的理由是防止“合同不生效→无需报批→永不生效”的循环。相关条款可包括报批期限、协助义务及报批专属违约责任，不等于全部主合同违约条款提前生效。书中主张约定外报批义务也可源于诚信、作为能独立请求的附随义务，但在责任定性处存在不同论述，应保留争议。

【应用推演】依据书中分析构造分支，执行前核现行规则：

1. 希望继续交易：请求履行报批或协助义务，写明主管机关、材料、主体、期限；不要把法院判令报批写成法院代行政机关批准。
2. 希望退出：检查书中强调的催告、合理期限及未履行事实，再评估解除及责任。书中认为未生效合同亦可解除，以解除形式拘束避免僵局；解除权期间须另查，不能照抄旧表述。
3. 报批主体与合同义务人不同：核目标公司是否应参加诉讼及其自身义务，避免只判股东报批却无法执行。
4. 已报批并获批准：重新判断主给付可否请求。未获批准：查拒批原因及可归责性；报批人并非保证批准结果，但迟延错过政策窗口可能承担责任。
5. 判令报批且执行仍拒绝：书中支持进一步解除及预期利益损失，并提出类推条件成就规则的理由；此为强争议解释，不是第502条明文赋予的“拟制行政批准”。

### 三、无权代理、追认及越权代表（第503–504条；PDF第338–349页）

【书中法条】无权代理、越权代理或代理终止后行为，未经追认对被代理人不发生效力；本人开始履行合同义务或接受相对人履行，视为追认。书中引第171条：相对人可催告收到通知起三十日内追认，未表示视为拒绝；追认前善意相对人可通知撤销。未追认时，善意相对人可向行为人请求履行债务或赔偿，赔偿受追认后可获利益上限约束；双方知悉无权代理的，按过错分担。

【编者解释】先分有权代理、表见代理和狭义无权代理；不要把无权代理直接写成整个交易绝对无效。调查行为是否能归属于本人，付款、收货等是否针对争议合同，以及催告、追认、撤销的先后。书中对善意通常推定，但明显背离本人意志的交易另论。

【书中法条】法定代表人、负责人超越权限订约，除相对人知道或应当知道越权外，代表行为有效，合同对组织发生效力。

【编者解释】代表权限制分内部意定限制和法定限制：内部限制一般不能对抗善意相对人；涉及公司决议的法定限制，相对人应履行相应审查义务。书中公司担保路径包括关联/非关联担保、决议形式审查、例外、上市公司公开披露、越权后责任及组织向代表人追偿。其采用旧《公司法》和会议纪要，所列“控制公司担保”“相互担保”等免决议例外及“无效”后果，**必须重新核验，不作为现行免责清单**。

### 四、超经营范围与免责条款（第505–506条；PDF第350–360页）

【书中法条】不得仅以超经营范围认定无效，仍按总则效力规则和合同编判断。造成对方人身损害的免责，以及故意或重大过失造成对方财产损失的免责，属于第506条列明的无效情形。

【编者解释】经营范围不是简单的民事行为能力边界；应查具体禁止、限制、特许经营规范及其法律后果，不能因营业执照未列某项目就结束审查。原书用效力性/管理性强制规定区分说明，不应仅复述标签而缺少规范目的分析。

【编者解释】免责按“是否订入→格式条款特殊要求→一般效力→不得免责事项”审查。不得免责适用于协商条款，也不因已经提示或签字而被治愈。重大过失判断结合主观认识和客观巨大危险，考察损害概率、严重性、预防成本以及职业注意标准；一般过失免责仍受格式公平和特别法限制。

### 五、争议解决条款独立但非当然有效（第507条；PDF第361–365页）

【书中法条】合同不生效、无效、被撤销或确定不发生效力，不影响有关解决争议方法条款的效力。

【编者解释】仲裁、法院选择、法律适用以及约定检验鉴定安排可能具有独立功能。主合同未成立时，仍须证明争议条款本身达成合意；独立性不是凭空补出仲裁协议。条款自身还须满足能力、意思真实及程序特别规则。解除终止后的争议也需保留解决通道。书中把部分外国法不予适用概括为条款无效，应另核涉外规则及具体法律效果。

## 实务判断步骤与证据清单

【应用推演】先按第二章确定成立，再分别制作能力/意思、违法性、审批、权限归属、独立条款五栏。对每项障碍写清法源、举证事实、补正可能和责任后果。请求履行、报批、解除、返还、赔偿要与效力状态对应，备选请求避免把“未生效”当作没有任何义务。

证据包括：主体登记及行为能力材料、完整授权链和任职时间、决议及披露原件、本人履行或接受记录、审批依据和受理/补正/拒批文书、报批材料移交及协助记录、催告送达、政策变化时间、独立违约条款、损失与因果关系资料、免责提示及协商记录、风险警示和专业操作标准、争议条款单独合意与有效性材料。

## 书中论证的压缩重构

**预付款条件不当然产生付款请求权（PDF第329、335–336页）**：【编者解释】股权转让约定受让人先付款、转让人后报批，相关约定可独立，但书中认为主合同尚未生效时，转让人不能直接要求作为股权对价的转让款；其可就对方请求报批提出未付款抗辩。催告仍不付款，书中进一步讨论解除以避免双向僵局。操作上要区分独立条款、抗辩和给付请求权，不从“独立有效”直接推出所有主给付都可诉请。本段是论证重构，没有另造裁判。

**专业注意义务影响重大过失（PDF第359–360页）**：【编者解释】医生对病患的注意要求高于一般人，是否应知风险须结合职业伦理。由此重构为：先固定风险、专业角色、可用预防措施及成本，再判断严重疏忽；不能只因签署免责声明或损失很大就决定免责有效或重大过失成立。

## 争点与OCR未决项

第317、338、343、350、356、361页法条框或标题有缺文；第322页修法理由语句残缺，不补写。第327页关于无效“全部无效”的概括应与第367页部分无效规则区分。第330–331页把第502条称缔约过失规定，疑沿袭或编校错误；第331页合同附随义务说与第333页无专门责任约定时仅缔约过失的说法有张力。第332页解除期限说明不完整，不能用于计算期间。第328、337页对法定批准拟制成就分别作原则否定和特殊讨论，不能消除限定。第337页“审判机构未予批准”“嗣后履行不同”疑 OCR/编校问题，以前文语境定位，不复原全文。

## 需核验的现行法与关联章节

按案件时点查《民法典》总则及第502–508条、合同编通则司法解释、担保制度司法解释、公司法及上市担保规则、外商投资和矿业等审批特别法、仲裁法与民事诉讼规则。尤其核批准备案制度是否变化、无权行为的准确效力表述、解除及撤销期间、报批违约损失范围。
