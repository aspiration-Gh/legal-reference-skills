# 第二十四章 物业服务合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15；全文阅读PDF2643—2747，源ch24.txt。法条层为书载规范概括，编者解释为2020年书中立场，应用推演为实务组织方法。实际使用核验现行法及争议发生时规则，尤其地方物业条例、收费政策和共同决定程序。

## 核心问题与规则

### 1. 明确合同主体、约束范围和服务标准（PDF2643—2662）

**法条层：**物业服务人包括物业服务企业及其他管理人。物业服务合同应书面订立，内容包括服务事项、质量、收费、维修资金、用房、期限及交接；公开作出的有利于业主的服务承诺属于合同内容。依法成立的前期物业合同、依法选聘后订立的物业合同，对业主具有约束力。

**编者解释：**物业服务兼具管理及多种劳务特征，是独立典型合同，不能整套移植委托规则。业委会代表签约，不因此成为全部物业费的个人化支付义务人；在业主自行管理情形，依法成立并实际承担管理职责的业委会，可按书中分析起诉欠费业主。未签书面合同但主要义务已经履行并被接受，可依实际履行判断成立。公开承诺应明确、真实、公开、对业主有利且合法；服务细则须结合双方认可及公示审查，不允许以单方细则任意加重义务。

**应用推演：**先收集前期合同或业主共同决定、业委会授权、物业合同、投标承诺和公示细则，再形成“项目—质量—频次—负责人—费用”的对照表。物业费包干制由企业承担盈亏，酬金制提取报酬后结余或不足由业主承担，账务主张须分制审查。

### 2. 前期物业终止与普通解聘分流（PDF2663—2669、2711—2717）

**法条层：**前期合同期限未满，业委会或业主与新物业订立的合同生效，前期合同终止。业主依照法定程序共同决定解聘，可以解除物业合同；决定解聘应提前六十日书面通知，合同另定通知期限的除外；除不可归责于业主的事由外，造成物业损失应赔偿。

**编者解释：**仅作出选聘决定，不等于新合同已生效。前期物业的上述法定终止不同于普通任意解聘，书中不要求业主就此赔偿原物业的解聘损失。业主决定自行管理也可使前期合同终止。出售物业后，建设单位不能当然独自更换前期物业；其权限须结合共同管理权及授权审查。普通物业解聘不必一律证明根本违约，但须完成共同决定和通知程序；单个业主不能单独解除覆盖全体业主的服务合同。赔偿诉讼如何列业委会、全体业主及分担执行，书中承认仍有难点。

### 3. 专项外包不减责任，禁止全部转委托（PDF2670—2676）

**法条层：**部分专项服务可以委托专业组织或第三人，但物业仍向业主负责；不得把全部服务一并或拆分后全部转委托。

**编者解释：**判断“全部转委托”应看原物业是否实质、有效管理，是否驻有管理团队、自行承担一定服务并直接回应业主，不能只数外包项目。物业不得以业主同意外包为由，仅承担选任和指示责任。业主基于物业合同通常向物业主张，不能当然借委托介入权向外包人主张合同权利。此分析不排除第三人另因侵权等独立根据承担责任，后者须另查。

### 4. 基本服务、安全保护和管理边界（PDF2677—2685）

**法条层：**按约及物业使用性质妥善维修、养护、清洁、绿化、经营管理共有部分，维护基本秩序，采取合理措施保护人身财产安全；对治安、环保等违法行为负合理制止、报告和协助义务。

**编者解释：**基础义务不能通过免责格式条款排除；住宅、商业、工业及公益物业的使用性质影响义务内容。物业没有行政处罚权，不得擅自罚款、暴力管理；也不能以无执法权为由完全不劝阻、不报告。安全义务是合理措施义务，不是对一切盗窃和事故兜底。房屋质量、重大更新支出、侵权人直接损害与物业日常维修、巡查失职应分开。

### 5. 信息公开与费用催收分别处理（PDF2686—2701）

**法条层：**物业须定期合理公开服务事项、人员、质量、收费及履行、维修资金使用和共有经营收益，并向业主大会、业委会报告。已按约提供服务，业主不得仅以未接受或无需接受服务拒费。逾期欠费可催告合理期限支付，届满仍不支付可诉讼或仲裁；不得以停电、停水、停热、停气催费。

**编者解释：**公开对象是业主，报告对象是业主组织，二者不是择一履行。单个业主可主张公开，直接要求向其作团体报告则须另查主体适格。拒费理由要区分空置、不需服务与真实服务瑕疵：前类通常不成立，后类须按实际未履行事项和证据评价减费、补救或赔偿，不能一概全免。书中将催告及合理期限作为起诉前置要求，现行处理须核验，不能擅自转换成已确认的受理规则。物业因个别业主欠费停止全小区基本服务，损害其他业主，不能由合同抗辩理论正当化。

### 6. 装修、使用人变更与共有用途（PDF2702—2710）

**法条层：**装修前告知物业、遵守合理注意事项、配合必要检查；转让、出租、设立居住权或依法改变共有用途，应及时告知。

**编者解释：**装修监督属于基本义务，不应重复收取一般装修管理费；另外约定设计、咨询等个性服务另论。保证金的合理性与合法性要分开：书中倾向尊重约定，但明确地方可能禁止，不能据此得出全国可收费。共有部分用途改变由业主共同决定，通知不替代共同决定或行政许可。物业发现装修违法却不合理制止，可能就扩大的损失负责；已经适当履职，不承担装修企业全部责任。

### 7. 续聘、不定期延续与通知期限（PDF2718—2730）

**法条层：**期限届满前依法共同决定续聘，应续订合同；物业不同意续聘，应依书载法条“合同期限届满前九十日”书面通知，另有通知期限约定从约定。到期未依法决定续聘或另聘，物业继续服务，原合同继续有效、期限变为不定期；解除不定期合同应提前六十日书面通知。

**编者解释及争点：**编者将不定期关系视为原合同延续，非另起新合同；通知为解除表示，期限届满产生效果，不必再发第二次通知。普通固定期解聘损失与不定期依法通知退出不同，编者支持后者通常不赔偿解除本身损失，不能由此免除违约或交接责任。

**高优先核验：**PDF2721—2723把“届满前九十日”解释成最后九十日内任何一天通知，甚至期满前一日可通知；这是源书明确存在的解释风险，不是本技能认可的现行操作期限。拟定退出日时必须核官方法条、地方规定及裁判，实务排期不得直接依该解释缩短准备期。

### 8. 终止、交接与继续服务（PDF2731—2747）

**法条层：**终止后按约定或合理期限退出，交还用房、设施和必要资料，配合交接并如实说明管理状况；违反交接义务不得请求终止后物业费，致损赔偿。新物业或自行管理业主接管前，原物业应继续处理服务事项，并可请求相应期间费用。

**编者解释：**欠费争议不能阻却交接；争的是终止是否成立，则先审共同决定及解除效力。新物业不能自行强占接管，应由业主或业委会组织。原物业有两项并存义务：继续必要服务、积极配合退出。既不得突然弃管，也不得制造无法接管再收费。书中前段以法定后合同义务解释，后段转而援引无因管理，并将交接费倾向限于必要支出，存在理论张力；应优先核验物业特别规定，不以无因管理规避拒交接不得收费规则。

## 判断步骤与证据（应用推演）

1. 确定争议区域、专有或共有性质、合同阶段和付款主体；核房屋交付、实际使用及所有权变化，别把建设单位的承诺自动算给物业。
2. 核共同决定：面积和人数两套基数、参与及赞成票分别统计；保存业主名册、授权票、会议通知、签名和公示。书载选聘解聘采用双三分之二参与、参与者双过半同意；改变共有用途另有更高通过比例，使用时核验，不套用旧物权法基数。
3. 核履行：合同及公开承诺、巡检维保记录、报修单、投诉回复、现场照片视频、报警及行政报告，定位服务缺口的期间、频次及影响，提出相应而非任意比例减费主张。
4. 核费用：区分物业费、维修资金、公共经营收益、专项收费和装修费用；审收费依据、公示、催告到达、合理期限及服务期间，另行列明损害赔偿。
5. 核交接：形成设施钥匙、技术图纸、设备档案、财务余额、未完合同、业主信息及风险告知清单，记录实际接管节点；资料传递同时核个人信息保护要求。

## 书中具体论证重构

**电梯更新与欠费（PDF2648—2649）：**物业须巡查并联系专业维修；若电梯需整体更新而业主不愿使用维修资金，造成不便不当然是物业违约。判断顺序是查故障发现和报告履职，再查属于日常维护还是重大更新，以及谁控制资金决策，不宜仅凭“电梯坏了”全额拒费。

**开发商赠物业费（PDF2661）：**建设单位卖房承诺赠送物业费，物业认可或授权时才可能对其有约束；未认可时，业主缴费后向建设单位依承诺求偿。该例展示买卖和物业合同的请求权应分别组织。

**交接先予执行（PDF2738—2739）：**编者区分终止效力本身尚有实质争议，与终止无异议但拒不退出导致生活秩序失常；后者才进一步审查紧急先予执行条件，不因“物业纠纷紧急”自动跳过权利基础判断。
