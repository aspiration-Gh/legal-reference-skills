# 第二章 合同的订立——从磋商证据确定合意、成立与先合同责任

## 核心问题与适用条件

### 一、先找成立所需的合意和形式（第469–473条；PDF第82–98页）

【书中法条】合同可用书面、口头及其他形式；可有形表现并随时调取的数据电文视为书面。第470条列举一般条款，不意味着每个合同缺任一条款均不成立。

【编者解释】按合同性质识别必备内容，书中以当事人、标的、数量说明买卖的最低确定性。价款等可补足事项依补充协议、相关条款、交易习惯及法定规则处理。要约必须内容具体确定，并体现一经承诺即受拘束；“具体确定”也可通过未来价格机制确定，不要求全部数值已出现。广告、价目表通常为邀请，满足要约条件时另论。询问能否降价不必然是拒绝或反要约；明确提出不同成交价格则另作判断。

【编者解释】招标为邀请、投标为要约、中标通知为承诺，书中倾向中标通知发出时成立；竞争缔约仍须核特别法。交叉要约、同时表示以及意思实现，说明不能机械要求文件依次写着“要约”“承诺”。

### 二、用时间轴处理撤回、撤销和承诺（第474–489条；PDF第99–221页）

【书中法条】对话表示在相对人知道内容时生效；非对话表示一般到达生效。数据电文先看生效时间约定，再看是否指定系统；指定的进入该系统时生效，未指定的以知道或应当知道进入系统为标准。撤回通知须先于或同时到达；要约撤销须在受要约人**作出承诺之前**被知道或到达，不等到承诺生效。确定承诺期限或明示不可撤销，以及有理由信赖不可撤销并已作合理履约准备，是撤销例外。

【编者解释】主观声称信赖不够，应有正常交易者能理解的理由及实际准备。违反不可撤销限制不发生要约失效效果。拒绝、依法撤销、期限经过及实质变更均可能使原要约失效；对已经失效的原要约再次表示同意，通常需要重新走合意过程。

【书中法条】承诺原则上通知；交易习惯或要约允许时可用行为。沉默须有法律、约定或双方交易习惯依据，不能由要约人单方写“不答复即同意”创设。承诺原则上须在期限内到达；未定期限，对话即时，非对话合理期限。信件、电报的期限起算依书中第482条所列发信日期等，快速通讯以到达起算；有明确约定另行审查。承诺可撤回，生效后不能再以“撤销承诺”单方消灭合同。

| 异常情形 | 【书中法条】判断方向 | 核心证据 |
|---|---|---|
| 超期发出，或虽期限内发出但通常不能及时到达 | 第486条：原则为新要约，原要约人及时确认有效除外 | 发出、期限、通常在途时间、确认通知 |
| 按时发出且通常能到达，因其他原因迟到 | 第487条：原则有效，原要约人及时通知因超期不接受除外 | 通讯故障、邮程、迟到及拒绝通知 |
| 改变标的、数量、价款、责任、争议解决等实质内容 | 第488条：新要约，原合意链须重新审查 | 各版差异、后续接受或履行 |
| 非实质变更 | 第489条：原则有效，及时反对或禁止任何变更除外；内容以承诺为准 | 变更影响、反对时间、禁止变更约定 |

【编者解释】合理期限结合传递、审核复杂性、承诺回传衡量；文件信头列邮箱不当然等于指定系统（PDF第146–147、170–175页）。对于“格式之战”，书中比较最后用语、第一枪、相互击倒，并以最后用语解释该法域规则；不能据此忽略格式条款规制、真正合意和特别程序条款要件。第220页以利益影响和诚信论证轻微变更，属于解释立场，不是随意改写法定实质条款的授权。

### 三、签章、履行、电子订单与成立地点（第490–493条；PDF第222–252页）

【书中法条】合同书由当事人均签名、盖章或按指印时成立；此前一方履行主要义务且对方接受，可成立。未采用要求的书面形式也有履行补正路径。

【编者解释】要分别查：标的是否确定；履行是否为主要义务；是否由相对人接受。不是必须双方都履行，也不是任何付款或持钥匙居住都够。多方中有人未签，分析其缺席是否影响整体权利义务，及是否约定全体签署为条件；借款和保证还可能是同一文件中的不同合同。签章方式一般择一，但“签名且盖章”约定应另查。

【编者解释】真章不必然证明真实协议，假章也不当然排除有权代表或代理人的行为；审查签约者权限、形成过程及履行。骑缝章主要防替换，缺骑缝章不当然不成立。私章、指印被否认时，主张成立者须准备真实性证据。

【书中法条】要求签确认书的，签订时成立；符合要约条件的网络商品、服务信息，对方成功提交订单时成立，有效另约除外。【编者解释】确认书应在成立前要求；成立后补提不能推翻已有合同。电商经营者用格式条款约定消费者付款后仍不成立，受书中所引《电子商务法》第49条限制，提示说明也不能使违法条款有效。自动信息系统是使用者的工具；平台自营身份与非自营平台法定责任应分开。

【书中法条】成立地点一般随承诺生效；数据电文看收件人主营业地、无主营业地看住所地，有约定从约定；合同书原则看最后签署地点。【编者解释】履行补正时看接受履行地，确认书看签订地。成立地不是当然的受诉法院，还须查协议、级别及专属管辖；不得故意制造涉外连接点规避强制规范。

### 四、强制缔约与预约（第494–495条；PDF第253–269页）

【书中法条】国家订货、指令性任务依法律行政法规订约；负有要约义务者及时提出合理要约，负有承诺义务者不得拒绝合理要求。预约约定未来一定期限订立合同，不履行可承担预约违约责任。

【编者解释】强制缔约仍需合意过程，不是任务一到合同即成立；无正当理由拒绝、过错、损失与因果关系是书中缔约过失分析要点。国家订货不一概属于行政协议，此处与第一章分类存在差异。

【编者解释】预约是独立合同，应区分磋商文件、预约、本约：先看是否愿受约束、是否意在将来另订合同，再看标的、条款完备度、订约期限、定金及履行。内容完整不当然抹去明确的预约意思。对强制缔约，书中倾向区分简单、典型、完整预约，前两者可继续磋商，完整预约在可履行且意思基础充分时审慎支持缔约；**这是争议观点**。赔偿也不等同于本约全部利润：成本、信赖程度、机会损失、实际履行、违约获利及过错分别查，适用减损和损益相抵。

### 五、格式条款的三层审查（第496–498条；PDF第270–291页）

【书中法条】为重复使用预拟且订约未协商的条款，受格式条款规制；提供者公平安排权利义务，并合理提示重大利害条款，依要求说明。未履行导致对方未注意或未理解，可主张未订入。无效情形包括一般无效、不得免责、不合理免责或加责、限制主要权利，以及排除主要权利。

【编者解释】按以下顺序处理：

1. **识别与订入**：商店公告、制式单据也可能构成。提示在成立前主动完成；普通合同说明一般以要求为前提，保险有主动明确说明特别规则。大片黑体、隐蔽张贴不必然足以引起注意。对方已注意且理解的，不因缺少形式提示当然排除。
2. **效力**：即使已经订入并解释清楚，仍可能因不合理利益失衡或排除主要权利无效；“限制”与“排除”程度不同。部分条款无效不直接等于整个合同无效。
3. **解释**：先查同一事项的有效非格式条款，再作可能订约者平均合理的通常理解；仍有两种以上合理解释才作不利于提供者解释。不得人为制造歧义或跳过通常理解。

### 六、悬赏与缔约阶段保护（第499–501条；PDF第292–316页）

【书中法条】公开承诺对完成特定行为者支付报酬，完成者可请求支付；拾得物返还义务与悬赏报酬可并存，但侵占遗失物者受书中第317条的例外限制。恶意磋商、隐瞒重要事实及其他违背诚信行为造成损失，可生缔约过失责任。缔约知悉的商业秘密或其他应保密信息，不论合同成立与否，不得泄露或不当使用。

【编者解释】悬赏性质有契约说与单方行为说争论；书中认为不知道广告而完成行为也可请求，数人完成、优等悬赏、撤销方法及“重谢”数额须结合公告和具体情形，不冒充条文明确规定。费用、受益及劳动成果价值是数额判断因素。

【编者解释】缔约过失按义务违反、损失、因果关系、过错四要件分析；正常交易条件未谈拢不当然有过错。合同后来成立或生效，也不消灭先前违反义务已经造成的损失。赔偿以信赖损失为核心，机会损失、固有利益及履行利益上限存在书中分歧，不直接套用合同违约金额。信息是否保密，应看非公开性、价值、措施及取得环境；向谈判方披露不等于公开，客户名单不能仅有一般公开名称。有效保密协议、合法独立来源、使用权限及持续保密义务分别查；救济可包含停止侵害，不限于金钱赔偿。

## 实务判断步骤与证据清单

【应用推演】按“主体权限→各次表示及版本→发出/到达/知悉→撤回撤销→内容一致→特殊形式或履行→成立时间地点→条款订入及效力→责任性质”制作争点表。预约先单独定性；合同不成立仍检查返还、折价和信赖损失，避免增值贬值重复计算。

证据包括：完整邮件头、系统指定约定和日志、订单及支付状态、公告历史版本、故障证明、历次报价及修改、签署原件和授权、印章保管及形成过程、交付验收和收款凭证、格式提示界面及说明记录、预约磋商履行、损失凭证及替代交易、信息交付与访问日志、保密措施和使用范围。仅截图或最后一版文本可能漏掉决定成立的环节。

## 书中事例的压缩重构

- **未盖章预售合同何时成立（PDF第160–162页）**：陈某燕在开发商备妥文本上签字交回，开发商未盖章，却收首期款并开发票。原书认可成立结论，但批评仅以签字回交即成立的理由，认为关键是接受主要义务履行。操作要点：成立结论相同，时间和依据仍须准确。
- **真章不等于真协议（PDF第232–233页）**：所谓补充协议根本翻转原投资风险，内容矛盾，且此前相关诉讼从未提出。书载再审不单凭印章真实采信文本，综合形成过程及异常事实否定真实性。核签章必须与合意证据联动。
- **条款有效仍可能不构成违约（PDF第284–285页）**：禁止跳单条款可合理保护中介利益，但房源由多家公开挂牌，买方经另一中介成交。原告未证明买方利用其信息绕开，不能只凭曾带看索违约金。
- **开发投入不证明量产已承诺（PDF第308–309页）**：样品认定协议与正式供货不同，样品价格、质量通过不等于量产数量价格已合意。因市场明显变化重新议价，书载裁判不认定恶意磋商。该案号 OCR 有缺字，不复原。

## 争点、OCR未决项与需核验的现行法

PDF第90页保管合同成立/生效说法需核；第165–166页“开始草拟即成立”与第174页“行为完成为准”有张力，须解释要约指定行为。第102页与第173页数据电文知悉的举证方向不完全一致；第183页异常迟到撤回通知的特殊处理须核。第210页商事标准文本是否受格式规制不可仅凭双方均为企业排除。第269页写无法确定房屋位置时“不能认定为预约合同”，疑“本约/预约”误植，未确认。第306–307页固有利益范围的观点与公交致死事例存在张力；第298–299页李姓当事人姓名多种识别，不强定姓名。

使用时重点核验：民法典订立及意思表示条文、合同编通则司法解释、电子商务与电子签名规则、招投标特别法、预约责任、格式条款和消费者/保险特别规则、商业秘密规则及证据规范。旧担保法默认责任、旧程序法条号、旧解释与域外比较均不得直接作为现行依据。
