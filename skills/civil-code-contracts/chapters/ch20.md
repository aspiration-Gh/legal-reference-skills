# 第二十章 技术合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记日期2020-07-15。已全文顺序阅读ch20.txt，覆盖PDF第2320—2435页，页码均为文件页码。下文区分书载法条规则、编者解释和应用推演；本批不实施全量法律更新，具体使用时必须核验事件发生时的现行法、司法解释和知识产权特别规则。

## 核心问题及适用范围

技术交易首先要回答：交易的是尚待研发的新方案、现有技术权利、决策建议，还是解决特定技术问题的服务？名称不能取代内容审查。知识产权合同不全是技术合同，商标、一般作品合同不能直接套用；技术服务也可以使用公知技术。混合合同应识别争议对应的特征给付，技术转让或许可附带的设备、材料、指导服务原则上仍为该合同组成部分（PDF第2320—2327、2371—2375、2399—2406页）。

## 八项核心规则

### 1. 定性、效力与合同清单

**书载规则：**技术合同涵盖开发、转让、许可、咨询和服务。开发合同、转让及许可合同采用书面形式；合同内容通常包括标的范围、技术指标、进度、保密、成果归属、收益分配和验收等。所列内容是指导性清单，并非缺一项即无效（PDF第2325—2330、2344—2346、2373—2375页）。

**编者解释：**签约效力与后续生产、实施需要行政许可的合法性要区分；课题组不具独立主体资格时，先查设立人、签约名义与责任归属，不宜简单认定合同无效。价款不明可按技术含量、质量数量、研发成本、应用程度及经济效益等合理确定，技术性和非技术性费用应分列。提成计费须约定计提基数、比例、周期及查账办法（PDF第2321—2330页）。

### 2. 职务成果、个人贡献与人身权

**书载规则及编者解释：**成果权属先查有效约定，再查是否执行单位任务或主要利用单位物质技术条件；两个标准不要求同时具备。职务成果的使用、转让权益与实际完成人的署名、荣誉等人身权益分别处理。仅出资、管理、翻译、整理图纸不当然构成创造性贡献（PDF第2331—2339页）。

判断时先辨雇佣关系与委托开发，兼职、临时工作也可能有职务关系；再比对岗位、任务书、技术方案及资源投入。离职后成果是否为原工作延续，要看具体课题关联，不以技术领域相同替代。书中强调物质条件须对形成成果有实质影响；按事先约定返还资金或支付使用费等情形须另查。不得用“业余时间完成”直接推出个人所有。

### 3. 技术垄断、侵权技术与善意取得后的使用

**书载规则：**非法垄断技术或侵害他人技术成果的技术合同无效；部分无效不必导致其他部分无效（PDF第2340—2343页）。

**编者解释：**限制研发、限制技术来源、不对等改进回授、搭售、限购及不争义务等，应结合条款效果审查，不能把所有许可范围限制都认作垄断。共有权人擅自作独占、排他许可可能侵害其他共有人。侵害技术秘密的合同无效后，书引司法解释允许符合严格善意条件的取得者在原取得范围继续使用，但须付合理使用费并保密，不是取得绝对使用权。善意要结合合理价款、取得渠道和认知能力判断，拒绝付费可能引发停止使用请求。须分开权利人对外救济与交易双方内部结算，避免重复付费；适用前须核验相关解释是否修订。

### 4. 委托开发和合作开发：出资不等于共同研发

**书载规则及编者解释：**仅提供资金、设备、材料或辅助协作，而由另一方独立研发，属于委托开发；各方按分工直接参加研发才具合作开发特点。委托人应付经费报酬、提出需求、提供资料、协作并接收成果；研发人应制定实施计划、合理使用经费、交付成果及必要资料指导。合作各方应投资、按分工研发并协作。违反义务造成停滞、延误或失败，须审查违约与损失之间的因果关系（PDF第2344—2357页）。

书中对研发经费采用实报实销与包干作区分：前者多退少补，后者依约承担结余或不足；约定不明时编者按包干解释。不要因委托人提供技术背景资料，或研发方自担一部分经费，就自行改判为合作开发。对可纠正的偏差优先审查补救和继续履行的现实意义，不能见失败即全额退款，也不能以“研发有风险”掩盖挪用经费、不开展工作。

### 5. 研发风险、标的公开与成果分配

**书载规则：**无法克服的技术困难导致全部或部分失败，先按风险约定，补充解释仍不能确定的合理分担；发现风险应及时通知并减损，违反者对扩大部分负责。他人已公开标的技术且致合同履行失去意义，可解除（PDF第2358—2361页）。

**编者解释：**技术风险应有现有技术水平下的客观难度、研发人已尽努力、专家评价属于合理失败等支持。技术已公开与履行失去意义是两个条件，不能只证明出现相似论文。

**书载规则及解释：**委托开发的专利申请权，无特别法律规定或约定时原则上归研发人，委托人有依法实施及同等条件优先受让申请权等权益；合作开发原则共有。放弃申请权与反对申请专利不同：前者允许其他方申请并保留相应免费实施利益，后者阻却他方申请。技术秘密成果先依约分配；约定不明时，书引解释将各方权能限定为自己使用、普通许可及相应收益，避免整体处分或独占许可侵犯其他方利益（PDF第2362—2370页）。自行实施条件不足而许可一个主体实施的特定解释，不能扩张为所有被许可人自由转许可。

### 6. 转让与许可：权属登记、许可类型和技术保证

**书载规则及编者解释：**现有专利权、申请权和技术秘密转让，与仅授权实施使用须区分。专利转让登记影响权利变动，不能与签约效力混为一谈；在先许可亦不能因后续转让当然消失。普通许可允许许可人自己使用并再许可，排他许可保留许可人自用，独占许可排除许可人自用；约定不明时书中按普通许可解释（PDF第2371—2382页）。

许可期限受专利存续限制；专利无效与届满、未缴年费终止的既付费用及赔偿后果并不相同。技术提供者负合法拥有、完整无误、有效并达到约定目标等保证，技术秘密还要具有实用性、可靠性；这些不等于保证商业盈利。阶段性成果须说明后续试验责任，明知需小试、中试却直接批量生产的损失应另查（PDF第2378—2387页）。

未付使用费、超范围实施、擅自再许可、泄密，分别对应补付、停止行为、交还资料及违约责任。依约使用却侵犯第三人权益，应区分提供者保证责任、使用者是否明知及对外共同侵权，内部约定不能消灭第三人权利（PDF第2390—2395页）。

### 7. 保密、后续改进及新成果

**书载规则：**受让人、被许可人须依约对未公开秘密部分保密；后续改进分享先依约，补充解释仍不明时他方无权分享。计算机软件、植物新品种、集成电路布图等技术成果转让许可参照相应规则，技术进出口、专利转让另有特别规范的优先处理（PDF第2388—2389、2396—2398页）。

**编者解释：**保密应覆盖谈判、履行及约定的终止后阶段；技术秘密许可人申请专利与保密的协调，应查特别约定，不能与已转让整体权利混同。咨询服务中新成果先依约，无约定时原则归完成人，但先排除职务关系，再查与履约实质关联及创造性贡献；他方实质参与可能构成共同研发，仅提建议不够（PDF第2429—2432页）。

### 8. 咨询、服务、培训与技术中介：结果风险不同

**书载规则及编者解释：**咨询提供技术分析、预测和决策参考；服务需实际解决特定技术问题并传授必要知识。符合约定的咨询报告引发决策损失，原则由委托人承担，另有风险约定除外；报告明显错误、不合约的违约不能借此免责。服务质量则结合约定技术效果判断，笼统的效益预测不当然成为质量担保（PDF第2399—2406、2407—2428页）。

委托人应提供资料、工作条件并接收成果；受托人发现明显缺陷须及时通知补正，不能长期沉默后以资料不足抗辩。报告内部写完不等于已交付。咨询及服务的调查、试验、差旅等费用无特别约定时由受托人承担。技术培训看学员条件、教员配置、课程目标与及时更换通知；技术中介须分开费用和成功报酬，未促成合同原则无报酬，必要费用及无效主合同对中介报酬的影响依条件审查（PDF第2433—2435页）。

## 书中具体论证重构

**技术秘密共有争议，PDF第2368—2370页：**甲乙共同形成同一秘密且权属约定不明。第一说限定自用和普通许可；第二说只禁止整体转让；第三说认为秘密可由多人掌握，故可多次转让。书中支持第一说：同一权源的秘密只有一项整体处分权，甲若独占或排他许可第三人，会妨碍乙平等使用；秘密能被独立研发取得，不等于共同权利可各自整体处分。由此保留双方自用、普通许可及各自收益，并将特定“一个普通许可视为自用”与一般再许可严格区分。这里是论证重构，没有虚构案号。

**转换适用的检验，PDF第2405—2406页：**名为技术转让的技术已进入公有领域，若提供方无相关过错，并确实指导、传授且解决约定技术问题，书中主张按技术服务处理，原费用可转为服务报酬；明显不合理的可依申请调整。不得只凭标题错误否定全部劳动价值，也不得忽略欺诈及服务不达标。

## 应用推演：判断步骤与证据

1. 用交付内容和风险承诺定性，拆分基础技术、目标成果、附带设备和服务，核查权利链、专利登记及行政许可。
2. 将技术指标、测试环境、验收方法、项目里程碑、费用口径、成果归属、许可范围、保密措施逐项对应书面约定。
3. 用任务书、研发日志、实验失败记录、源代码或图纸版本、技术鉴定、经费流水、通知回执还原履约，区分客观风险、协作障碍与违约。
4. 对权属争议分解实质技术构成，核对参与人的创造性贡献；对损失逐项核对因果关系、减损、使用收益和已付费用。
5. 先查解除条件及催告，再确定继续履行、补救、减免报酬、停止使用与赔偿。书载催告后30日规则及更长自行宽限期，须核验适用司法解释版本。
