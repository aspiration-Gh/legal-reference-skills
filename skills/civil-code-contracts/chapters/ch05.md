# 第五章　合同的保全

## 来源与适用范围

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记日期2020-07-15；源文PDF第527–584页已逐页全文阅读。以下为书籍提炼，未作现行法全量更新。使用时核验事实发生时的法律、司法解释及过渡规则。PDF页码与书内页码不同。

核心问题：债务人不向他人收债，或把财产、担保利益处分出去，债权人怎样保住受偿基础？本章按代位请求、到期前保存、撤销诈害行为三条路径覆盖，另处理程序、费用、清偿效果和执行破产冲突。“书载规则”与“编者解释”分别表达，办案建议标作“应用推演”。

## 七组核心规则

### 一、到期债权的代位请求：先查两层债权（PDF 527–538）

**书载规则**：债务人怠于行使其债权或相关从权利，影响债权人到期债权实现，债权人可依法以自己名义诉讼代位；专属于债务人自身的权利除外。行使范围受本人到期债权限制，必要费用由债务人负担，相对人可援用对债务人的抗辩。

**编者解释**：依次核实“债权人—债务人”“债务人—相对人”两层权利是否合法、到期、可确定。已有生效文书的先形式审查，但仍应核实后续清偿余额；没有文书不等于不能代位，须在诉讼中认定。债权发生原因不以合同为限。从权利可涉及担保、利息、工程价款优先利益，但须核各自条件及是否已由裁判确认，防止重复诉讼。

“怠于”不能仅用到期未收款替代，应结合主张权利的方式、时间及实际履行；书引旧司法解释强调是否诉讼或仲裁。影响实现应有两层联系：怠于行使导致债务人清偿能力受影响，清偿能力又影响原告受偿。编者主张对外部债权人的举证能力适当照顾，但不能将该主张写成一律倒置举证责任。债务人放弃自己的时效抗辩时，相对人能否代为主张，须与相对人自身抗辩区分。

### 二、到期前保存：目标是保存债务人利益（PDF 539–545）

**书载规则**：债权人自己的债权未到期，而债务人的权利面临诉讼时效届满、未及时申报破产债权等危险并影响将来受偿时，可代位请求相对人向债务人履行、向破产管理人申报或作其他必要行为。该路径不能用来提前让自己受偿。

**编者解释**：要求两重危险——不行动可能使债务人失权，以及失权可能影响未到期债权实现。债权已有足额担保，或债务人正积极维护权利，通常欠缺介入必要。保存方式不限起诉，应匹配催收、申报等具体危险；必要费用及善良管理人的注意义务亦应考虑。

**特别保留**：PDF 541–544页将保存对象扩至物权、形成权等，并认为债权人应以债务人名义作为法定代理人行使、按基础关系确定管辖。这些是编者从管理性、利益归属作出的解释，并非法条明文的完整程序，实际起诉或申报前必须核验。书中亦承认部分制度效果有待司法解释明确。

### 三、代位胜诉不等于原债消灭或取得物权优先（PDF 546–552）

**书载规则**：代位成立后相对人向债权人履行；债权人接受履行后，两层债权债务才在相应范围终止。债务人的相关权利已经被保全、执行或债务人破产的，依法处理。

**编者解释**：判决生效与实际受偿分开。未受偿部分仍可向债务人请求，受偿后必须扣减，避免双份清偿。代位直接给付带来的程序性先受偿效果，不是抵押权式的实体优先权，不能排除参与分配和破产规则。

书中支持代位起诉本身限制债务人处分及相对人给付，并讨论既判力是否及于其他债权人；这涉及诉讼保全、执行及当事人参加程序，不能由“已经起诉”推定登记冻结，更不能保证优先执行。债务人另行还款、相关权利被他案执行或进入破产时，均应重新核对代位判决的执行范围。

### 四、无偿处分与恶意展期的撤销（PDF 553–564）

**书载规则**：放弃债权、放弃担保、无偿转让财产等，或者恶意延长到期债权履行期限，影响债权实现的，债权人可请求法院撤销。债权本身须合法存在，但不要求已经到期。

**编者解释**：无偿处分通常不要求债权人另证受益人的恶意；恶意展期须考察展期动机及支付能力，不能将正常商业宽限都撤销。放弃未到期债权同样可能减少责任财产。放弃担保则应进一步看次债务人能否清偿、其他担保是否足够，以及债务人剩余财产是否仍能偿还原告，不能只看到担保注销便认定诈害。

诈害性的判断既看处分发生时，又看行权时是否仍影响清偿；不能用事后贬值当然追溯否定原本有足够资力的处分。事实性毁损、不取得新利益、身份行为等不能机械作为撤销对象；怠于行使现存权利应先分流至代位。另与恶意串通无效区分：后者要证明串通，举证门槛不同，不能只因撤销期间不足便改贴无效标签。

### 五、不合理价格与为他人担保（PDF 565–570）

**书载规则**：明显不合理低价转出、高价购入财产，或者为他人债务提供担保，影响债权实现，并且相对人知道或应当知道该情形的，可请求撤销。

**编者解释**：比较基准是交易当时、交易当地同条件价格，须考虑财产性质、区位、流动性、市场供求及变现目的。书引旧解释的低于市场价七成、高于市场价三成等只能按其时代背景理解，不能作为无需其他要件的自动线。季节货、临期果蔬的合理甩卖与关联交易低价输送并非同类。相对人恶意的判断落在是否知道或应知影响债权实现，不必等同双方明确商议逃债。

为他人担保须检查被担保债务、担保范围、对价与相对人认知；不能从“免费担保”直接跳到可撤销。债务人为自身新债提供担保，涉及新资金和责任财产的变化；为既存无担保债权补担保，还须区分普通撤销与破产撤销，不能共用要件和期间。

### 六、范围、费用与期间同时审查（PDF 571–578）

**书载规则**：撤销范围以债权人的债权为限，必要费用由债务人承担；知悉或应知撤销事由起一年内行使，自债务人行为发生起五年未行使则消灭。

**编者解释**：以实际起诉债权人的受影响债权范围衡量，不当然按全体债权总额撤销全部交易；已有足额担保部分应纳入必要性审查。标的可分时，只撤足以保全的部分；不可分时不能强求数额完全一致。书中关于将不合理价格的“差额”作为减损额的解释，不能直接变成法院替当事人重订价格。

必要费用另于诉讼费核定，保留律师、调查、评估、差旅、保全等支出的必要性、合理性凭证。代位费用与撤销费用的旧解释处理并非完全一致，不能不加区分照搬。

期间均被编者解释为除斥期间，催告、协商不当然中断。PDF 577页倾向将部分行为的起点定位为实际财产权转移或承担责任，PDF 578页又强调行为发生及不受过户等理由影响；应完整保留签约、履行、登记、知悉各时间点，按可能较早的期限采取措施，不自行消除该解释张力。

### 七、撤销后恢复责任财产，再解决清偿（PDF 579–584）

**书载规则**：被撤销的影响债权实现行为自始没有法律约束力。

**编者解释**：本章倾向撤销权不具有独立优先受偿效力，财产返还服务于恢复债务人责任财产，原告不能直接把追回财产据为己有。未转移物权与已转移物权分别审查；再转让涉及善意取得及返还不能责任。撤销与代位能否一并提出，书中按被放弃债权是否到期、返还债权何时发生区别讨论，且记载草案中的一般一并行使条款最终未保留，不能据书中推论承诺法院必然合并支持。

## 应用推演：判断步骤、证据与诉请

1. 建立三方关系图及余额表，确定自己的债权是否到期、有没有生效文书、是否已有足够担保，避免选择不必要的保全路径。
2. 若是消极不收债，核对次债权、到期日、催收诉讼及从权利期限；本人未到期但有紧迫失权风险时转保存路径。若是积极减损财产，分类无偿、有偿、恶意展期或对外担保。
3. 收集处分前后的资产负债、执行查控、银行流水、转让合同与真实对价、关联关系、估价及市场可比交易；用具体受偿障碍证明影响，不只说“欠钱还送东西”。
4. 独立核验原被告、第三人、管辖、仲裁条款效力和财产保全申请。书载程序多依旧司法解释，不应作为现行立案模板。
5. 把撤销、返还、代位给付、债务人清偿及费用请求分项写明依据；动态登记所有受偿及其他查封、破产信息，防止重复执行。

## 书中具体例证重构

**名义有价、实质无偿（PDF 563页）**：书中举例，财产转让合同写了合理价款，但约定以无实际价值的股权抵付，或把付款拖至遥远将来。判断不能停在合同标价，应核实股权实际价值、可兑现性及付款现实可能，再评估是否实质减少责任财产。书中还以有履行能力的担保人被换成无履行能力者说明，应审查担保质量而非只看“仍有担保”字样。这些是编者论证例，不是具名裁判。

**临期降价（PDF 567页）**：临期果蔬为减少腐损、回笼资金低价出售，不宜只按价格比例认定诈害。需要库存与保质期、同期行情、询价及资金用途证明商业理由；相反，形式上未突破某比例也不自动排除诈害。该例说明价格、行为目的、受偿影响与相对人认知须共同审查。

## 误区、关联与现行核验

误区：自己的债权未到期就请求次债务人直接付款；代位判决一生效就注销原债；撤销胜诉便取得优先权；把任何担保注销、低价销售均当作逃债；只算一年不算五年；把起诉当作已经完成财产冻结。

关联：[ch04 履行](ch04.md)的从权利、连带债与涉他履行；[ch06 变更和转让](ch06.md)的转让、债务承担；[ch07 终止](ch07.md)的免除、抵销和清偿；另联用破产、执行及担保规则。

现行核验重点：合同编通则司法解释关于代位标的、怠于行使、保存行为行权名义、诉讼主体与管辖、仲裁影响、撤销范围和返还、异常价格及关联交易、必要费用和除斥期间；执行参与分配及破产中个别清偿规则。保存权范围扩张、起诉处分限制和既判力扩张均仅为本书解释线索。
