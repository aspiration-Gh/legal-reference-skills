# 第十二章　借款合同：资金交付、用资成本与还款责任

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15；本章PDF第1266—1327页，已顺序读完源文。页码均为PDF页码。书中使用旧民间借贷司法解释及24%／36%利率分层，属于历史材料，不能直接用于现行计算。使用本章须先确认借款、合同变更和诉讼发生时间，再核验适用规范。

## 核心问题

先判断谁向谁借款、何时实际交付及实际可用本金，再处理合同效力、用途、期限、利息和担保。借条、转账及资金用途分别证明不同事实；实际使用人、付款账户名义人与合同借款人也未必相同。

## 八项核心规则

### 1. 主体和成立方式决定证明路径（1266—1276、1312—1315）

【书中法条规则】借款以货币为标的，借款人到期返还并依有效约定付息。自然人之间借款自贷款人提供借款时成立；书面形式允许自然人之间另作约定。

【编者解释】金融借款为诺成合同，自然人间借款为实践合同；不能将实践性扩大到所有民间借贷。现金收取、资金到账、依法取得票据权利、实际取得账户支配权及约定其他方式完成履行，可分别证明交付。借款、保证、抵押写在同一文本中，仍须区分各自成立要件。自然人间文本约定签字生效，不能代替实际提供借款；未签字但依约实际履行，也须审是否形成合意与履行承认。

【应用推演】识别个人、企业及金融机构，再建立“文本签署—到账—处分”时间轴。法定代表人以个人名义借款用于企业经营，书中案例认定企业共同还款，应查实际用途及适用解释，不能将“公司收到款”一概等同共同借款。

### 2. 借款合意与交付事实须相互印证（1268—1272、1275—1276、1287—1289）

【编者解释】借条或收据不绝对证明现金交付；大额现金来源、补签时间、双方关系、前债未还又持续出借等异常可产生合理怀疑。无标准借据也可由证明、转账、对账及承认形成完整证据链。认可真实借据但否认数额者，应说明反证及还款情况；仍不能免除出借方就借款成立的基础举证。

指定第三人收款可以完成交付，不当然构成债务转移；没有授权证据的对外转账，不能自动证明向被诉借款人放款。书中对签章时主要条款空白、事后填入但无合意证据的合同不认成立，同时从实际资金往来另认借贷，提示不得把书面文本瑕疵与整个交易不存在混为一谈。

### 3. 真实信息、放款提款及贷后监督分别处理（1277—1281、1286—1292）

【书中法条规则】借款人依要求提供有关业务和财务真实情况；贷款人未按约定日期、数额提供借款并造成损失的赔偿；借款人未依约提款的按约定日期、数额付息。贷款人可依约检查监督使用，借款人依约提供财务资料。

【编者解释】自然人间尚未交付则合同未成立，不直接套用未提款付息规则。财务真实性审查与贷后持续报告分处不同阶段；隐瞒信息的效力及损害救济需另审要件。长期完全不提供约定报表，可依合同目的解释构成违约，即使具体时间方式未写清。监管机构要求银行检查属于风险管理规范，违反并不当然使保证人免责。

【应用推演】留存申请材料、审贷记录、放款条件、提款申请、到账凭证、报表提交及催要记录；如主张提前到期，应指明具体条款、违约事实及通知，而不只写“信用变差”。

### 4. 用途违反、主体混同和抵销不能混同（1280—1281、1293—1298）

【书中法条规则】借款人未按约定用途使用，可产生停止发放、提前收回或解除等后果。

【编者解释】民间借贷也可约定用途，资金闲置一段时间才投入项目不当然证明文本伪造。借款人擅自改变用途，与贷款人参与欺诈、串通骗保不同；后者须另有证据。笼统“流动资金”可能涵盖偿还债务，欲限制应明确写明。借新还旧则须联动保证章专项判断。

书中工程项目借款案例拒绝以另方未结算工程款抵销个人出借款，关键包括主体不同、授权付款不改变出借人及工程款未确定，不能简化成“不同合同的债务一概不能抵销”。先审是否互负债务及抵销要件，再审还款来源承诺的效力。

### 5. 按实际交付确定本金，识别变相砍头息（1282—1285）

【书中法条规则】利息不得预先从本金扣除；已扣除的，按实际借款数额返还并计算利息。

【编者解释】不只查名为利息的扣款，还查综合费、费用回流及放款次日立即付息。书中将借款人未真正享有相应本金使用期限利益的次日付息评价为非典型砍头息；不能因此推定一切提前付息均违法，要结合交易事实。对金融机构服务费，还须审是否实际提供有价值的独立服务。

【应用推演】逐笔核对合同金额、银行到账、同日／次日回流、收费方及最终收款人。不要只拿借据面额计算，更不能在已从本金剔除后又重复扣减同一费用。

### 6. 计息先审有没有约定，再审清晰度和合法上限（1299—1305、1316—1323）

【书中法条规则】没有支付利息约定，视为不支付；约定不明且不能补充，依交易方式、习惯、市场利率等确定，但自然人之间约定不明视为无息。支付时间约定优先；不能补充确定时，书中按借期一年以内到期一并付、一年以上每届满一年付及剩余期间到期付处理。

【编者解释】“融资费”等标签不排除实质利息；“钱不会白用”没有利率或计算方式，书中自然人案例不支持借期利息。借期利息与逾期利息分开判断，不能从无借期利息推出永远不存在逾期责任。债权转让后被判无效，也不当然消除借款人持续占用资金期间的利息。

旧书列金融罚息政策、民间借贷利息与违约金合并限制、24%／36%分层及LPR改革，均须按适用时点重新核验。服务、咨询、顾问、管理费用审质价相符及与借款的关联：收费节奏、与本金比例、签约及放款时间、实际成果、是否重复报告或补造记录。不能仅因另有顾问合同便排除变相利息，也不能仅凭收费即当然抵扣。

### 7. 到期、提前还款和展期分三条时间线（1302—1311）

【书中法条规则】按约还款；期限未约定且无法补充确定时，可随时返还，出借人可催告合理期限内返还。提前还款除另有约定外按实际借款期间计息。到期前可申请展期，经贷款人同意。

【编者解释】合理宽限期取决主体和偿付准备，不宜把某案开庭日作为统一到期日。展期是履行期限变更；监管展期期限限制不当然成为合同无效根据。事后重新约定清偿安排未必属于条文所指展期，更不当然延续已消灭的保证。保证人未书面同意时，应继续按原保证期间审查，不能简单称保证全部免责。原借款经赋予强制执行效力的公证，后来重大修改的展期协议是否可直接执行需单独审查。

### 8. 资金来源和放贷效力在算账之前核清（1323—1327）

【编者解释／历史规则】书中以当时司法解释及会议纪要讨论套取金融信贷高利转贷，重在资金来源、利差牟利与借款人知悉情况，并提出尚欠银行贷款可推定资金来源、允许反证。该套要件是历史规则，不当作现行无效要件清单。转贷无效不当然使上游银行借款无效；无效后的本金返还及资金占用损失，与合同约定利息分开。商业银行按合同上浮利率也不因“高于基准”四字就当然无效。

## 书中具体例证重构

【1268—1269页】出借方有150万元转账，又主张以旅行袋交付两次大额现金，相关借条收据事后补写，且其中“现金”数额包含先前转账。法院要求现金来源的朋友及陪同者出庭、补充提款记录，仍未提供，故未认定争议现金交付。可迁移的方法是检查证据相互矛盾之处并补足来源、交付、对账链条；不是确立“大额现金借贷均不受保护”。

【1282—1283页】书中设例：借款约定500万元，提供时扣50万元利息、实际给450万元，按450万元识别本金，后续利息也以实际本金为基数。这里只重构源书示例，实案还要核资金回流与费用性质。

## 操作与证据清单

【应用推演】制作逐笔账表，列出借款合意、资金来源、付款人、收款人及授权、到账和回流、约定用途、有效利息及费用、每次还款、抵充主张、催告与保证期间；先解决效力及本金，再分段计算借期和逾期成本。收集原始流水而非只有截图，核电子聊天上下文、借据形成时间及补填授权，区分贷款人、受托放款人和实际使用人。将服务合同与服务成果一并核对，并要求对方说明费用计算和资金去向。

常见误区：以借据面额代替实付本金；只凭向第三人转账证明交付；把实际用款人直接当借款人；把其他主体的工程款直接抵销借款；把无借期利息等同无逾期责任；将旧利率分层和转贷要件用于所有时期。
