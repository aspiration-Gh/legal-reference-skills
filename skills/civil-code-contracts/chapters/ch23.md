# 第二十三章 委托合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记2020-07-15；全文阅读PDF第2560—2642页，对应源文件ch23.txt。以下“法条层”是书中所载规范的概括，“编者解释”保留作者判断，“应用推演”是据此形成的办案步骤。实际使用先核验行为发生时及现行法律、司法解释与过渡规则。

## 核心问题与规则

### 1. 先定合同性质，再查代理授权（PDF2560—2569）

**法条层：**委托的核心是受托人处理委托人事务，既可特别委托，也可概括委托。

**编者解释：**原则上属于行为之债，强调勤勉处理过程；无明确约定时，不保证事务成功。报酬与费用必须分开：报酬是劳务对价，垫付费用不是。有报酬约定或应付报酬的交易习惯，才据此认定有偿。不得委托依法须本人实施、强人身性或违法的事务。委托合同是双方内部债的关系，代理权授予是另一法律行为；有委托不当然有代理权，有代理权也不必有委托合同。

**应用推演：**读取具体权利义务，先分清过程服务、成果交付、固定回报、经营风险承担，再检查对外签约名义和授权。不能因合同标题有“委托”就适用本章。概括授权也不是委托人全部事务无限开放；处分重大利益应逐项核实特别授权。

### 2. 费用、指示、转委托、报告与财产移交（PDF2570—2586、2604—2605）

**法条层：**委托人应预付费用，偿还必要垫款并付利息；受托人按指示处理，原则上亲自办理，经同意、追认或符合紧急保护利益条件可以转委托。经同意或追认的，委托人可直接指示次受托人，原受托人就选任、指示承担责任；未经认可且无紧急例外的，原受托人对次受托人行为负责。受托人有过程报告、终止结果报告及取得财产转交义务。

**编者解释：**必要费用审查关联性、合理性和处理方式的适当性。虽法条没有“另有约定除外”，编者仍支持当事人另定费用承担，不将“应当预付”直接当效力性强制规范。变更指示原则上先征同意；紧急且无法联系时，还须能够推定符合委托人本意，并及时报告。财产包括物、金钱、股权等财产性权利，登记在受托人名下的应办理移转。未报告若不构成根本违约，可涉及任意解除；构成根本违约才转入一般法定解除审查。

转委托未经同意，不当然使受托人与次受托人订立的合同无效；应分别审查合同效力、对委托人效果及外部复代理。书中对次受托人“直接负责”与内部合同相对性的表达存在张力，不能据单句断定委托人对次受托人享有全部合同请求权。

### 3. 自己名义签约时，按第三人知情时点分流（PDF2587—2603）

**法条层：**书中第925条分支要求受托人在授权范围内以自己名义签约、第三人订约时知道代理关系；有确切证据仅约束受托人与第三人的除外。第926条分支以订约时第三人不知道代理关系为前提：因第三人原因不能向委托人履行，经披露可发生委托人介入；若第三人知道该委托人就不会订约，则排除介入。因委托人原因不能向第三人履行，经披露第三人可选委托人或受托人，但不得变更选择。抗辩随分支分别转移。

**编者解释：**“知道”取实际明知，不包括应知；还要求明知具体被代理人，但不要求明知授权的全部细目。支持直接约束关系的一方承担相应证明责任。同一事实不能把显名代理、第925条和第926条同时作为无差别依据；行纪已有特别规定，也不能绕道适用。介入须明确向第三人主张；选择权行使后，不因选定者无力履行就改选他方，亦不当然产生三方连带责任。编者认为披露不能被强制履行，但受托人仍面对自身合同责任；这是解释立场，不可写成“拒绝披露一概免责”。

### 4. 分开核算报酬、过错赔偿和风险损失（PDF2606—2613）

**法条层：**按约支付报酬；不可归责于受托人的解除或不能完成，原则上支付相应报酬，另有约定从约定。有偿委托因受托人过错造成损失，无偿委托因故意或重大过失造成损失，分别承担赔偿；超越权限致损另作评价。受托人处理事务因不可归责自身事由受损，可以向委托人请求赔偿。

**编者解释：**“是否付酬不清”与“确定有偿但数额不清”不同：前者经补充及习惯仍不能确定，可按无偿；后者应确定合理报酬。相应报酬除完成比例，还可结合委托人拖延导致的工作时长、劳务投入。编者主张越权致损适用严格责任；第三人侵害导致受托人损失，书中讨论第三人不明或无力赔偿时向委托人求偿及后续追偿，使用时核验请求权关系，防止重复获赔。

### 5. 分辨重复委托与共同受托（PDF2614—2617）

**法条层：**经原受托人同意另行委托，造成其损失仍须赔偿；共同处理同一事务的数个受托人对委托人负连带责任。

**编者解释：**重复委托是委托人另行委托，转委托是受托人再委托，共同受托强调同一关系中的共同处理。未经同意重复委托不当然无效，但须赔偿损失。若事务范围及权限已分别划清，并非当然构成共同处理；真正共同处理者不能仅凭内部管理分工对抗外部连带责任。

### 6. 任意解除与终止善后分别审查（PDF2618—2642）

**法条层：**双方可随时解除；除不可归责于解除方的事由外，无偿合同赔偿解除时间不当造成的直接损失，有偿合同赔偿直接损失及履行可得利益。法定主体变故原则上导致终止，但另约或事务性质不宜终止有例外；保护委托人利益需要时存在继续处理、及时通知及必要措施义务。

**编者解释：**限制任意解除条款有三种旧裁判路径：条款无效、解除有效但违约、解除受阻。编者支持解除效果不被排除，限制约定可影响责任，并明确仍待司法解释或案例统一。单纯委托与含包销等内容的混合合同须先区分。已办事务费用、应得报酬与解除赔偿分项计算，适用减损、损益相抵等避免重复。

委托人丧失行为能力不再当然导致终止；编者将受托人“丧失”限于完全丧失，属解释结论。法人解散、宣告破产、进入清算与最终终止不等同，不能机械等注销后才通知和保全。委托人死亡后，继续处理止于继承人、遗产管理人或清算人接手；受托人一方变故后，其相关承接主体履行的是通知与必要保护义务，并非自动继承全部专业服务义务。

## 具体判断步骤与证据

1. **建立三层关系图（应用推演）：**列委托合同、授权行为、对外交易；标出每份合同的签约名义、代理权限、知情时点。收集授权书、往来信息、签约参与记录及交易付款安排。
2. **建立履行时间线：**原始指示与变更、联系失败、紧急风险、转委托同意或追认、报告、财产取得与移交。不能仅以最终未成功反推受托人过错。
3. **建立四栏结算表：**必要费用及利息、已付出劳务报酬、违约损失、解除损失。保留票据、资金去向、工时及已完成事项，逐项证明因果关系及净损失。
4. **选择终止路径：**核实是一般法定解除、约定解除、任意解除还是主体变故；留存通知到达及承接时间，先安排财物、账户、未决诉讼资料交接。该流程是应用推演，不扩张书中法定义务。

## 书中例证重构

**救灾购橘（PDF2576）：**甲明确要求无论如何购买某地柑橘；乙到场遇虫灾且联系不上甲，改买邻地质优价当的柑橘。甲实际为了变相救灾。编者据此说明：客观经济利益更优，不等于符合委托本意；紧急、失联仍不能替代对明确指示目的的审查。

**介入权与转让的先后（PDF2602—2603）：**书中闽路润、兴盟、钢翼交易，兴盟仅向受托人表示将购销债权让给受托人起诉，未先向第三人明确介入。编者据此认为兴盟未取得该合同主体地位，不能把未取得的债权有效转让。实际应用核查介入表示对象、身份与到达时间，不凭内部函件补足。

**继续处理的期限（PDF2635）：**养貂技术委托中，委托人死亡，其子暂难找到技术人员，编者要求受托人继续必要指导至承接完成。该例支撑防止突然停止服务造成损害，不能推成无期限无偿服务。

## 争点、误区与OCR未决

不得将有偿关系一律当成果保证、把转委托未获同意写成合同无效、把隐名代理知情替代为“应知”、把任意解除写成无须赔偿。PDF2611关于无偿代购彩票漏购而指定号码中奖的免责论证，是书中基于射幸性及过错的争议判断，不能泛化至故意侵吞已购彩票。PDF2583复代理条号与前文不一致，PDF2617“共同委托人”语境应指受托方，PDF2635例末主体称谓不一致；仅按上下文概括，不校造条号和人名。若需引用原文须核原PDF及官方规范。
