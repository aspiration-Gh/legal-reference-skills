# 第十六章 保理合同

来源：《民法典合同编理解与适用》，最高人民法院民法典贯彻实施工作领导小组主编，后记日期2020-07-15。全文顺序阅读源 ch16.txt，覆盖 **PDF第1823—1857页**（PDF文件页码，不是印刷页码）。本章是旧版书籍知识提炼；使用时须按争议事实发生时间核验现行法、司法解释及过渡规则。以下“书载规范”指书中转述的法条或规范，“编者解释”不具有法条效力，“应用推演”是证据和办案步骤建议。

## 核心问题与适用范围

适用于以现有或将有应收账款转让为基础，提供融资、账款管理催收、付款担保等服务的交易。首先区分三层效力：转让人与保理人之间是否转让、是否对债务人生效、多个保理人或其他权利人之间谁能对抗谁。不能用一份合同的签订日期回答全部问题。

## 八项核心规则

### 1. 识别保理及将来债权（PDF1823—1832）

**书载规范：**保理以现有或将有应收账款转让和相应服务为基本结构。**编者解释：**服务内容为选择性、提示性列举，不要求融资、管理、催收、坏账担保同时具备；赊销背景下有债权转让与融资即可具备典型保理结构。预付保理提供提前融资，到期保理可能不提供融资，不能因此否定合同。

将来账款须能通过合同描述在发生时确定为转让目标。编者认为，现有债权原则上在转让合意时变动；将来债权在实际发生时变动，无需再次作出让与意思表示。直接取得说与瞬间经让与人取得说对该时点的结论相近，但对外效力仍要另查登记等规则。书中质押登记办法与银行保理监管规则对应收账款范围并不完全一致，不得以某一历史部门规章的定义替代全部民事效力判断。

### 2. 书面形式与完整交易文件（PDF1833—1835）

**书载规范：**保理应采用书面形式，内容通常包括业务类型、服务期限、基础交易、账款信息、融资或报酬、支付方式。可有形表现且可调取的数据电文可构成书面形式。**编者解释：**合同之外的信函、传真等可能共同组成合同。回购、保证、抵质押、违约及争议解决条款应结合全套往来文件解释，不能只看主协议标题。

### 3. 虚构应收账款的信赖保护（PDF1836—1840）

**书载规范：**债权人与债务人共同虚构账款作为保理转让标的，债务人不得以账款不存在对抗保理人，但保理人明知虚构的除外。**编者解释：**必须有共同制造的权利外观、保理人的实际信赖、该信赖与订约的因果关系。若保理人无论账款真假都会放款，不符合本条保护前提。

书中比较三种路径：侵权补充赔偿、诚信原则下确认书的证据效力、外观主义保护。编者赞同第三种，认为立法特意使用“明知”，不能直接改写为“知道或应当知道”。但完全未调查或虚假程度明显到稍查即知的情形，编者保留讨论空间。实际处理仍应保存尽调资料，不能把“非明知”当作免除监管或合同尽调义务的依据。

### 4. 通知及基础合同嗣后变更（PDF1841—1844）

**书载规范及编者解释：**转让人或保理人均可通知债务人；保理人通知应表明身份并附必要凭证，不能只有无从核对的简单声明。通知旨在避免债务人错误清偿。

以转让通知到达债务人时的基础合同条件为审查起点。嗣后无正当理由变更或终止基础合同、损害保理人利益的，不得对抗保理人。关键是正当理由及利益影响，不能把全部真实商业调整一律否定；质量争议、正常退换货与串通延付须分别调查。

### 5. 有追索权保理的请求与清算（PDF1845—1849）

**书载规范：**可向原债权人请求返还融资本息或回购账款，也可向债务人主张账款；扣除融资款本息与相关费用后有余款，应返还原债权人。**编者解释：**不能因两项请求并存获得重复清偿，书中并将保理人受偿上限解释为融资款本息和约定费用。

共同起诉不等于当然连带责任。书中记载让与担保说支持连带、间接给付说支持债务人先偿与原债权人补充的分歧；编者在无连带约定时赞同后者，理由是应收账款清偿为第一还款来源。有连带约定时按约处理。这是本书解释立场，使用时必须另核后续裁判与规范，不能标成法条直接规定的法定顺位。

### 6. 无追索权保理的风险与收益（PDF1831—1832、1850—1851）

**书载规范：**保理人向债务人主张债权，收回超过融资本息及相关费用的部分无需返还原债权人。**编者解释：**这是承担信用风险的对应收益，不构成不当得利。但无追索并非包揽一切基础交易风险：债权本身不真实、不合法、存在因供货履行瑕疵而产生的抗辩，与债务人支付能力风险不同；债权人仍可能承担账款品质、权利瑕疵担保责任。须核合同中的保证、商业纠纷及回购触发条件。

### 7. 多重保理的权利顺位（PDF1852—1856）

**书载规范：**已登记优于未登记；均登记按登记时间先后；均未登记，以最先到达债务人的转让通知所载保理人为先；既未登记也未通知，按融资款或服务报酬比例取得账款。最后一项不是按账款票面金额比例，也不是按放款先后。

**编者解释及争议：**登记解决公示及竞争权利问题，通知另解决对债务人的效力。书中借鉴国际公约提出，后受让人明知先转让时，不宜仅靠先通知夺取优先地位；还讨论同日到达参考寄出先后。这些均非该法条明文，不能直接作为一般裁判结论。本规则直接针对同一账款多重保理，不自动穷尽普通转让、质押、执行或破产权属冲突。

### 8. 补充适用债权转让通则（PDF1857）

**书载规范及编者解释：**保理专章未规定的，联系本编第六章债权转让规则，继续审查禁止转让约定、从权利、抗辩、抵销及增加的履行费用，并结合成立、生效、履行、违约通则。不能凭保理标签消除债务人的全部基础抗辩。

## 书中具体例证与论证重构

**有追索保理受偿范围例（PDF1847、1849）：**书中引述珠海华润银行与江西省电力燃料公司等纠纷〔（2017）最高法民再164号〕，实际融资本金3680万元，所主张应付账款本金46115344.70元。书载裁判未按全部账款本金支持请求，而将范围限于融资本金及利息；编者据此论证清算限制，并以间接给付解释债务人先偿、原债权人补充。这里仅重构本书所述裁判，不表示已调阅判决全文或确认其现行指导效力。

**不当变更例（PDF1843—1844）：**保理订立后，原债权人与债务人自行延长付款期限或附加不合理条件。判断链是确认通知到达与原合同版本，再查变更理由和损害，缺乏正当理由的仍向保理人按原条件履行。

## 应用推演：处理步骤与证据

1. 建立三方主体、基础交易、账款编号及金额表；取得主协议、订单、交付验收、发票、对账、付款流水，确认现有或将来账款及可识别性。
2. 对照实际履行确定服务内容及追索类型；分别列融资、费用、余额返还、回购条件，核对已回款，防止双重受偿。
3. 固定债务人确认、尽调访谈及内部审批的形成时间，检验虚构、明知与信赖因果关系，不能只凭盖章确认书推定全部事实。
4. 保存通知内容、所附凭证及到达证据；收集通知前后基础合同版本，逐项解释变更理由。
5. 调取登记及变更记录、竞争转让通知和付款记录；先分三层效力，再论顺位及诉讼请求。提出连带、补充或回购请求时分别列明依据。
