# 合同实务术语索引

据现有30章提炼，按拼音首字母排序；释义为书载规则提要，解释分歧回读章节。本表选取容易影响判断的概念，不涵盖全部罕见术语，也不代替全书。来源层次及适用时点见[来源说明](sources.md)。

- **保理** — 转让现有或将有应收账款并提供融资、管理等服务；追索类型影响风险与清算。[ch16](chapters/ch16.md)
- **保证期间** — 确定保证责任是否存续的期间，不同于保证债务诉讼时效；主张对象与方式随保证类型变化。[ch13](chapters/ch13.md)
- **不安抗辩** — 先履行方有确切履行能力风险证据时中止；须通知并审担保、恢复条件。[ch04](chapters/ch04.md)
- **不当得利** — 无法律根据的财产利益返还；须查损益联系、除外情形及善恶意。[ch29](chapters/ch29.md)
- **仓单** — 仓储收货、提货及流转凭证；持单不当然证明所有权或真实货物存在。[ch22](chapters/ch22.md)
- **承揽** — 独立完成特定工作成果并取得报酬；区别持续劳务和买卖。[ch17](chapters/ch17.md)
- **代位权** — 债权人依法代行债务人权利；到期前保存与直接受偿分支不同。[ch05](chapters/ch05.md)
- **抵充／抵销** — 前者分配不足给付，后者依法或依约消灭互负债务。[ch07](chapters/ch07.md)
- **缔约过失** — 订约阶段违反诚信义务造成损失的责任；谈判失败本身不足。[ch02](chapters/ch02.md)
- **定金** — 以实际交付成立的担保安排；订金、押金不当然适用没收或双返。[ch08](chapters/ch08.md)
- **格式条款** — 重复使用、预先拟定且未协商的条款；订入、效力、解释分别审查。[ch02](chapters/ch02.md)
- **工程价款优先权** — 特定工程价款的法定优先受偿；主体、范围、质量及行权期限另审。[ch18](chapters/ch18.md)
- **合伙** — 为共同事业共享利益、共担风险；内部份额与外部债务分别判断。[ch27](chapters/ch27.md)
- **合同相对性** — 合同原则约束当事人；第三人请求或责任须有独立依据。[ch01](chapters/ch01.md)
- **检验通知期** — 检验并提出不符异议的期限；不同于质保期、诉讼时效，隐蔽瑕疵等另审。[ch09](chapters/ch09.md)
- **情势变更** — 不可预见、非商业风险重大变化致继续履行明显不公；协商不成请求裁决。[ch04](chapters/ch04.md)
- **融资租赁** — 以真实租赁物结合融资；租金、风险与维修不同于普通租赁。[ch15](chapters/ch15.md)
- **所有权保留** — 先交付使用，约定条件成就后移转所有权；取回不自动解除，须清算。[ch09](chapters/ch09.md)
- **提存** — 法定受领障碍下向合格机构交付，依法产生相应清偿效果；另行寄存不足。[ch07](chapters/ch07.md)
- **委托／行纪／中介** — 分别重在处理事务、以自己名义贸易、报告机会或撮合；对外主体与报酬条件不同。[ch23](chapters/ch23.md)／[ch25](chapters/ch25.md)／[ch26](chapters/ch26.md)
- **无权代理／无权处分** — 前者涉及行为归属，后者涉及处分权限；均须分开审合同与权利变动。[ch03](chapters/ch03.md)／[ch09](chapters/ch09.md)
- **无因管理** — 无既有义务而为他人避免损失管理事务；真实意思、管理方法与受益范围影响请求。[ch28](chapters/ch28.md)
- **信赖利益／履行利益** — 分别关注信赖交易的损失与如约履行状态；成本、利润、重复补偿分别核算。[ch08](chapters/ch08.md)
- **一般／连带保证** — 区别主要在履责顺序、先诉抗辩及期间内行权方式；多人保证不自动等同连带保证。[ch13](chapters/ch13.md)
- **预约** — 约定将来订立本约的独立合同；不直接等同本约已成立。[ch02](chapters/ch02.md)
- **债权人撤销权** — 撤销影响受偿的诈害处分；无偿、有偿等构成不同，胜诉不自动取得优先权。[ch05](chapters/ch05.md)
- **债务加入／免责承担** — 前者增加责任人，后者使原债务人就转移部分退出；意思、通知、同意要求不同。[ch06](chapters/ch06.md)
