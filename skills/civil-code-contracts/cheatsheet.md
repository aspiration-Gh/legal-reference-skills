# 合同判断速查

本表是据书自编的分流提示，尚非现行法结论；先定事实时点，读所链章节，再按[来源说明](sources.md)核法。它不复现全部条件和罕见问题。

| 情形 | 核查条件 → 判断方向 | 依据 |
|---|---|---|
| 未签章却已付款收货 | 是否主要义务且被接受 → 可能成立；权限与效力继续审 | [ch02](chapters/ch02.md)、[ch03](chapters/ch03.md) |
| 格式免责已经勾选 | 提示理解、内容效力、通常解释分查 → 签字不当然有效 | [ch02](chapters/ch02.md) |
| 对方违约想停付 | 对待给付、履行顺序、瑕疵范围 → 只拒绝相应请求；能力风险另审确切证据及通知 | [ch04](chapters/ch04.md) |
| 想单方解除 | 事由、目的受损、催告、期限、到达 → 有权才能行使；解除后仍清算 | [ch07](chapters/ch07.md) |
| 涨价或灾害 | 商业风险、具体因果、可否履行 → 分情势变更、不可抗力及一般违约 | [ch04](chapters/ch04.md)、[ch08](chapters/ch08.md) |
| 第三人替还钱 | 有无承担意思、原债是否退出 → 代付、加入、免责承担分别处理 | [ch06](chapters/ch06.md) |
| 债务人逃债 | 不收债或积极处分、受偿影响 → 代位或撤销；未到期保存不得提前自偿 | [ch05](chapters/ch05.md) |
| 保证未写方式 | 先查适用时期，再辨一般保证与连带 → 分别核期间内主张对象及程序 | [ch13](chapters/ch13.md) |
| 已签收仍发现瑕疵 | 检验范围、隐蔽性、通知、卖方知情 → 签收不等于全面放弃 | [ch09](chapters/ch09.md) |
| 货物损毁或收回 | 交付、原因、风险约定、合同类型 → 风险与违约分算；收物须扣值清算 | [ch09](chapters/ch09.md)、[ch15](chapters/ch15.md) |
| 租物不能用 | 实际用益妨碍、归责、修复可能 → 相应减租或审解除，轻微问题勿全停租 | [ch14](chapters/ch14.md) |
| 欠费被停水电 | 谁停供、何种债务、催告通知 → 供应方依专门程序；物业不得停供催物业费 | [ch10](chapters/ch10.md)、[ch24](chapters/ch24.md) |
| 赠与后反悔 | 权利已否移转、公证公益等例外 → 区分任意撤销、法定撤销与穷困抗辩 | [ch11](chapters/ch11.md) |
| 工程无效仍索款 | 已完质量及修复结果 → 审折价补偿；优先权另核主体范围期限 | [ch18](chapters/ch18.md) |
| 开发失败或成果争夺 | 客观技术困难、勤勉、协作、创造贡献及约定 → 分风险、违约与权属 | [ch20](chapters/ch20.md) |
| 物流货损或存物丢失 | 运输区段／保管占有、收费及专业注意 → 选特别责任与证据，勿一概严格或无责 | [ch19](chapters/ch19.md)、[ch21](chapters/ch21.md)、[ch22](chapters/ch22.md) |
| 服务没成功却收费 | 成果承诺、过程义务、促成与费用约定 → 委托、行纪、中介分别结算 | [ch23](chapters/ch23.md)、[ch25](chapters/ch25.md)、[ch26](chapters/ch26.md) |
| 无合同要求退款 | 既有义务、保有根据、真实意思、现存利益 → 分无因管理与不当得利 | [ch28](chapters/ch28.md)、[ch29](chapters/ch29.md) |

**金额与期限闸口：**本金、返还、损失和担保受偿先去重；定金与同一违约的违约金原则择一。保证期间、解除期间、检验通知期、诉讼时效单列，旧利率和旧工程优先权期限核实后才计算。详见[责任](chapters/ch08.md)、[借款](chapters/ch12.md)、[保证](chapters/ch13.md)。
