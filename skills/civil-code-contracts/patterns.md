# 合同问题的实务方法

以下步骤均为**自编应用推演**，依据现有章节组织，不冒充编者命名方法。章节中的书载规则、编者解释须分别引用；具体使用按[来源说明](sources.md)核验适用时点官方法源。

## 1. 关系、时间与请求三张表

**何时用：**任何合同审查、催款或退款问题。

**怎么做：**列主体及授权、实际给付、订约至争议时间轴；把诉求写成“谁向谁请求什么”。先分合同、身份关系、行政协议及法定债，再按特征给付找典型合同；混合合同保留各部分联系。逐项记录改变结论的缺失事实。

**边界：**文件名称、账户名、签章及利益关系均不能独自决定责任主体；新旧法按事实与过渡规则分流。[绪论](chapters/ch00.md)／[一般规定](chapters/ch01.md)

## 2. 成立、效力与条款逐层审查

**何时用：**未签字、电子订单、预约、报批或免责争议。

**怎么做：**核表示内容、发出与到达、承诺、主要履行及接受；再核权限、批准对象、强制规范。格式条款依次查是否订入、内容效力、解释；含糊条款先解释，遗漏事项再补充。

**边界：**成立不必然生效；未生效主合同的报批及争议条款可能独立；提示签字不能治愈违法免责。保存完整版本和提示、授权、送达证据。[订立](chapters/ch02.md)／[效力](chapters/ch03.md)

## 3. 暂停、补救与退出分支

**何时用：**对方欠款、交付不符、履行能力下降或成本激增。

**怎么做：**制作义务与到期表，核己方履行；按顺序选择同时、先履行或不安抗辩，控制对应范围。能力危险须确切证据、通知、担保及恢复审查。解除另核事由、严重性、催告、行权期间与通知到达；情势变更先协商，再依法请求裁决。

**边界：**抗辩通常仅暂缓；涨价、涉诉不自动允许停付；解除仍须结算。存证包括瑕疵、风险与本合同的联系、补救方案及到达凭证。[履行](chapters/ch04.md)／[终止](chapters/ch07.md)

## 4. 债权保全与主体变动分开办理

**何时用：**债务人不收债、转走财产、转让债权或第三人承诺还款。

**怎么做：**画两层债权及余额；不收债查代位，未到期且有紧迫失权危险查保存，积极处分查撤销。主体变动分债权转让、免责承担、债务加入；分别固定通知、同意及承担范围，再查担保、抗辩与抵销。

**边界：**胜诉不等于已受偿或取得优先权；代付不当然免责承担。保证另建期间和时效表，保理另查账款真实性、追索及登记竞争。[保全](chapters/ch05.md)／[转让](chapters/ch06.md)／[保证](chapters/ch13.md)／[保理](chapters/ch16.md)

## 5. 对照物与钱，形成可核算清单

**何时用：**质量、风险、退货、租赁退出及融资租赁收物。

**怎么做：**分别记录交付、权属、风险、检验通知、价款与费用；保存验收、事故原因、质保及催告。清算逐项列原物、使用收益、修复、残值、已付款及保险。继续收租、解除收物等请求选择须与合同状态匹配。

**边界：**签收不排除隐蔽瑕疵；风险转移不免除独立违约；普通租赁与融资租赁不能共用停租规则；取回后不能不扣物值重复受偿。[买卖](chapters/ch09.md)／[租赁](chapters/ch14.md)／[融资租赁](chapters/ch15.md)

## 6. 把赔偿拆为项目，再逐项限制

**何时用：**违约金、定金、利润或利息请求。

**怎么做：**列项目、期间、如约履行基准、必要成本、因果与订约可预见证据；核减损、与有过错、节省成本及已获补偿。定金核实际交付、担保对象及目的落空；与同一违约的违约金比较择用。借款先核实际本金及费用回流，再分段计息。

**边界：**营业额不等于净利润；定金与全额损失不可重复填补；旧书利率不可直接套算。金额用工具计算并列假设。[违约责任](chapters/ch08.md)／[借款](chapters/ch12.md)

## 7. 专门合同按不同风险承诺分流

**何时用：**工程、研发、运输、保管及服务纠纷。

**怎么做：**工程先查资质招标、已完质量再谈价款；研发失败先辨技术风险、协作障碍与违约；运输先分人身、随身物、货物和区段；保管仓储核交付成立例外、收费、专业标准及出入库；委托看勤勉过程，中介看促成条件，行纪看自己名义对外责任。

**边界：**不能以失败推定违约或以免费一概免责；工程、物业退出不机械套普通委托。对应证据为图纸签证、研发日志、运单交接、仓单验收及服务记录。[承揽](chapters/ch17.md)／[工程](chapters/ch18.md)／[运输](chapters/ch19.md)／[技术](chapters/ch20.md)／[保管](chapters/ch21.md)／[仓储](chapters/ch22.md)／[委托](chapters/ch23.md)／[物业](chapters/ch24.md)／[行纪](chapters/ch25.md)／[中介](chapters/ch26.md)

## 8. 无合同与共同事业另走请求基础

**何时用：**共同出资退出、代办事务或误付返还。

**怎么做：**合伙分内部盈亏与外部债务，退出先盘点清算；管理事务先排除既有义务，再核他人利益、真实意思、通知与费用；不当得利先查保有根据，再查除外、善恶意及现存利益。

**边界：**退伙不自动免旧债；热心帮忙不自动有偿；钱花掉不等于利益消失。成果按“事实缺口→争点→书中依据→官方核验→条件结论→证据行动”交付；涉及数据、隐私或系统安全，联用 `cyber-data-law`，合同授权不替代数据行为合法性判断。[合伙](chapters/ch27.md)／[无因管理](chapters/ch28.md)／[不当得利](chapters/ch29.md)
