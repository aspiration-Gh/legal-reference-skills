来源：最高人民法院民法典贯彻实施工作领导小组主编《民法典合同编理解与适用》，人民法院出版社。后记署2020年7月15日，具体版次未确认。原PDF2905页；本技能覆盖绪论及29章的2802页正文。103页封面、序言、凡例、目录、分编扉页和后记列入排除清单，未作为实务章节改写。

## 先做什么

1. 识别用户要解决的是订约审查、履行催告、解除退款、损害赔偿、担保追偿还是其他请求；收集主体、地域、关键日期、完整合同及实际履行事实。
2. 用下方索引加载有关章节。具体结论必须读对应文件，不凭入口摘要替代条件、例外及书中争论。
3. 明确区分**书载法条提要、编者解释、应用推演**。书中案例是压缩重构，须按标注PDF页回查，不能扩写未载事实或责任比例。
4. 实际法律问题须联网核验官方现行法律、司法解释、施行与废止信息，以及行为发生时应适用的旧法和过渡条款。先查国家法律法规数据库、立法机关官方网站、最高人民法院；行业与地方问题再查主管部门及当地官方规则。记录标题、发布机关、日期、条号和链接。
5. 检索不到或无法联网时，说明尚未核验，仅给书籍框架和条件化分析；不得声称旧书规则为现行法。

## 核心判断框架

- **关系与请求分离**：先确定合同类型、实际当事人和请求权基础，再决定谁向谁主张什么。无名、混合、身份、行政协议等先分流；不以合同名称直接定性（ch01）。
- **成立—生效—履行—救济分层**：签章、批准、处分权、代理权、交付不是同一问题。成立不等于生效，有效不代表已完成物权变动，第三人代付不等于债务加入（ch02–04、ch06）。
- **条款解释与补缺分开**：先审真实意思、文义、上下文、交易目的、习惯与诚信，再处理未约定事项；格式条款另审纳入、效力及解释（ch01–02、ch04）。
- **抗辩按顺序和范围适用**：辨同时履行、先履行、不安抗辩及解除，证明实际风险，核通知和恢复条件。履行困难不自动成为不可抗力或情势变更（ch04、ch08）。
- **财产保全与主体变动分开**：代位、撤销、债权转让、免责债务承担和债务加入的对象、同意、通知及法律效果各异；胜诉不自动取得物权优先（ch05–06）。
- **退出仍需结算**：解除事由、行权期间、通知到达、返还、折价、损害、担保及独立结算条款逐项判断，避免把解除等同从未订约（ch07）。
- **赔偿先分项再限缩**：核违约义务、损害与因果，区分履行利益、费用及其他损失，再查可预见性、减损、与有过错、免责和重复受偿；违约金、定金及实际损失分别处理（ch08）。
- **特殊合同优先，通则补充**：先用对应典型合同规则，再回到通则；保证期间、检验异议期、解除期限与诉讼时效不能混算（ch09–27）。
- **无合同不等于无请求**：管理他人事务与无根据受益分别检验无因管理、不当得利；不能用概括的“公平”替代构成要件（ch28–29）。

## 跨章路由与交付

- 合同审查：ch01→ch02→ch03→对应合同章→ch08。
- 不履行/退款：对应合同章→ch04抗辩→ch07解除→ch08金额。
- 担保/债权转手：ch06→ch13；应收账款融资再读ch16。
- 房屋交易：ch09/ch14→ch26；物业收费另读ch24。
- 服务开发/外包：ch17/ch20/ch23分别定性；涉及数据处理、隐私、系统安全时联合 `cyber-data-law`，不可从合同授权直接推定数据行为合法。
- 输出顺序：已知事实与缺口→争点→书中框架→已核现行依据→条件化结论→证据及可行下一步。草拟通知或条款时列触发条件、履行期限、送达与举证安排；发送、签署另依用户授权。
